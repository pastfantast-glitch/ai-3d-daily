AI MOTION / MAYA

MotionMaker Bring Your Own Data：用自己的動畫庫訓練 AI Motion

本機訓練 studio-specific motion model，生成結果仍可在 Maya 裡完整編修。

Animation ★★★★★
完整分析

Animation / AI Motion

MotionMaker 的 Bring Your Own Data 允許團隊用自己的 rig 與 hand-key / mocap 資料，在本機訓練客製 ML motion model；生成的動作仍可回到 Maya Graph Editor、Time Editor 與 Dope Sheet 繼續編修。

輸入 / Rig / 訓練

輸入可以是 mocap 或 keyframe animation，先 retarget 到標準角色、標記 walk/jump 等 action style 後訓練。Autodesk 強調訓練與模型都留在本機；NVIDIA GPU 可加速，官方案例中約 40 分鐘資料在 RTX A2000 筆電上訓練約 7 小時。

Production 判斷

這比一般 text-to-motion 更接近 studio pipeline：核心價值是把既有 animation library 的風格與角色性格變成可重用生成模型。優先測 crowd/NPC locomotion，並量測 foot lock、root motion、轉向與 hero animation cleanup 成本。

TEXTURE / BAKING

Substance Painter 12.1：Skew Painting + Auto Rebake 直攻遊戲 Bake 痛點

低模上直接修正投射方向，搭配 hard-surface Auto UV 與 OpenPBR。

Texture ★★★★★
完整分析

Texture Production Delta

Substance 3D Painter 12.1 把 baking workflow 重做：新增 Auto Rebake、直接畫在 low poly 上的 skew correction、Edge Protection，以及 hard-surface Auto UV mode。這些都是會直接減少 low/high bake 修正時間的 production 功能。

Material Pipeline

Painter 12.1 也把 OpenPBR 納入預設材質工作流；12.1.3 在 8/25 更新 Substance engine 並修正 skew correction undo、network export 等問題，讓這批功能更接近穩定 production 使用。

遊戲資產實測

用一個硬表面道具做 A/B：傳統 cage + 手動 skew 修正 vs 12.1 skew painting + auto rebake，記錄 bake 次數、錯誤修復時間與 UV 可編輯性；再確認 OpenPBR export 到 UE/Unity 的 channel mapping。

ENGINE / TECH ART

Godot 4.8 開發快照：3D Trail、VisualShader Groups 與 AO 升級

幾項直接影響 VFX、材質重用與場景光照的功能已進入可測階段。

Engine ★★★★☆
完整分析

Engine / Rendering Delta

Godot 4.8 第四個 development snapshot 已把幾個美術向功能拉到可觀察階段，包括長期被要求的 3D Trail node、VisualShader node groups、多 bounce ambient occlusion 與 directional lightmap specular lighting。

對 Tech Art 的意義

3D Trail node 可減少武器拖尾、軌跡與 VFX 依賴自訂 mesh/script 的成本；VisualShader node groups 則讓材質功能更容易模組化與重用，方向與 UE/Unity 的 shader function/subgraph 類似。

採用策略

目前仍屬開發快照，不適合直接鎖 production。建議先做一個 trail + stylized shader prototype，觀察 draw call、透明 overdraw、序列化與版本升級風險，再等 stable release 決定是否納入正式專案。

BLENDER / TEXTURE

MatPlus 1.3：把 Layer-Based 3D Texture Painting 收進 Blender

多 UDIM、Smart Masks、auto-cache 與 game-ready map export，目標是減少 Blender↔Painter round-trip。

Texture ★★★★★
完整分析

Blender Texture Workflow

MatPlus 1.3 把 Substance Painter / Mari 類型的 layer-based texture painting 放進 Blender，支援 paint/fill layers、folders、blend modes、per-layer masks、多 UDIM 與 game-ready map export；1.3 進一步加入 auto-cache、BeFX Library、Smart Masks 與 Display module。

Production 價值

對希望減少 Blender↔Painter round-trip 的 Prop/Character pipeline，真正值得測的是多 UDIM、channel stack、mask reusability 與 Unreal/Unity map export 是否穩定，而不是只看 UI 像不像 Painter。

導入測試

拿一個含 2–4 UDIM 的硬表面資產，在 MatPlus 與 Substance Painter 各完成一套 edge wear/dirt/material variation，記錄 bake、layer 管理、VRAM、輸出 preset 與返修時間，再判斷是否適合正式資產。

BLENDER / DEFORMATION

Softie Collision：Geometry Nodes 即時碰撞變形，不必完整 Physics Sim

多碰撞物、self-collision 與 hardness control，適合快速動畫 deformation blocking。

Blender ★★★★☆
完整分析

Blender Deformation Workflow

Softie Collision System 用 Geometry Nodes 做即時表面碰撞變形，不需要 lattice、shape key 或完整 physics sim，支援多碰撞物與 self-collision，並提供 hardness 控制。

速度 / 限制

開發者表示簡單多碰撞設定可在 i7-14700F 上低於 10ms；它最適合 surface deformation，深度穿透會讓 raycast vector 失效，因此不是通用 soft-body 替代品。

遊戲美術用途

適合動畫 blocking、抓握軟物、擠壓道具、局部 squash 以及需要快速 art-direct 的 deformation。若要進遊戲，應測 bake/轉形狀鍵或骨架的方式，而不是假設 Geometry Nodes 本身能直接 runtime。

TEXTURE / STYLIZED

Cycletex：照片快速變成可平鋪的低解析遊戲貼圖

透視校正、crop、downscale 與 seamless 集中在同一個 retro texture utility。

Texture ★★★★☆
完整分析

Texture Utility

Cycletex: Retro Texture 把照片轉低解析遊戲貼圖的常見前處理集中成一個工具：前景選取、透視拉正、8/16-pixel crop、縮圖、調色與自動 seamless。

Stylized / Retro 用途

真正有價值的是把『找照片→校正透視→做 tile→降解析』變成快速迭代流程，適合 PSX/低解析風格，也可作為快速 blockout texture 工具。

實測建議

拿同一張街景照片比較 Photoshop/Substance 手工流程與 Cycletex，檢查 seam、色階量化、透視殘留、可重複性與輸出授權，再決定是否適合批次建立環境 base texture。

SHADER / READABILITY

Godot 重現 BG3 Occlusion Cutout：不隱藏整棟牆也能看清角色

對俯視與室內遊戲很實用的角色可視性 tech-art 解法。

Shader ★★★★☆
完整分析

Gameplay Readability

Nando 在 Godot 4.7.1 重現 Baldur's Gate 3 類型的 occlusion cutout shader：當牆面或物件擋住角色時，不是整個隱藏遮擋物，而是在視線區域切出可讀窗口。

Tech Art 價值

固定俯視、斜俯視或室內遊戲常需要這類可視性解法。它比單純 fade 整棟建築保留更多場景資訊，也更容易維持場景美術完整度。

移植測試

可把同一思路分別在 Godot/UE/Unity 做 prototype，測多角色、透明物、Nanite/Deferred、陰影與 depth prepass；最重要是遮擋判定成本與畫面 popping 是否可控。

Ziva-inspired Muscle R&D：XPBD + FEM 與可重用 Tet Cage

Character Tech R&D

EA Technical Artist Shirzad Bahrami 正在做受 Ziva VFX 啟發的物理 muscle system，除了既有 XPBD，也加入 FEM，並測試可跨不同 muscle/fat mesh 使用的 tet cage 與 VisMesh attachment constraints。

遊戲角色意義

ANIMATION / PROCEDURAL

Spider Walker：Blender 即時程序多足步態，可 Bake 成 Action

raycast + velocity prediction 自動安排落腳點，適合生物 locomotion blocking。

Animation ★★★★☆
完整分析

Animation / Procedural Motion

Spider Walker 是 Blender 5.2 LTS 的免費 procedural animation add-on：以 raycast 找地面、依速度預測下一個落腳點，讓多足角色在 body 移動時即時生成 step sequence。

輸入 / 輸出

輸入需要 body/root bone、可獨立 pose 的 leg controller bones 與可行走 surface collection；動作確認後可直接 bake 成一般 keyframed Action，方便後續手修與 FBX pipeline。

Production 判斷

這類工具的價值在 blocking 與大量 locomotion 變體。應測斜坡、樓梯、急轉、不同腿數、速度突變與 foot penetration；若 bake 後曲線乾淨，會比完全手 K 多足步態省很多時間。

4K + alpha、本機非破壞 preview，減少角色臉與服裝貼圖反覆匯出。

Workflow ★★★★☆

Texture Iteration

StudioCats 的免費 Live Sync 工具讓 Photoshop / Clip Studio Paint 的貼圖改動即時預覽到 Unity，支援 4K + alpha，而且通訊完全在本機，原始 texture/material asset 不被破壞。

近期功能

遊戲美術價值
