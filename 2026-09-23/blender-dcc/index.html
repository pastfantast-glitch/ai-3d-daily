#06 · blender-tip

Blender Retopo 小技巧：Ctrl+右鍵連續鋪點、Relax Slide 保體積

Blender Secrets 示範更快鋪設新拓樸與整理點距的手動 retopo 流程。

Blender 技巧 ★★★★☆
完整分析

技術／流程變更

教學示範按住 Ctrl 搭配右鍵快速沿表面鋪設新頂點與邊，再用 Relax Slide 重新分布點位，重點是整理拓樸時不要把原本體積壓扁。

Production 影響

這對角色臉、布料或 AI／掃描網格的手動 cleanup 很實用，可把大量逐點操作縮成連續鋪設與局部放鬆兩個步驟。

導入測試與限制

這是操作技巧而非自動拓樸方案，品質仍取決於 edge flow 規劃；複雜關節、臉部環線與硬表面轉折仍需人工判斷。

#17 · addon

Inertia：以 Geometry Nodes 即時預測拋射、軌道與曲線運動

Blender add-on 把重力、摩擦、速度等物理運動轉成可預覽的路徑，降低手工 keyframe 計算。

外掛 ★★★☆☆
完整分析

技術／流程變更

Inertia 以 Geometry Nodes 建立 Projectile、Orbital 與 Curve 三套系統，會在 viewport 顯示即時預測軌跡，並讓使用者用 Gravity、Friction、Speed 等參數調整。

Production 影響

對道具飛行、載具軌跡與 motion design，可先用物理路徑快速得到可信基礎，再轉為動畫調整，省下大量手算與反覆試 key 的時間。

導入測試與限制

工具偏物件級物理動畫，並非完整 rigid-body solver；與碰撞、角色互動或引擎最終物理的一致性仍需要另外測試。

程序雲工具提供積雲、積雨雲、卷雲等多種雲型，並以物理尺度與 shader 建立可調天空。

Blender ★★★☆☆
完整分析

技術／流程變更

工具用 Geometry Nodes 建立多層雲系統，可控制尺寸、覆蓋與外觀，並提供多種雲型；材質以空氣與水粒子尺度為基礎，且能製作雲層動畫。

#19 · blender-tip

Procedural Sponge Modifier：用 Geometry Nodes 把任意 Mesh 轉成海綿結構

免費節點工具可調 pore size、細節與紋理，把任何模型程序化轉成多孔海綿外觀。

Blender 技巧 ★★★☆☆
完整分析

技術／流程變更

Procedural Sponge Modifier 以 Geometry Nodes 將輸入 mesh 轉為多孔結構，可調孔洞尺寸、紋理與整體細節密度，並保持程序式可修改。

Production 影響

雖然題材小，但對程序建模思路很有參考價值：把表面破碎、孔洞與密度變化封裝成 modifier，可延伸到岩石、腐蝕與風格化材質幾何。

導入測試與限制

高密度幾何可能快速增加 polygon 與記憶體成本；若用於遊戲資產，應測試 bake-to-normal、LOD 或 shader 近似方案。
