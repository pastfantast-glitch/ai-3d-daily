#08 · rigging

BGEN Picker：Blender／Maya 共用的角色控制選取介面

BGEN Picker 支援視覺控制器、滑桿、多角色 picker 與腳本按鈕，用介面降低複雜 rig 的操作成本。

綁定 ★★★★☆
完整分析

技術／流程變更

工具可拖放建立 picker 版面、加入自訂形狀與顏色、控制滑桿、腳本按鈕與快捷鍵，也支援多角色配置並可匯入匯出 picker。

Production 影響

在角色動畫製作中，picker 能把複雜 control rig 的操作入口標準化，減少動畫師搜尋 controller 與記憶命名的時間，對外包交接也更清楚。

導入測試與限制

效能與大型 production rig 的相容性目前主要來自產品描述；導入前應測試 namespace、reference、多人共用設定與版本管理。

#09 · animation

KeyPro：在 Maya Timeline 疊加音訊、Key 密度等動畫資訊

KeyPro 以多層資料顯示重做 Maya 時間軸，讓動畫師不必頻繁切面板查看關鍵幀與音訊資訊。

動畫 ★★★★☆
完整分析

技術／流程變更

KeyPro 在 Maya 原生 timeline 下方堆疊多個即時資料層，包含音訊波形與關鍵幀密度等資訊，讓動畫師在同一區域看到節奏與 key 分布。

Production 影響

這類 timeline 擴充對 cutscene、lip sync 與密集 key 調整特別有價值，可減少開關 Graph Editor 或音訊工具的操作切換。

導入測試與限制

目前功能資訊偏產品展示，尚缺大型場景與長鏡頭的效能數據；要先驗證高 key 數、reference rig 與團隊 Maya 版本相容性。

#10 · rigging

Mutant Tools 肌肉 Rig 原型：以 ribbons 與 block-based rig 組合變形

Maya 肌肉 rig WIP 使用 ribbons 與 Mutant Tools 的模組化 rigging framework 建立可重用結構。

綁定 ★★★★☆
完整分析

技術／流程變更

示範以 ribbon 系統配合 Mutant Tools 的 block-based rigging 結構建立肌肉變形，目的在把肌肉控制拆成可重複配置的 rig 元件。

Production 影響

導入測試與限制

目前仍是 WIP 示範，沒有完整 deformation benchmark、skin cluster 成本或遊戲引擎輸出驗證；導入前應先測試性能與 bake 流程。

#11 · animation

Motion Painter：直接在 Blender Viewport 畫路徑生成可編輯 Keyframe

Motion Painter 把手繪路徑轉成 Blender 標準 location／rotation 關鍵幀，提供 Follow、Orbit、Wave 等筆刷。

動畫 ★★★★☆
完整分析

技術／流程變更

使用者在 viewport 畫出 motion path 後，工具把筆畫轉成可編輯的 Blender location／rotation keyframes，並提供直線、多段線、橡皮擦與多種運動筆刷。

Production 影響

對 previs、物件飛行、鏡頭 blocking 或 stylized motion 很有效，因為創作者可以先用路徑思考運動，再回到標準 keyframe 做精修。

導入測試與限制

它不是角色 body mechanics 解算器，路徑轉 key 後仍要處理 timing、碰撞與弧線品質；複雜旋轉與角色骨架需要另外驗證。
