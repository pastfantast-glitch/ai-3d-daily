Plasticity 2026.2 加入資產庫、曲率分析與 Studio 曲面約束

Plasticity 2026.2 可把零件整理成可分享資產庫，新增三種模式的曲率分析與 Project Align；Studio 版另提供維持 G0、G1、G2 連續性的曲面約束。

場景製作 ★★★★★
完整分析

曲面建模技術更新

Project Align 可沿目標曲面邊緣、依向量或法線排列控制點；曲率分析則用 Gaussian、Mean、Max 三種模式檢查不同表面問題。

重複零件的製作影響

新的 Assets 系統可把元件組成可拖入視窗的共享資產庫，對螺栓等機械零件的重複配置與團隊共用更直接。

版本限制與導入驗證

曲面約束只在 Studio 版提供；正式導入前也應核對 Windows 10、Ubuntu 22.04、macOS 12 以上的系統需求與授權方案。

#03 · production-workflow

老藤籃道具完整流程：模組化編織、實物掃描與六組 4K UV

Shubham Vijay 拆解老藤籃道具：先研究編織結構，再以可平鋪模組塑形，並整合 RealityScan、ZBrush、Maya、Substance 3D Painter 與 Marmoset Toolbag。

製作流程 ★★★★☆
完整分析

建模與掃描技術流程

藤條先拆成水平、垂直與斜向模組，平鋪後用 Lattice 塑成籃體；實物枝條則經 RealityScan 重建、ZBrush 清理與 Maya 拓樸。

材質製作影響

六組 4K UV 透過重複物件疊放維持紋理密度，烘焙法線、AO 與曲率後，再以高度、粗糙度、灰塵及日曬褪色建立使用痕跡。

限制與交付判斷

作者為最終展示保留較高面數，且坦言反覆微調增加工時；因此這套配置適合展示資產，不代表已針對即時效能最佳化，也未提供遊戲引擎效能數據。
