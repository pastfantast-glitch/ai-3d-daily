01
AI 3D● 高優先官方

Meshy 7：多視圖幾何與貼圖參考正式分離

一句話：幾何參考與 Texture Reference 不必再綁在同一組圖片，AI 3D 開始更接近真正的遊戲資產工作流。

Production ★★★☆☆節省時間 高學習成本 低
完整分析

更新內容

Meshy 7 已進入 API，並加入可分別指定幾何參考與貼圖參考的流程。你可以用正、側、背視圖控制 Silhouette 與比例，再用另外的彩色設定圖或材質 Render 控制 Texture，避免過去同一套圖片同時負責形體與材質造成的污染。

對 3D 美術的影響

最直接受益的是角色裝備、武器、載具與場景 Prop。合理流程會變成「四視圖 → Geometry、彩色設定 → Texture、AI 生成 → Blender / Max Cleanup → Unity / Unreal」。它更適合作為 Blockout 或 High-poly 起點，而不是 Final Asset。

20 分鐘實測

拿一個你已有標準答案的 Prop：四視圖控制 Geometry、2–3 張配色圖控制 Texture。生成後只檢查 Silhouette、洞口、硬表面轉角、UV 與 Cleanup 時間，再和人工 Blockout 比較。

UNREAL● 高優先官方

Unreal Engine 5.8：PCG、Mesh Terrain 與大型場景流程持續成熟

一句話：這版對 Environment Artist 的價值，在於程序化場景、植被、Terrain 與 Shader 效能開始一起往 Production 靠攏。

大型場景 ★★★★★導入成本 中～高節省擺設 高
完整分析

5.8 強化大型世界、PCG、Mesh Terrain、植被與 Shader 效率。場景美術的工作會更偏向 Modular Kit、Variations、規則與 PCG Input，而不是逐顆擺放。Mesh Terrain 仍建議先測試，不要立即當成唯一正式地形方案。

20 分鐘實測

複製一個現有 Level，以 2–3 種 Prop 做 PCG Scatter，和人工擺設比較控制力、花費時間，再用 Shader Complexity / Stat GPU 看成本。

Unity AI：從聊天工具走向能理解 Project Context 的 Agent

一句話：真正值得美術關注的是它能讀 Scene、GameObject、Component 與 Project Context，而不只是幫你寫 C#。

美術 QA ★★★★★Production ★★★☆☆風險 自動修改資產
完整分析

如果 Agent 能穩定理解 Project Context，它最有價值的用法可能是找錯誤 Texture Import、Material、LOD、Renderer 與 Prefab，而不是直接生成遊戲內容。正式專案應先從只讀分析開始。

20 分鐘實測

要求它「分析目前 Scene 所有 Mesh Renderer、Material、Texture、LOD，列出 10 個可能影響效能或美術一致性的問題，但不要修改」。

BLENDER官方

Blender 5.2 LTS：適合作為長期 Production Pipeline 的基準版本

一句話：團隊使用 LTS 的價值不是新功能最多，而是版本與插件相容性更容易固定。

穩定度 ★★★★★團隊基準 ★★★★★外掛風險 中
完整分析

如果要把 Blender 正式納入 Max / Maya 團隊，固定 LTS 能降低插件、Python API 與檔案版本變動帶來的維護成本。先驗證 FBX、Rig、Material Slot 與常用外掛再推到全團隊。

20 分鐘實測

跑一個真實資產的 Max → Blender 5.2 → Unity / Unreal，只檢查 Scale、Axis、Normal、UV、Material Slot、Pivot 與 Skeleton / Root。
