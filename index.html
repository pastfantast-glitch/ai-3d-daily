重建克麗奧佩脫拉神殿：模組建築、馬賽克材質與三種時段照明

Sungeun Moon 以《刺客教條：起源》的神殿為參考，拆分可重用建築、在 Substance 3D Designer 製作馬賽克，再於 Unreal Engine 調整日間、夕陽與夜景。

Unreal ★★★★★
完整分析

場景流程：先拆模組再安排紋理

作者先用方塊與圓柱建立空間，放入預設角色確認比例，再從遊戲截圖規劃柱體分件、可平鋪牆地面與飾條貼圖；常春藤也拆成可重用片段，配合建築形狀重新擺放。

製作控制：先驗證貼圖空間分配

飾條貼圖先用照片排出粗略配置，套到模型檢查裝飾細節是否清楚，再調整各區解析度；馬賽克以基本形狀搭配 SVG 建立圖案，Gradient Map 依灰階分配顏色。

驗證方法：分開比較直射光與陰影

作者在 Photoshop 取樣參考色彩，分別調整 Directional Light 與 Sky Light，並以大氣散射處理不同時段天空；後製主要統整色彩。作品歷時約六個月且在下班後製作，不能把工期當作全職製作基準。

mPainter 0.9.0 alpha：沿用 Blender 材質的多通道貼圖繪製工具

來源日期 2026-11-12

mPainter 是從 Blender 分支開發的貼圖繪製軟體，使用專屬 Qt 介面與筆刷引擎，支援圖層、遮罩、UDIM 及程序材質匯入；目前仍為早期 alpha。

Blender ★★★★☆
完整分析

貼圖技術：多通道與遮罩共同編輯

在 3D 或 UV 視窗可同時繪製基礎色、粗糙度、金屬度、法線與高度；圖層、填色層和資料夾提供非破壞編輯，遮罩生成器可利用曲率、AO、位置及世界法線。

製作輸出：程序材質接上貼圖檔案

Blender 節點材質可作為 Material Presets 匯入，圖層資料夾也能存成預設；另支援多貼圖組、UDIM 與快取，讀入 OBJ、FBX、ABC、USD、GLB 後輸出 PNG 或 EXR 貼圖。

成熟度限制：alpha 與素材需分別準備

介紹提醒個人開發的 alpha 仍有錯誤、崩潰和未完成功能，應以自己的模型驗證並常存檔；軟體未附材質庫，原始碼可自行編譯，預先編譯的發行版則另外販售。

SculptForge：整合雕刻、拓樸與貼圖的開源工具，AI 功能另有依賴

來源日期 2026-11-12

SculptForge 的介紹涵蓋獨立雕刻、四邊面重拓樸、UV、PBR 繪製與烘焙，並提供 Blender、Maya 和 Unreal 連接；產品仍處於早期發行階段。

製作案例 ★★★★☆
完整分析

模型流程：重拓樸後重新投射細節

軟體列出多層細分、動態拓樸和雕刻圖層，可用 Quad Remesh 產生以四邊面為主的網格，再以 Project Detail 投回細節；UV 接縫、UDIM、PBR 圖層與多種烘焙輸出承接表面製作。

製作整合：既有物件更新與 LOD 輸出

介紹稱 Blender 橋接可更新既有物件並保留變換、材質及修改器，另有 Maya 傳輸工具；可製作不同減面程度的 LOD，Send to Unreal 則將資產傳入已開啟的編輯器。

導入限制：AI 和引擎連線有額外條件

一般雕刻可離線，但 AI 生成的額度與條款依模型或服務而定，不能因本體免費就推定生成無限制；3DGS 處理需要 PC GPU 及外部工具，Unreal 直接傳送也須設定 Python 外掛與遠端執行。
