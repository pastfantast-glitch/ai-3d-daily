01
AI 3D● 高優先官方

Meshy 7：多視圖幾何與貼圖參考正式分離

一句話：幾何參考與 Texture Reference 不必再綁在同一組圖片，AI 3D 開始更接近真正的遊戲資產工作流。

Production ★★★☆☆節省時間 高學習成本 低
完整分析

更新內容

Meshy 7 已進入 API，並加入可分別指定幾何參考與貼圖參考的流程。你可以用正、側、背視圖控制 Silhouette 與比例，再用另外的彩色設定圖或材質 Render 控制 Texture，避免過去同一套圖片同時負責形體與材質造成的污染。

對 3D 美術的影響

最直接受益的是角色裝備、武器、載具與場景 Prop。合理流程會變成「四視圖 → Geometry、彩色設定 → Texture、AI 生成 → Blender / Max Cleanup → Unity / Unreal」。它更適合作為 Blockout 或 High-poly 起點，而不是 Final Asset。

20 分鐘實測

拿一個你已有標準答案的 Prop：四視圖控制 Geometry、2–3 張配色圖控制 Texture。生成後只檢查 Silhouette、洞口、硬表面轉角、UV 與 Cleanup 時間，再和人工 Blockout 比較。

複製一個現有 Level，以 2–3 種 Prop 做 PCG Scatter，和人工擺設比較控制力、花費時間，再用 Shader Complexity / Stat GPU 看成本。

Meshy 7：Geometry 與 Texture Reference 分離，真正影響的是可控性

一句話：AI 3D 不再只追求一次生成的視覺品質，而是開始允許美術用不同資料分別控制形體與材質。

角色/Prop ★★★★★Production ★★★☆☆Cleanup 仍必要

更新內容

WORKFLOW

Tripo 類工具的真正競爭點：Smart Export、DCC Bridge、Texture 與後處理

一句話：2026 年評估 AI 3D 工具，不能只看 Turntable，而要看它能不能順利進 Blender / Max / Unity / Unreal。

工作流價值 ★★★★☆節省時間 中～高關鍵 Export / UV / Topology
完整分析

當生成品質逐漸接近時，真正拉開差距的是匯出、分件、材質、拓撲、Rig、DCC Bridge 與遊戲引擎整合。對 Production 來說，少 30 分鐘 Cleanup 通常比 Demo 多 10% 細節更有價值。

實測方法

同一份參考圖在兩個 AI 3D 工具各生成一次，再進 Blender 檢查命名、分件、UV、材質數量、法線、Polycount 與可編輯性，最後輸出 Unity / Unreal。

團隊導入 ★★★★★穩定性 高遷移成本 中
完整分析

對從 3ds Max / Maya 轉 Blender 的團隊，最大風險常不是操作學不會，而是每個人版本不同、插件不一致、FBX 設定不統一。LTS 很適合當統一基準，再把 Export Preset、Addon 清單與 Scene Units 寫進 SOP。

實測方法

挑角色與場景各一個正式資產，用 5.2 LTS 跑完整 Import / Edit / Export，檢查 Scale、Axis、Normal、Material Slot、UV、Skin、Morph 與 Root。

UNITY AIOpen Beta

Unity AI：對美術最有潛力的不是生成內容，而是 Project-aware QA

一句話：能理解 Scene 與 Project Context 的 Agent，未來可能直接幫美術找出 LOD、Texture、Material、Renderer 與 Prefab 問題。

美術 QA ★★★★★正式導入 ★★★☆☆建議 先只讀

先用只讀方式，要求 Agent 對既有場景做資產 QA 報告，不允許修改。觀察它能否指出你已知的問題與假陽性比例。

UNREAL

UE 5.8：PCG 與 Mesh Terrain 讓 Environment Artist 更接近規則導向工作

一句話：場景美術會逐漸從「逐顆擺物件」轉成「建立 Modular Kit、規則與 Variations」。

Environment ★★★★★TA 協作 高導入成本 中～高
完整分析

PCG 能把植被、碎石、道路周邊資產與大規模分布自動化，但要得到好的視覺結果，仍需要美術設計規則、Variation、Seed、密度與 Art Direction 例外。

3D 美術 Production / Workflow

今日趨勢：AI Asset Cleanup 正在從「額外整理」變成一套新的 Production Skill。

AI → DCC

AI 生成不是終點：真正可用的流程仍是 Generate → Cleanup → Engine

一句話：目前 AI 最能節省的是前段探索與初模時間，Retopo、UV、Bake、材質、Rig 與 Engine 驗證仍是核心。

前段加速 高後段人工 仍高適用 Prop / Blockout
完整分析

一個 AI 模型要進遊戲，至少還要經過幾何清理、拓撲、UV、材質壓縮、Pivot / Naming、碰撞、LOD、Rig 或 Animation 測試。Production 能不能省時間，要看整條流程，不是生成本身。

適合誰看

角色美術、場景美術、TA、外包管理、負責建立 AI SOP 的主管。

實測方法

記錄每一步分鐘數：Generate、Cleanup、Retopo、UV、Texture、Import、Fix。連續測 5 個資產後，再決定是否值得正式採用。

ENVIRONMENT

程序化場景增加後，美術價值會從「擺得快」轉向「規則設計得好」

一句話：當 PCG 幫你自動分布，真正決定品質的是 Modular Kit、Variation 與 Art Direction 規則。

場景效率 高學習成本 中TA 需求 上升
完整分析

Environment Artist 未來會更常需要理解 Density、Mask、Slope、Biome、Seed、Rule Override 等概念。這不代表傳統場景美術消失，而是從「手動重複操作」移向「建立可重複使用的視覺規則」。
