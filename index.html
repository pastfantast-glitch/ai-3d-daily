CHARACTER / NPRDISCOVERED · 08/12

Serie 角色案例：Blender 角色如何做出接近 2D 繪畫的質感

Mani Salguero 分享 ZBrush、Blender、Substance Painter 的角色流程，重點是用數位繪畫式貼圖與改良 shader 壓低 3D 感，而不是單靠 Toon Ramp。

NPR 價值 ★★★★★角色 高可複製性 中高
完整分析

視覺目標與關鍵決策

這個案例要解決的不是「做一個 Toon Shader」，而是讓 3D 角色在最終畫面讀起來接近數位繪畫。作者因此把 silhouette 與正面吸引力放在嚴格的三維比例之前；後腦與側面的比例調整必須服務主要觀看角度，而不是反過來讓幾何正確性破壞 2D 感。

Production 流程

做法先從形體與 silhouette 建立，再把 2D 感分散到 Hair、UV、Texture 與 Shader。髮型改用 single-sided planes 並配合 Backface Culling，避免內部體積干擾平面化輪廓；UV 則把臉與視覺焦點的低變形、texel density 放在優先位置，案例約使用 6 個 UDIM，以支撐近距離細節與手繪處理。

為什麼這樣做

最值得複製的是「先決定 Final Look，再分配 Model／Texture／Shader 職責」。如果 Base Color 已承擔大量造型與明暗，Runtime Shader 就應保持節制；反之若希望燈光可動態改變，就不能把所有陰影都烘進貼圖。這比單純把 PBR 換成 Ramp 更接近真正 NPR Production。

限制、風險與可複製 SOP

約 6 UDIM 與高比例手繪細節較接近作品集／近景角色，不應直接當成遊戲角色預算。可抽成 SOP 的順序是：① 鎖定主要鏡頭與 silhouette；② 先測 hair plane 是否能維持 2D 輪廓；③ UV 優先保護臉與焦點；④ 明確分配哪些明暗畫進 Texture、哪些交給 Shader；⑤ 用多光向與動畫測試是否破功。適合 Character Artist、Surfacing Artist、NPR／Toon Shader Artist。

20 分鐘實測

同一角色固定鏡頭做 ① 純 PBR、② 手繪 Base Color + 簡化光照、③ 手繪 + Toon Shader 三版，再補正面／3⁄4／側面三角度檢查 silhouette，記錄哪一層最容易破壞 2D 感。

ENVIRONMENTDISCOVERED · 08/11

2D Concept → Painterly 3D World：Stylized 場景模組化與手工樹木

Angelo Ciervo 從 2D concept 拆到 modular pieces、手工樹木、材質與 Unreal 組裝，適合看 Stylized Environment 如何在畫面感與可重用資產間取平衡。

Environment ★★★★☆Modular 高可複製性 高
完整分析

視覺目標與場景拆解

這個案例的核心問題，是把 painterly 2D 村落 Concept 轉成 Unreal 場景，同時保留比例、構圖與手工感，又不能讓資產全部變成一次性 Unique Mesh。作者先在 Unreal 直接用 primitive 做 rough blockout，以畫面與尺度作為第一個驗證點，再輸出到 Blender 細分結構。

Modular Strategy 與 Production 流程

建築被拆成可管理的模組，搭配一致命名與可重用 UV／Trim 思路；大量資產採 mid-poly，並在 Unreal 與 Blender 之間反覆往返檢查。這種流程的價值是「先讓 Engine 畫面成立，再決定哪些資產值得加細節」，而不是先在 DCC 做完所有物件才第一次進引擎。

Material、植被與畫面控制

材質端以 Substance Designer 建立可重用材質與 trim sheet，利用 brush-stroke alpha、Tile Sampler 與 roughness variation 做 painterly breakup，再配合 decals、vertex painting 降低模組重複感。Landscape Master Material 使用多個可繪層與 virtual texturing／mask 控制；Outline 則透過 Custom Depth 選擇性用在前景或 silhouette 重疊處，而不是全畫面一刀切。植被也依螢幕重要度分級：遠景松樹 foliage 被簡化，避免在遠距離浪費幾何與貼圖成本。

Production 判斷、限制與 SOP

這套方法適合中大型 Stylized Environment，因為 Modular Kit 提供重用，Hero／Unique Asset 與材質 variation 再負責打破重複。主要風險是 Unique Mesh 過多、模組 silhouette 太容易被看穿、材質 variation 無上限，以及只在 Substance 裡看材質、沒有回到 Engine 判斷整體。案例約投入一個半月，因此它不是「快速招式」，而是一套完整場景迭代方法。可複製 SOP：① Engine blockout；② Module／Hero 分工＋命名；③ 共用 UV／Trim／Material；④ 依 screen importance 配置植被與細節；⑤ 回 Engine 做 composition／lighting／outline／重複感 QA。適合 Environment Artist、Level Artist、TA。

20 分鐘實測

只做 5–8 個 modular pieces，重組三個不同街角；共用同一組 trim／painterly material，檢查 silhouette 重複、接縫、variation 是否足以拉開差異。

UNREAL / SUBSTRATEDISCOVERED · 08/14

Half-Life 2 Headcrab 重製：UE5 Substrate 完整材質案例

3ds Max、ZBrush、Substance Designer／Painter 與 Unreal Engine 5 Substrate 串成完整生物資產流程，適合觀察高品質材質如何真正落到 UE。

Material ★★★★☆3ds Max 關聯 高Shader 約 3.2K instructions
完整分析

材質目標

這不是單純「做一隻 Headcrab」，而是作者刻意用生物材質測試 Unreal Substrate，補足大量教學偏向汽車／硬表面的情況。真正要解決的是皮膚、濕潤感、粗糙度與生物表面層次在 Unreal 裡如何兼顧質感與可交付成本。

Production Pipeline

流程涵蓋生物／IP 研究、反覆 Sculpt、高模與 Bake、Anatomy／Low-poly、Texture／Material、Rig／Animation，再進 UE 5.7.4 做進階 Substrate、手動 LOD、場景 Lighting／VFX／Cinematics。這比工具流水帳更有價值的地方，是每個環節都有明確 Engine Handoff，而不是最後才把展示模型丟進 Unreal。

Engine 成本與交付規格

案例公開了相當具體的成本：LOD0 約 16K triangles，一路降到 LOD5 約 44 triangles；單一 Low-poly Geometry、單一 UV Set、4K Texture，Texel Density 約 40.36 texels/cm，並包含 3 組 idle animation。Substrate Shader 約 3.2K instructions。這些數字讓它可以被當作 Production benchmark，而不只是漂亮 Render。

Production 判斷、限制與 SOP

約 3.2K instructions 顯然偏 Hero／Portfolio 級，不應直接成為所有平台的預設材質。正式專案應先定 Target Platform，再建立 Hero／Reduced Material tiers，並把 LOD、Texture Budget 與 Shader Cost 一起評估。公開摘要沒有完整曝光所有 Substrate Node 架構，因此不能憑結果反推不存在的節點細節。可複製 SOP：① 先定平台與畫面距離；② 設 Hero／Reduced 材質層級；③ 鎖定單一 UV／Texel Budget；④ 明確設定 LOD 目標；⑤ 在 polish 前先看 instruction count／GPU；⑥ 最後用動畫與不同 Lighting 驗證材質。適合 Material／Surfacing Artist、Creature Artist、TA、使用 3ds Max → UE 的美術。

CHARACTER / SURFACINGDISCOVERED · 08/19

Fungal Creature：用 Blender、ZBrush、Substance 與 UE5 組合多種有機材質

Kamil Tondera 的生物角色案例把樹皮、菌類、根系與植物組織整合成同一個可信生物。重點不是單一軟體技巧，而是從 silhouette、曲線生成、Retopo 到 hand-painted surfacing 的完整角色 Production 流程。

Character ★★★★☆Organic Surfacing 高可複製性 高
完整分析

視覺目標與問題

案例要解決的是如何把樹皮、蘑菇、根系與植物組織混成一個仍然有清楚 silhouette 的生物，而不是把很多高頻細節堆在一起。作者會反覆退遠檢查整體形體，避免有機細節把主輪廓與焦點吃掉。

Production 流程與關鍵決策

流程從簡單球體／圓柱 blockout 開始，在 ZBrush 完成高模與解剖，再利用 Blender Curve、Draw 與 BY-GEN 類工具快速建立藤蔓與組織細節；Retopo 採 ZRemesh + Blender RetopoFlow，UV 用 UVPackmaster；Substance Painter 以 mask、procedural generator、Curvature/AO 與 hand-paint 疊出多材質，再進 UE5 做最終燈光。

為什麼值得學

最有 Production 價值的是把『大形 → 中型結構 → 表面材質』分層處理。藤蔓、根系這種形狀若全靠雕刻會非常慢，用 Curve 先解決路徑與體積，再把高頻細節交給 alpha／brush／texture，能明顯降低重工。

限制與可複製 SOP

這是 Hero Creature 類案例，細節量與材質複雜度不能直接照搬到大量 NPC。可複製 SOP：① 先鎖 silhouette；② 曲線類結構先程序／Curve 化；③ Retopo 分自動與人工兩階段；④ 材質避免純色，用色相與 roughness 微變化連接不同組織；⑤ 進引擎後用單一主光先驗證形體，再補局部燈。適合 Character Artist、Creature Artist、Surfacing Artist。

20 分鐘實測

做一段樹皮＋菌類混合的小型 bust：Curve 拉出兩條根系，ZBrush 或 Blender 雕一層主體，Substance 只用 3 組 roughness/value variation 分開材質，再進引擎用單主光檢查遠近距離 readability。

BLENDER / RETOPODISCOVERED · 08/19

Quad Maker：把 Blender 手動 Retopo 做得更接近 Maya Quad Draw

Mark Kingsnorth 的 Quad Maker 提供 Add Vertices、Fill Quads、Extend Borders、Draw Quad Strip、Quick Cut 等操作，目標是把高模手動重拓撲變成更連續的單一工作流。對從 Maya／3ds Max 轉 Blender 的角色與 Prop 美術，它值得當效率工具評估。

Retopo ★★★★☆導入成本 低適合 角色 / Prop
完整分析

它解決什麼

Blender 原生可以完成 Retopo，但操作常分散在吸附、擠出、Knife、Loop Cut、Smooth 等多個工具。Quad Maker 把常用操作集中成一套偏 Quad Draw 思維的工具集，降低手在工具間切換的頻率。

Production 影響

Add Vertices、Fill Quads、Draw Quad Strip、Extend Borders 對臉部、肩胯與 hard-surface 轉折區特別有用，因為這些地方通常不是全自動 Retopo 能直接交付的區域。真正值得比較的是每 1,000 個 quad 的人工時間與修正次數。

限制與風險

它仍然是手動 Retopo 輔助，不會替你決定 deformation loop、pole 位置或 topology 語意。第三方 add-on 也需要確認 Blender 版本更新相容性，因此不能把它當成唯一 Retopo SOP。

可複製 SOP

用同一個高模資產做 A/B：A 用 Blender 原生 Shrinkwrap + Poly Build；B 用 Quad Maker。固定 15 分鐘，比較 quad 數、穿插、邊界連續性與每次改線需要的操作步數，再決定是否加入角色 SOP。

適合誰

Character Artist、Creature Artist、Prop Artist，以及從 Maya Quad Draw 或 3ds Max Graphite／Freeform 工作流轉到 Blender 的使用者。

BLENDER / TEXTUREDISCOVERED · 08/12

MatPlus 1.3：在 Blender 內做類 Substance Painter 的 Layer-Based Texture Workflow

MatPlus 把 Paint Layer、Fill Layer、Folder、Blend Mode、Mask、UDIM 與 game-ready texture export 放進 Blender，1.3 再加入 auto-cache、BeFX Library、Smart Masks 與 Display 模組。它不是 Painter 的直接替代結論，但對希望減少 DCC 往返的人很值得測。

Texturing ★★★★☆UDIM 支援引擎輸出 Unity / Unreal
完整分析

材質目標與架構

MatPlus 的核心不是新增一支畫筆，而是在 Blender 內建立非破壞式 layer stack，管理 Base Color、Roughness、Metallic、Normal、Bump 等通道，讓 Fill／Paint／Mask／Folder 的思路接近 Painter 或 Mari。

Production 收益

如果建模、UV、Lookdev 都在 Blender，最大的收益是少一次 Export → Painter → Reimport 的來回，尤其在模型拓撲與 UV 還在反覆修改的階段。多 UDIM 與 Unreal／Unity map export 讓它至少具備遊戲資產測試價值。

1.3 的實質更新

1.3 將重點放在 auto-cache、BeFX Library／Smart Masks 與 Display 模組，方向是改善大型材質堆疊的操作效率、加快起始材質建立，以及讓預覽呈現更可控。這些更新比單純新增幾個 material preset 更接近 Production usability。

限制與適用邊界

Blender 內 texturing 是否能取代 Painter，仍取決於 bake、mask generator、anchor-like workflow、資產管理、效能與團隊標準。若公司 Pipeline 已高度依賴 Substance automation，轉換成本可能比省下的 DCC 往返更高。

20 分鐘實測

拿一個 2-UDIM Prop，在 MatPlus 做 Base Color + Roughness + Metal + Normal 四通道，至少建立 1 個 Fill、1 個 Paint、1 個 Mask，再輸出 Unity／UE preset。記錄與 Painter 相同任務的切換次數、等待時間與修改 UV 後的恢復成本。
