AI 3D ★★★★☆
完整分析

技術流程：生成融入互動規則

Halls of History 以 World Labs 的 Marble 建立高斯潑濺房間，再放入 Tripo 物件；Tripo API 依對話產生不同尋寶道具，玩家組合物件解謎並開啟下一個房間。

製作影響：快速比較外殼方案

Gemtronic 將數位寵物放入智慧戒指，電子零件維持一致、外殼可替換。作者先用 Tripo 比較外形，再把選定方案送入 CAD 精修與實體製作，生成物因此扮演設計候選的角色。

成熟度限制：案例不等於量產驗證

Editable Motion Paths：在 Blender 視窗直接塑形動畫軌跡與節奏

來源日期 2026-11-11

Editable Motion Paths 將骨骼或物件動畫顯示為可編輯曲線，關鍵影格成為點、切線成為貝茲把手，修改後即時更新 F 曲線；工具支援 Blender 4.4 以上。

Blender ★★★★☆
完整分析

動畫技術：沿可見路徑直接編輯

外掛把關鍵影格與貝茲把手放在動畫路徑上，可用吸附、擠出、切割及倒角等熟悉操作改變動作；底層 F 曲線會即時更新，也支援多骨骼與世界、局部或攝影機空間。

製作控制：形狀與時間分開調整

每幀圓點呈現間距，速度圖與時間圖可拖曳，雕刻筆刷則分別調整路徑形狀或快慢；角色洋蔥皮、速度色彩與重心顯示提供觀察動作的輔助資訊。

驗證限制：相容宣稱有範圍

報導說工具已在 Blender Studio 的 Rain 綁定測試，並轉述開發者的可投入製作與非破壞宣稱；這不等於所有自訂約束和驅動器都經過驗證。已列出的相容基線是 Blender 4.4 以上。

歷史參考｜Maya Smart Layer 0.9：分層修正路徑、骨盆與四足動作

來源日期 2024-12-23

Maya ★★★☆☆
完整分析

技術流程：修正轉成新圖層

先把動畫控制器加入圖層、為需要的修正設定關鍵影格，再執行腳本計算新動畫圖層並按比例套用；Flexible 模式支援四足角色沿圓形或曲線路徑行走。

製作影響：保留銜接姿勢

0.9 可保留起點和終點姿勢不被彎曲，原文將其連到遊戲動作混合品質；路徑距離改變時另有自動骨盆修正，處理腿部過度伸展，並可選擇是否沿曲線保留垂直旋轉。

判斷限制：效率數字出自作者

原文把覆蓋動畫師大部分需求的說法歸於作者，沒有提供跨綁定的對照測試；曲線行走、牆面行走及旋轉濾波應視為文中展示的功能，不能推定任意角色均能免除修整。

Blender Layered Actions 設計紀錄：讓動畫編輯器依動作組織資料

來源日期 2026-11-03

Blender 於 2026 年 11 月公布 Layered Actions 工作坊結論，提議以 Action 為通道階層起點，減少共享資料重複顯示，並將 Action／Slot 管理放進動畫編輯器側欄；內容屬逐步實作的設計。

綁定 ★★★★☆
完整分析

技術設計：資料蒐集與階層分開

新的動畫過濾系統先蒐集曲線及圖層等通道並附上 Action、骨骼等中繼資料，再據此建立階層；提案以 Action 組織物件、材質等資料，避免相同共享資料在多個物件下重複。

製作影響：在動畫脈絡管理指派

工作坊希望在 Dope Sheet 與 Graph Editor 側欄直接管理 Action／Slot，並讓共用同一 Action 的多個資料區塊一起切換；另討論固定通道與自訂分組，協助動畫師集中處理相關控制器。

成熟度限制：設計不等於已交付

官方說明目前先替換動畫過濾系統，其他功能將逐步實作；顯示多層累積結果或世界空間的有效曲線，更明言尚不確定是否及何時完成。不能把工作坊列出的構想都當成現行功能。
