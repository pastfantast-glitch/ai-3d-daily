01

2D / 3D 生成式 AI

生成品質之外，真正拉開工具差距的是 Export、Topology、UV、Texture 與 DCC Bridge。

WORKFLOW持續追蹤

Tripo 類工具：競爭點轉向 DCC Bridge 與後處理

生成品質接近後，Export、UV、Topology 與 Texture 整理時間更直接決定 Production 價值。

工作流價值 ★★★★☆節省時間 中～高關鍵 Export / UV / Topology
完整分析

當生成品質逐漸接近時，真正拉開差距的是匯出、分件、材質、拓撲、Rig、DCC Bridge 與遊戲引擎整合。對 Production 來說，少 30 分鐘 Cleanup 通常比 Demo 多 10% 細節更有價值。

實測方法

同一份參考圖在兩個 AI 3D 工具各生成一次，再進 Blender 檢查命名、分件、UV、材質數量、法線、Polycount 與可編輯性，最後輸出 Unity / Unreal。

02

3D 美術工具 / 軟體

成熟 Pipeline 的升級決策，穩定性與相容性通常比新增功能更重要。

3DS MAX持續追蹤

3ds Max 更新：升級先看 Plugin 與 FBX 相容

成熟 Pipeline 應先驗證 Skin、Morph、Material 與常用外掛，再決定是否全員升級。

升級急迫性 低～中風險 Plugin先測 FBX / Skin
完整分析

正式 Production 不建議只因小版本更新就全員升級。先建立測試檔，涵蓋 Skin、Morph、材質、USD / FBX、MaxScript 與常用插件，確認輸出引擎後沒有差異，再決定是否推廣。

適合誰看

角色美術 Lead、場景 Lead、TA、Pipeline TD，以及負責團隊版本管理的人。

03

3D Production / Workflow

真正要算的是 Generate 到 Engine 可用的總時間，以及規則化場景的控制成本。

AI → DCC持續追蹤

AI 3D Production：真正要算 Generate → Cleanup → Engine

AI 可加速前段，但 Retopo、UV、LOD、Collision 與引擎整理仍決定資產是否真的省時間。

前段加速 高後段人工 仍高適用 Prop / Blockout
完整分析

一個 AI 模型要進遊戲，至少還要經過幾何清理、拓撲、UV、材質壓縮、Pivot / Naming、碰撞、LOD、Rig 或 Animation 測試。Production 能不能省時間，要看整條流程，不是生成本身。

適合誰看

角色美術、場景美術、TA、外包管理、負責建立 AI SOP 的主管。

實測方法

記錄每一步分鐘數：Generate、Cleanup、Retopo、UV、Texture、Import、Fix。連續測 5 個資產後，再決定是否值得正式採用。

ENVIRONMENT持續追蹤

程序化場景：美術價值轉向規則與 Variation 設計

PCG 能減少重複擺設，但 Modular Kit、Density、Mask 與視覺節奏仍需要美術判斷。

場景效率 高學習成本 中TA 需求 上升
完整分析

Environment Artist 未來會更常需要理解 Density、Mask、Slope、Biome、Seed、Rule Override 等概念。這不代表傳統場景美術消失，而是從「手動重複操作」移向「建立可重複使用的視覺規則」。

04

美術 / 遊戲產業

觀察職能如何被技術化與重新組合，比只追單一公司新聞更有長期價值。

INDUSTRY持續追蹤

3D Artist 職務技術化：Engine、Procedural 與 TA 邊界變模糊

角色與場景美術愈來愈需要理解 Engine、Optimization、Procedural 與 Pipeline。

職涯影響 高TA 價值 上升純執行型工作 風險較高
完整分析

AI、PCG 與更複雜的即時引擎工具都在把傳統「角色 / 場景 / TA」的邊界打散。對個人職涯而言，最值得投資的是跨一層能力：角色懂 Engine、場景懂 PCG、建模懂材質與效能、Lead 懂 Pipeline。

適合誰看

3D Artist、Lead、TA、外包主管與需要規劃團隊技能的人。

本週可做

把目前技能表列出「DCC、Engine、Shader、Automation、AI」五欄，找出最弱的一欄，安排一個 30 分鐘實作而不是只看教學。
