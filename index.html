AI 3DDISCOVERED · 08/03

Hunyuan3D-Buffalo 1.0：把理解、生成、編輯與部件生成放進同一模型

這不是單純提高單次生成品質，而是把 3D understanding、text-to-3D、instruction editing 與 text-grounded part generation 統一。對 Production 更重要的是「生成後繼續改」的方向。

Production ★★★★☆可編輯性 高潛力成熟度 研究階段
完整分析

事件與影響

Buffalo 1.0 以 Hunyuan3D-VLM 做語意、結構與空間理解，再以 DiT 做生成；編輯與 part generation 會參考來源物件以盡量保留未修改區域。這種架構比一次性 text-to-3D 更接近美術反覆修改資產的工作方式。

Production 判斷

目前最值得追蹤的是 instruction editing 與 part-level generation 能否穩定維持 silhouette、UV／材質與未修改區域。論文結果不能直接等同 game-ready，因此先視為高潛力研究技術。

適合與實測

適合 AI Pipeline、TA、角色／Prop R&D。若取得可用版本，用同一資產做三次局部修改，檢查未修改區域漂移量，而不是只比較第一次生成。

UNITYDISCOVERED · 02/23

Unity 2026 Render Pipeline 策略：新專案明確往 URP 集中

Unity 已把 Built-In Render Pipeline 的棄用路線、HDRP 維護方向與 URP 的未來投資講清楚。這對新專案 Shader／NPR 技術選型比單一版本功能更重要。

新專案 URP 優先Built-In 6.5 起 Deprecated影響 ★★★★★
完整分析

事件與影響

Unity 將主要創新集中到 URP；HDRP 以穩定與平台支援為主；Built-In 在 6.5 開始標記 deprecated，至少仍會存在到 6.7 LTS。URP 規劃包含更完整的動態 3D lighting、physical sky、SSR 與 real-time GI 等方向。

Production 判斷

新遊戲尤其是 Stylized／Toon 專案，不宜再把 Built-In 當長期基準。既有 Built-In 專案則不必急遷，應先盤點 custom shader、GrabPass、Renderer Feature 替代方案與 migration cost。

適合與實測

適合 Unity TA、Shader Artist、Lead。可拿現有一個 Toon Material 在 URP 建最小 migration prototype，檢查主光、Ramp、Outline、透明與 Renderer Feature。

CHARACTER / NPRDISCOVERED · 08/12

Serie 角色案例：Blender 角色如何做出接近 2D 繪畫的質感

Senior Character Artist Mani Salguero 分享 ZBrush、Blender、Substance Painter 的角色流程，重點是用數位繪畫式貼圖與改良 shader 壓低 3D 感，而不是單靠 Toon Ramp。

NPR 價值 ★★★★★角色 高可複製性 中高
完整分析

核心技巧

案例把造型、手繪 texture 與 shader 視為同一套視覺系統。對 NPR 角色尤其重要：如果 Base Color 已經承擔大量形體與明暗設計，Shader 就不需要再用寫實 PBR 光照把那些設計破壞掉。

Production 判斷

可複製的是「先定義 2D 最終畫面，再反推模型、貼圖與 shader 各負責什麼」，而不是照抄單一節點。正式遊戲仍要額外驗證不同光向、動畫與多場景的一致性。

Visual Evidence QA

原先使用的是整篇來源頁截圖，不是可確認的 Final Render，因此本次依新規格移除。待能取得並確認屬於此案例的 Final Result／作者作品圖時才恢復 Preview。

3 步實測

同一角色做 ① 純 PBR、② 手繪 Base Color + 簡化光照、③ 手繪 + Toon shader 三版；固定攝影機比較臉部陰影穩定度與輪廓。

ENVIRONMENTDISCOVERED · 08/11

2D Concept → Painterly 3D World：Stylized 場景的模組化與手工樹木流程

Angelo Ciervo 的案例從 2D concept 拆到 modular pieces、手工樹木、材質與 Unreal 組裝，適合拿來看 Stylized Environment 如何在「畫面感」與可重用資產之間取平衡。

Environment ★★★★☆Modular 高可複製性 高
完整分析

可複製流程

① 先從 concept 拆大型／中型形狀；② 建 modular kit；③ 樹木等英雄資產保留手工特色；④ Substance 系列建立 stylized material；⑤ Unreal 中以 composition 與 lighting 統一畫面。

Production 判斷

這種方法比每個物件都獨立雕到很細更適合遊戲場景。風險是 modular repetition 太明顯，因此 variation 應集中在 silhouette、植被與材質破損，而不是無限制增加 unique mesh。

Visual Evidence QA

原先的來源頁截圖包含文章 UI，不能視為 Final Environment Shot，因此本次移除。只有確認到案例最終場景畫面後才重新顯示。

適合誰

Environment Artist、Level Artist、Stylized Art Lead。可用一個小街角只做 5–8 個 modular pieces，測試能否重組出三個不重複構圖。
