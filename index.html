02

Production / Workflow

今天最值得複製的場景思路是「Spline → Segment → MeshData → Streaming」。

ENVIRONMENTNEW

把長距離場景資產做成資料導向工具

道路、河流、管線、電纜都可把 authoring 與 runtime generation 分開，讓美術專注路徑與變化，系統處理 mesh 與效能。

03

角色 / 場景案例

角色面是程序多足 locomotion；場景面是 spline river 分層。

ROLE

Root Motion → 預估落點 → Ground Trace → Bake

適合把 Creature 第一版步態自動化，再把最後 timing、overlap 與 secondary motion 留給 Animator。

ENVIRONMENT

Spline → 分段 Mesh → UV Flow → Terrain / VFX / Audio

比單一巨大 mesh 更適合 Open World，也更容易做 streaming 與局部重建。

04

Blender Tips

今天的 SOP 概念：程序系統先保持 Live，確認後才 Bake。

BLENDER 5.2

不要過早 Bake 程序動畫

Controller 與 Deform Bone 分離、先調 solver 與 collision、確認循環後 Bake，再用 Graph Editor Cleanup；概念接近 3ds Max 先保留 procedural controller 再 Collapse。

今天值得實測

控制在約 20 分鐘內，可直接判斷是否值得進下一步。

01 · TRIPOP2.0 Quad Test

拿已有人工 Low-poly 的人形／生物，只看肩、胯、膝、pole、UV seam 與 Subdivision，判斷能否少做至少一半 Retopo。

02 · MESHYTotal Cleanup Time

同一 Prop 做 Meshy 7 與 Smart Topology，計時 Generate、Cleanup、UV、Material、Pivot、Engine import。

03 · BLENDERSpider Walker 斜坡測試

4 足 rig 在平地、15° 斜坡、小階梯各走一次再 Bake，觀察腳滑、腿交叉與曲線密度。
