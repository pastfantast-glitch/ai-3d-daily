UNITY / GINEW · 08/19

Unity Surface Cache GI Preview：URP 即時 GI 的可測版本持續推進

Unity 官方討論串近期揭露了 Surface Cache GI 的一批實質改善，包括 emissive triangle importance sampling、Rendering Layer Mask 過濾等；部分改善已進最新公開 Alpha 6000.7.0a4。對 URP 場景與 Stylized Lighting，這比單純「未來會有 GI」更接近可實測狀態。

Lighting ★★★★★成熟度 Preview先測 Emissive / 室內反彈
完整分析

事件與影響

官方開發者指出新版改善了 emissive triangles 的取樣，並支援以 Rendering Layer Mask 排除不應參與 GI 的物件；討論中並確認多項改善已可在 Unity 6000.7.0a4 測試。這代表 URP 的即時 GI 已從概念展示逐步進入可建立專案基準的階段。

Production 判斷

目前仍是 Preview，且 XR 尚未支援，因此不適合立即成為正式專案唯一 GI 方案。但對室內、間接光明顯、或需要 emissive mesh 影響環境的場景，已值得建立 A/B 測試。

Visual Evidence

來源串內有 Before／After screencap，但目前執行環境無法可靠做網頁元素級 Targeted Screenshot，因此依規格不使用整頁截圖。

20 分鐘實測

在 6000.7.0a4 建一個小室內，用一個高亮 emissive mesh 與一般 direct light 分別照明，觀察 bounce、漏光、穩定度與 GPU 成本。
