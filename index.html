AI 3D★★★★★

Meshy 7：多視圖幾何與貼圖參考正式分離

01

一句話結論：這項更新開始解決 AI 3D 最常見的控制問題之一：幾何參考與材質參考不必再綁在同一組圖片裡。

事件 / 更新內容

Meshy 7 已進入 API，並加入可分別指定幾何參考與 Texture Reference 的流程。實際工作上，可以用正、側、背等多視圖控制模型 Silhouette 與比例，再用另外的彩色設定圖、材質特寫或 Render 控制貼圖。這比過去要求同一組圖片同時負責形體與材質更符合遊戲資產製作方式。

對 3D 美術的影響

角色裝備、武器、載具與 Prop 最直接受益。新的合理流程會變成「四視圖 → Geometry、彩色設定 → Texture、Meshy → Blender / Max Cleanup → Unity / Unreal」。AI 更適合當 Blockout 或 High-poly 起點，而不是一次生成 Final Asset。

20 分鐘實測

UNREAL★★★★★

Unreal Engine 5.8：大型場景與 PCG 更接近正式 Production

02

一句話結論：5.8 對場景美術的價值，在於 Mesh Terrain、PCG、植被、Lighting 與 Shader 效能開始一起成熟。

閱讀完整分析

事件 / 更新內容

UE5.8 持續強化大型世界、PCG、Mesh Terrain、植被與角色流程，同時推進 Lumen、MegaLights 與 Shader 效率。對 Environment Art 而言，Mesh Terrain 特別值得注意，因為它朝能處理洞穴、垂直懸崖與立體地形的 Mesh-based Worldbuilding 前進。

對 3D 美術的影響

場景工作會更偏向 Modular Kit、規則、Variations 與 PCG Input，而不是逐顆物件人工擺設。Environment Artist 與 TA 的工作邊界會更靠近。
