animation

Blaze AutoPose：在既有 Blender Rig 上用位置／旋轉約束快速完成姿勢

Blaze AutoPose 把 Cascadeur 類型的 auto-posing 工作流帶進 Blender，可在 viewport 放置 position、rotation、look-at constraints，再直接把結果套到既有 FK controllers；支援 Rigify、Auto-Rig Pro、Mixamo 等常見 rig。

★★★★☆
完整分析

姿勢製作流程

工具不是另建一套骨架，而是用少量空間約束求解全身姿勢並回寫既有 FK controllers，降低 blocking 階段逐骨調整成本。

Rig 相容性

已有 Rigify、Auto-Rig Pro、CloudRig、Mixamo 與 Puppet Studio preset，自訂 humanoid 也可做一次性 control mapping。

導入測試

應用既有角色測手腳接觸、look-at、重心與極端姿勢，再比較人工 blocking 的控制感與修正時間。

來源
mocap

MoCapAnything V2：單目影片直接輸出任意 Skeleton 的 BVH-ready Rotations

MoCapAnything V2 從 monocular video 直接預測 3D pose 與 animation-ready joint rotations，支援人、動物、物件與自訂 skeleton，並可帶入自己的 rigged FBX 做骨架拓樸與 reference pose 前處理。

★★★★★
完整分析

動作輸入輸出

流程直接從影片推到 joint rotations 與 BVH，不先依賴特定人體 mesh model，對非標準骨架與 creature motion 特別有研究價值。

Retarget 潛力

自訂 rigged FBX 可生成 skeleton topology、joint-name embedding 與 reference poses，讓不同骨架有機會共用同一 mocap pipeline。

驗證方式

應測 humanoid、四足與比例差異角色的 foot contact、root motion、快速轉身與 BVH 回 Blender/UE 的可用性。

來源
other-dcc

retoPoly：3ds Max 原生 Modifier Stack 內直接做 Manual Retopology

retoPoly 是新的 3ds Max native modifier，可直接在 high-res mesh 上繪製與編輯 topology，提供 contour、bridge、patch、guide、brush、mask 與 live conform，保留 Max modifier-stack 工作流。

★★★★☆
完整分析

Retopo 工作流

工具把 manual retopology 放回 modifier stack，能在不離開 3ds Max 的情況下對 high-res asset 直接拉 edge flow。

製作價值

對仍以 3ds Max 為主要建模 DCC 的團隊，可減少 ZBrush/TopoGun/Blender 間的 round-trip。

實測

用角色頭部與 hard-surface 兩類資產測 live conform、橋接、patch 與高密度參考網格效能。

來源
4d

RAGA：3DGS Avatar／Scene Interaction 的 Real-time Gaussian Ray-traced Shadows

RAGA 直接在 Gaussian space 進行 ray-traced shadow casting，不依賴 mesh reconstruction，並以 avatar proxy 穩定服裝變形時的陰影；論文報告約 50 FPS。

★★★★☆
完整分析

動態 3DGS 渲染

方法直接計算 ray-Gaussian opacity integral，讓 animated Gaussian avatar 在既有 Gaussian scene 裡能有更一致的陰影互動。

Production 潛力

若 3DGS 逐步進入 virtual production 或 real-time avatar 場景，陰影一致性是從展示走向可用 rendering pipeline 的重要缺口。

限制與測試

目前依賴 CUDA/OptiX；應先測多角色、透明衣物、快速動作與不同 Gaussian density 下的 temporal stability。
