Mixos Live Link：Blender 與瀏覽器貼圖開始雙向同步

主動物件可直接送到 Mixos，貼圖 maps 再回到同一 Blender Principled BSDF。

Quick Impact｜最值得測貼圖 round-trip 與材質重掛時間。

完整分析

Production Delta

Mixos Live Link 把 Blender → 瀏覽器貼圖 → Blender 的 round-trip 變成雙向同步：active object 可直接送進 Mixos，貼圖結果再回到同一物件的 Principled BSDF。對角色與 Prop 貼圖迭代，價值在於少掉手動 export/import 與材質重新掛接。

適用流程

適合快速 look-dev、概念材質、外包 review 前的快速改色與小型資產貼圖。Mixos 也提供離線桌面 app 執行 bake；Live Link 本身 GPL，Blender 3.6+ 可用。

限制

正式 production 仍需驗證 UDIM、大型 4K/8K texture set、色彩空間、命名規範、版本控管與 Substance Painter 既有流程的差異；付費點在檔案輸出與 Live Link push。

20 分鐘實測

拿同一個遊戲 Prop 測傳統 FBX/texture round-trip 與 Live Link，記錄建立材質、更新貼圖、重新同步三輪所需時間，再確認 normal/roughness/alpha 是否一致。

Slot Link 1.0.2：把 Blender Actions 變成更接近遊戲 Clip 的輸出單位

支援 curve animation targets，並可批次輸出 slot-linked animations 到 FBX。

Quick Impact｜Blender → UE/Unity 多動作 export 值得直接實測。

完整分析

Animation Pipeline

Slot Link 1.0.2 把 Blender Actions 當成可獨立管理的完整動畫，並可把 slot target 綁定後批次輸出 FBX。8/26 更新再加入 curve animation target 支援，對遊戲角色多動作檔管理比單純切 Action 更接近實際 export pipeline。

輸入 / 輸出

輸入是 Blender Action/Action Slots 與 rig/curve targets；輸出重點是多動畫 FBX。這不是 AI 動作生成，但它直接解決遊戲動畫從 DCC 到引擎的組織與匯出成本。

風險

需要驗證 NLA、root motion、shape key/curve target、動畫命名與 Unity/UE import 的一致性，尤其是同一 rig 多 clip 的 start/end frame 與骨架路徑。

實測

用一個角色建立 Idle/Walk/Attack 三個 Action，再加一個 curve animation target，批次輸出 FBX 並檢查 UE/Unity clip 數量、root motion 與曲線資料是否完整。

USD viewport instancing 與 spatial streaming 出現新的 upstream pipeline 訊號。

完整分析

Pipeline 訊號

Blender 8/27 Pipeline & I/O meeting 出現 Apple 工程師參與 USDkit、Spatial Preview 與 Blender 整合討論，同時 USD viewport instancing 仍在推進。這不是已發布功能，但對 USD 即時預覽與空間內容 pipeline 是值得追蹤的 upstream signal。

BH Smart Sym 1.5：局部鏡像開始保護 Custom Normals

Safe Partial Mirror、Preserve Custom Normals 與 multi-object cursor mirror 都是遊戲模型實用修正。

Quick Impact｜硬表面 Prop 的 shading / mirror cleanup 值得測。

完整分析

Modeling Delta

BH Smart Sym 1.5.0 新增 Safe Partial Mirror、Preserve Custom Normals 與 multi-object cursor mirror，直接針對遊戲模型常見的『只鏡像局部但不要吃掉鄰接面』與『硬表面 custom normals 被破壞』問題。

適用資產

最適合武器、機械 Prop、環境 kit 與角色裝甲的局部對稱修正；對已做 weighted/custom split normals 的資產特別有價值。

限制

它是 modeling convenience tool，不會替代 Mirror modifier 的可回溯性。多人協作時仍要確認所有工作站版本一致，避免 operator 行為差異。

實測

拿一個已加硬邊與 custom normals 的機械件，只選局部 bevel 後做 mirror，檢查鄰接面、normal seam 與 shading 是否保持，再比較原生 Symmetrize 的結果。

Move Engine M3 Beta：多人 Markerless Mocap 加速，hands / pose 模型同步更新

多人 take 平行求解，solver 更快，並改善重算可重現性與 tracking failure。

Quick Impact｜兩人互動、手部遮擋與 cleanup 成本最值得測。

完整分析

AI Motion Delta

Move Engine 1.9.38 的 M3 模型進入 beta，並更新 detection、pose、hands 模型；多人 take 改成平行求解並優化 solver，官方明確指出 multi-actor processing 變快。這則作為六個月補漏，比重複昨天已發布的 Rokoko 更有 registry 價值。

輸入 / 輸出 / Rig

核心輸入仍是 markerless multi-camera video capture；輸出可進後續角色 retarget pipeline。此版特別值得測 hands 與多人 take，因為模型包同步更新。

Cleanup / 穩定性

1.9.38 修正同一 take reprocess 結果不一致，讓重算具可重現性；也修正偵測到的人數少於預期時 tracking fail。仍需自己量測 foot sliding、root drift、遮擋與 hands 穩定度。

遊戲 Pipeline 實測

用兩人互動、手部有遮擋的 20 秒 take，比較舊 solver 與 M3 beta 的 processing time、手部錯誤 frame、root/foot cleanup 分鐘數，再 retarget 到遊戲 rig 驗證。

Unity 6000.5.9f1：DX12 小貼圖 VRAM 回收修正

大量小 texture 場景可重新檢查 VRAM；ML-Agents 也更新到 4.1.0。

Quick Impact｜Texture-heavy 專案可做 GPU memory A/B。

完整分析

Release 重點

Unity 6000.5.9f1 於 8/19 發布，對美術/效能比較值得注意的是 DX12 小貼圖 VRAM 回收修正，並新增可調 heap size 的 boot config；同版也更新 ML-Agents 4.1.0 與 Behavior 1.0.16。

Production 影響

限制

版本仍列出 shader warmup、lighting bake、TMPro 等 known issues；升版前要以專案自己的 GPU memory capture 與 build smoke test 決定。

UE5 摩托車系統：Rider 與 Vehicle 必須當成同一個動態系統

實際 production breakdown 說明兩輪 physics 與騎士 animation 為何不能只是視覺跟隨。

Quick Impact｜載具角色動畫、傾角與物理 coupling。

完整分析

Animation / Physics

這個 UE5 production breakdown 把摩托車與騎士視為同一個動態系統，而不是把 rider 當成附著 mesh；作者因 Chaos Vehicles 對兩輪穩定性的抽象不合需求，改寫自己的模型。

可轉用觀念

對載具角色動畫，重點是 rider mass/pose 與 vehicle physics 必須互相影響；如果動畫只做視覺跟隨，傾角、加速與碰撞時會很假。

限制

這是單一專案的自研解法，不代表 Chaos Vehicles 不適合一般產品；自寫物理會把維護、網路同步與 edge case 成本全部帶回團隊。
