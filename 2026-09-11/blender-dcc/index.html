Redshift 2026.9：Live Renderer 補上 Anisotropy／HDR Compression，Maya USD/Alembic Instancing 也擴充

Redshift 2026.9 更新 Live real-time renderer 的 anisotropy 與 HDR compression，支援 OCIO 2.5，並擴充 Maya 的 USD/Alembic proxy instancing。

其他 DCC ★★★★☆
完整分析

DCC 工作流

Redshift 2026.9 讓 Redshift Live 支援 anisotropy 與 HDR compression，使 brushed metal 等方向性高光材質能在即時 preview 中更接近最終效果；核心 renderer 同時升到 OCIO 2.5。Maya 端增加 USD/Alembic proxy instance 與 nParticles 中 USD proxy 的支援，改善大量重複資產工作流。

製作價值

對 lookdev 團隊，Live preview 能正確看到 anisotropic response 會減少材質在互動預覽與 final render 間的落差；OCIO 2.5 則有利於與現行 VFX color pipeline 對齊。USD/Alembic instancing 對大場景的價值在於更有效地重用 cache/proxy，而不是複製完整幾何。

升版 / 導入測試

挑一組髮絲或拉絲金屬、HDR highlight 與大量 USD proxy 場景，對照前版與 2026.9 的 viewport/final parity、顯存、instance 數與 color transform；並確認現有 DCC plugin、OCIO config、render farm 與 Houdini/Maya 版本相容。屬點版更新，應先在副本專案回歸再升 production baseline。
