Smart Remesh 2：AI / 掃描高密度模型開始把 UV、材質與 Retopo 一起處理

UV/UDIM、材質與 baked detail 保留，讓自動 remesh 更接近可進 production 的 cleanup 節點。

Quick Impact｜最值得拿 Meshy / Tripo 高密度 Prop 實測 cleanup 時間。

完整分析

Production 判斷

Smart Remesh 2 把 UV/UDIM、材質指派、烘焙細節保留與 Smart Cleanup 放進同一個 Blender retopology 流程，特別針對 AI 生成、掃描與高密度 kitbash 的清理成本。對遊戲美術而言，價值不只是減面，而是降低『重拓樸後還要重做 UV/材質』的返工。

適用資產

硬表面模式適合機械 Prop、建築件與 kitbash；Organic 模式則偏向雕刻與掃描。工具宣稱硬表面可保持表面頂點位置不漂移，Organic 模式可直接把細節 bake 到乾淨結果。

限制

自動 remesh 仍不能取代關節 deformation topology、特定遊戲 LOD edge flow 與手工 hero cleanup；UV 保留也需要用實際複雜 UDIM、硬邊與材質邊界驗證。

20 分鐘實測

拿同一個 Meshy/Tripo 高密度 Prop，分別跑硬表面與 Organic，記錄減面率、UV/材質是否保留、normal bake 失真與最後人工 cleanup 分鐘數。

Blender Layer V2：Blender Viewport 直接進 Krita，3D Pose → Paint-over 更順

支援 Blender 5.2 LTS / Krita 5.3+，補上透明與 Pose Library preview 等實際工作流問題。

Quick Impact｜Concept、角色造型審核與 NPR paint-over 值得測。

完整分析

Workflow 重點

Blender Layer V2 把 Blender 3D viewport 直接連到 Krita drawing layer，讓概念美術可以用 3D 模型、Pose Library 與相機構圖當底，再在 Krita 上即時繪製。對需要角色/場景快速 paint-over 的流程，比傳統截圖→貼圖→重截更順。

Production 價值

最適合 concept、keyframe、造型審核與 NPR paint-over。V2 標示支援 Blender 5.2 LTS / 4.x 與 Krita 5.3+，並修掉透明/空畫布與 Pose Library preview 問題，代表它開始接近可持續使用的橋接工具。

限制

目前資訊主要來自社群發布，正式團隊導入前仍需確認色彩管理、alpha、相機解析度、同步延遲與大型場景 viewport 性能。

實測

用一個角色 A-pose 與一個場景相機，測 3D pose/相機變更到 Krita layer 更新的延遲，再確認 paint-over 匯出回美術評審流程是否能省一次以上 round-trip。

Super Duper Batch Exporter 2.9：命名 Token 與子目錄把 Blender 批次 Export 再往 Pipeline 推一步

$OBJ / $COLL_PATH / $SCENE 等 token 可直接映射團隊命名與資料夾規則。

Quick Impact｜大量 Prop / LOD / FBX 輸出比單次 Export 更值得導入。

完整分析

Production 更新

Super Duper Batch Exporter 2.9.0 新增以 $OBJ、$COLL、$COLL_PATH、$SCENE、$BLEND、$DATE、$TIME 組合檔名與子目錄，讓批次輸出不再綁死特定 collection mode。對大量角色、Prop、LOD 與關卡模組輸出，這比單次 export UI 改進更有 production 價值。

引擎 Pipeline

工具支援 FBX、glTF、ABC、USD、OBJ 等格式；FBX 還可在 export 時用 decimate 自動建立 LOD，Unity/Unreal 可直接辨識。最值得測的是把 collection hierarchy 直接映射成專案資料夾與命名規範。

限制

自動 LOD 不等於最終美術 LOD；骨架、blendshape、material slot、pivot、socket 與自訂 exporter 設定仍需做團隊 QA。

20 分鐘實測

建立一個 10 個 Prop + 3 LOD 的測試 collection，用 token 產出完整資料夾結構，匯入 Unity/UE 檢查名稱、LOD、材質 slot 與 pivot 是否完全可重現。

Deadhand Theater：用 3D Impact Animation 取代泛用粒子，讓 VFX 服從世界觀

把 hit flash 從 generic particles 改成更像舞台機關的 3D 動畫，是很好的 stylized VFX art-direction 案例。

Quick Impact｜同一攻擊做粒子版 / 3D 動畫版，直接比 readability 與成本。

完整分析

Art Direction 判斷

Deadhand Theater 把一般粒子 hit flash 改成 3D impact animation，讓每次攻擊更像舞台上的實體表演。這個案例重要的不是特效技術本身，而是『效果語言是否服從遊戲世界觀』。

Production 啟示

對 stylized 遊戲，可把 impact 拆成 mesh deformation/flipbook/短動畫、少量粒子與音效，而不是所有技能都用相似 bloom + spark。這能提高辨識度，也更容易形成可重用的 VFX style kit。

限制

報導沒有公開性能數據與完整 UE 實作；3D impact animation 可能增加 skeletal/static mesh、draw call 與 authoring 成本，不能只看畫面效果。

實測

挑同一個攻擊做粒子版與 3D 動畫版，固定鏡頭比較 readability、GPU cost、資產重用率與一次效果製作時間，再決定哪些 attack tier 值得用高成本版本。

ZBrush / Mari / Maya / UE / Nuke 的跨工具角色流程值得轉成 look-dev SOP。

Quick Impact｜重點看大形→surfacing→lighting parity，而不是 micro detail。
