#07 · animation

Ragdoll for Web：把重力、碰撞與接觸帶進瀏覽器角色 Pose，支援 Maya／Blender .rag 資料

Ragdoll Dynamics 推出瀏覽器版 physics-based character posing，可在本機瀏覽器用重力、碰撞與接觸調整角色，並讀取 Maya／Blender 的 .rag 資料；後續 roadmap 包含 keyframe、recording 與 rigging。

動畫 ★★★★☆
完整分析

技術／流程變更

它把角色 posing 從純 FK／IK 拉桿加入物理條件，讓腳底接觸、重心、物件互動與多角色碰撞可以先由 solver 協助，再由動畫師決定姿勢；而且可從 Maya／Blender 的 Ragdoll 設定帶入瀏覽器。

Production 影響

對 blocking、姿勢探索與 review，免安裝的瀏覽器環境可降低動畫師與導演分享成本；物理輔助尤其適合重量感、跌倒、坐靠與角色接觸，不必一開始就手工修所有 contact。

導入測試與限制

目前功能仍在擴充，應先驗證 .rag 往返、骨架比例、constraint、瀏覽器效能、輸出回 DCC 的可編輯性；物理解只適合作為起點，不能取代 pose readability 與動畫節奏判斷。

#09 · animation

Blender 5.3 Animation：World-space Copy/Paste 與 Blend Copied Pose 已落地

Blender Animation & Rigging 模組 9/17 紀錄顯示 world-space copy/paste 的 frame range 與 Blend in Copied Pose 已落地，Spline IK 也加入 forward compatibility；Layered Actions 與 animation filter replacement 持續推進。

動畫 ★★★★☆
完整分析

技術／流程變更

World-space pose／animation copy 能跨控制器局部空間差異保留角色在世界中的運動意圖，這次還補到 frame range 與 blend copied pose，對 mirror 以外的 pose transfer 與 motion editing 更實用。

Production 影響

動畫師在修 root motion、跨 rig pose reuse、接觸姿勢與片段拼接時，可以少做手動補償；若 Layered Actions 後續穩定，Blender 的非破壞動畫編輯會更接近大型 production 所需。

導入測試與限制

這些變更仍在 5.3 開發線，需用自家控制 rig 測試 parent space、constraint、root motion、NLA／Layered Actions 與 undo；正式 beta 前不宜直接鎖定工作室版本。

#17 · rigging

Blender Studio Rigging Guide：CloudRig＋手工 Weight／Corrective Shape Key 的 production 分工

Blender Studio 的 rigging guide 說明以 CloudRig 產生控制 rig，再由 rigging artist 處理 weight paint、corrective shape keys 與角色特化控制；正式 production retopo 與 previs 自動拓樸也採不同嚴謹度。

綁定 ★★★★☆
完整分析

技術／流程變更

Blender Studio 並未把 auto rig 當成完整答案，而是讓 CloudRig 負責可標準化的控制結構，再由人工處理 skin weighting、corrective shape key 與角色需求；previs 與 final asset 也使用不同 mesh 品質門檻。

Production 影響

這種分工很適合遊戲角色 pipeline：自動化處理可重複骨架／控制器，變形品質則留給 rigging artist；把 rig 規格與 retopo 交付層級分開，也能讓 early animation 更早開始。

導入測試與限制

導入時要用不同體型角色驗證 CloudRig template、export skeleton、twist、corrective shape、遊戲引擎 retarget 與 animator 操作；Studio 的電影流程不能原封不動等同於 Unity／Unreal runtime rig。
