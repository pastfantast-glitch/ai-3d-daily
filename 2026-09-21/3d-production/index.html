#05 · character-production

AC9 Cloth Retopo 1.1：用 Marvelous／CLO 2D Pattern 反投影，重建服裝乾淨拓樸

免費 Blender add-on AC9 Cloth Retopo 以 CLO／Marvelous Designer 的 2D pattern 為基礎建立低模，再投影回高密度 3D 服裝；1.1 版改善 inset 等操作，適合把模擬布料轉成可烘焙、可綁定的遊戲網格。

角色製作 ★★★★★
完整分析

技術／流程變更

工具利用服裝原本的 2D pattern 作為規則拓樸來源，再把結果映射回 3D 形狀，避開直接在褶皺高模表面手工描線；這個思路特別適合 Marvelous／CLO 已有乾淨 panel 結構的衣服。

Production 影響

角色服裝常同時要求 seam 對齊、UV 可控與變形區 edge flow，若 2D pattern 能直接成為 retopo 起點，就能降低外包與角色團隊大量重複工作，並讓不同服裝保持一致密度。

導入測試與限制

測試時要挑緊身、厚外套與多層裙裝三種案例，檢查 panel seam、腋下／肩／膝變形、厚度、重疊層與 bake；自動投影不代表關節區 edge flow 一定符合 rigging 需求。

#18 · character-production

《Princess of the Lost Planet》角色拆解：AI 只做 Reference 探索，正式資產回到 ZBrush／Marvelous／TopoGun／RizomUV

Seori Nam 分享中世紀＋末日元素角色製作，AI 圖只用於早期 reference 探索；正式流程包含 ZBrush 頭身、Marvelous 服裝、TopoGun retopo、RizomUV 分組，以及 Substance／Marmoset 貼圖與展示。

角色製作 ★★★★☆
完整分析

技術／流程變更

案例把概念探索和可交付資產明確切開：AI reference 用來找方向，角色本體仍以 base mesh／ZBrush、Marvelous、TopoGun 與 RizomUV 建立，髮型則用 3ds Max hair cards，貼圖依畫面重要度分配多組 texture set。

Production 影響

這個流程對目前 AI 輔助角色製作很實用，因為它示範生成內容可以加速 visual search，但 topology、UV、材質與 hair card 仍由可控工具完成；也能避免把不可追溯的 AI mesh 直接塞進正式 pipeline。

導入測試與限制

案例是單一作者 production breakdown，效率與品質不能直接推廣到所有角色；導入時可比較純 reference 與 AI-assisted reference 在概念時間、重做率、UV／texture budget 與最終辨識度上的實際差異。

#20 · prop-production

CatPin：Blender 非破壞切件＋Pin/Socket，讓複雜道具分件與組裝間隙可重複調整

CatPin 是 Blender 的模型切分與 pin/socket 工具，可用多種 cut mode 建立連接件、設定 clearance，並以 draft 方式保留可修改性後再輸出 STL；對大型公仔／道具的分件規劃具有可轉移價值。

物件製作 ★★★☆☆
完整分析

技術／流程變更

CatPin 將 cut、pin、socket 與間隙參數化，重點是先以 draft 保持非破壞狀態，再決定最終切件；這比直接 destructive boolean 更容易在設計改動後重算接合位置。

Production 影響

對大型道具、機台外殼或需要拆件輸出的模型，參數化連接與 clearance 能減少手工對位；即使不做列印，『可重建的分件規則』也可作為高低模、展示模型或外包交付的輔助流程。

導入測試與限制

工具主要面向 3D print，遊戲資產仍需另外清 topology／UV／normal；導入時要測薄壁、曲面、非流形模型與大量 pin 的 boolean 穩定性，並確認 draft 到 final 不會產生破面。

BRIEF｜來源已驗證；證據深度較有限，完整分析會明確區分已知資訊與待驗證事項。
