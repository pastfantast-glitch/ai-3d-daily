HKTex：用 Heat Kernel 做 UV-free Surface Texture，直接處理曲面紋理連續性

HKTex 以 heat kernel 在曲面上建立紋理座標關係，目標是在不建立傳統 UV atlas 的情況下減少 seam、拉伸與 atlas 空間浪費，並支援多視角影像對表面紋理的最佳化；研究已公開程式碼。

研究 ★★★★★
完整分析

技術／流程變更

傳統 UV 將曲面切成多個 2D island 後再貼圖，天然會有 seam 與 distortion；HKTex 改以 heat kernel 描述曲面上的局部關係，讓 texture parameterization 不必先建立固定 UV atlas，研究也示範多視角 fitting。

Production 影響

如果這類方法能進入 DCC／engine tooling，掃描、生成式 3D 與複雜有機資產可能少一道昂貴的 UV 整理流程；對 AI 3D 來說尤其重要，因為生成 mesh 的拓樸與 UV 往往同時不穩定。

導入測試與限制

目前仍屬研究方法，需自行驗證 runtime sampling 成本、mipmap／anisotropic filtering、bake/export、引擎材質相容與 artist paint workflow；研究結果不能直接等同於可替代 production UV。

NeXus MPM Tech Preview：INSYDIUM 把 GPU Material Point Method 帶進 Blender／Cinema 4D

INSYDIUM 公開 NeXus MPM 技術預覽，展示以 GPU 執行 Material Point Method，讓不同材料在同一 solver 中互動，並規劃進入 Blender／Cinema 4D 的後續 beta。

研究 ★★★★☆
完整分析

技術／流程變更

MPM 將物質以粒子攜帶狀態、透過背景 grid 解算，適合雪、泥、沙、軟體等會大變形且彼此交互的材料；NeXus 的技術方向是用 GPU 把這套 solver 放進一般 DCC。

Production 影響

如果互動材料能在同一求解器內穩定運作，特效與場景團隊可以少做多個 solver 互相轉換，對破壞、地面變形與混合材質的 previs／shot iteration 都有吸引力。

導入測試與限制

目前僅為 tech preview，正式 Blender／C4D 支援版本、快取格式、記憶體、穩定性與大尺度 shot 效能仍未知；應等 beta 後用代表性雪／泥／剛體互動案例量測。
