#01 · maya

Autodesk AU 2026：3ds Max／Maya 把可編輯 Gaussian Splats 與 MotionMaker AI 動作推進 DCC 正式流程

Autodesk 在 AU 2026 展示 3ds Max 可編輯 Gaussian Splats、3ds Max／Maya 的 Arnold 原生 3DGS 渲染，以及 Maya MotionMaker 對人形、犬類與馬匹的生成式動作與可編輯曲線，方向是把新型資料與 AI 輔助直接放進既有 DCC 工作流。

Maya ★★★★★
完整分析

技術／流程變更

Autodesk 把 Gaussian Splat 從外部展示資料往 DCC 可編輯物件推進，並讓 Arnold 在 3ds Max／Maya 原生處理 3DGS；MotionMaker 也把基礎人形、犬類與馬匹動作生成後接回動畫曲線，而不是只輸出不可編輯的影片結果。

Production 影響

對使用 Maya／3ds Max 的遊戲與動畫團隊，掃描／3DGS reference、AI 輔助 blocking 與傳統 keyframe 可以留在同一套 scene、review 與 render pipeline；若 BYOD 模型能以自家 rig／動作庫訓練，長期價值會比單純通用生成更高。

導入測試與限制

目前屬於 AU 公開的新能力與方向，正式版支援矩陣、MotionMaker 對非標準 skeleton 的穩定性、曲線品質、3DGS 記憶體與 Arnold render farm 成本仍要以 production scene 實測，不能直接當成已成熟的交付基線。

#02 · addon

N-Gone Pro 2.0：Blender CAD／Boolean 高模整理改成非破壞 Prep→Low 流程

N-Gone Pro 2.0 針對 CAD、Boolean 與高密度硬表面模型加入更完整的非破壞整理流程，將 Prep 與 Low 分離，並整合程序 UV、命名與高低模準備，目標是縮短遊戲資產從髒高模到可烘焙低模的整理時間。

外掛 ★★★★★
完整分析

技術／流程變更

2.0 的核心不是單一 decimate，而是把來源模型整理、Low 建立、UV 與資產資訊拆成可回頭修改的階段；對 CAD／Boolean 模型來說，先保留原始形狀再逐步產生低模，能降低修改後整套流程重做的成本。

Production 影響

這類工具若能穩定處理平面、硬邊、命名與高低模配對，對武器、載具、機械件與 AI／掃描後的硬表面清理很有價值，尤其適合把大量手動 cleanup 轉成可重複 SOP。

導入測試與限制

應以三種資產測試：密集 CAD、Boolean 槍械與有圓角的大型機械件，逐項檢查 silhouette、hard edge、UV、bake cage、法線與回修改能力；自動結果仍需防止過度簡化或拓樸不利變形。

Blender ★★★★☆
完整分析

#11 · blender

Blender Modeling：Straight Skeleton 原型瞄準複雜 Face Inset／屋頂式拓樸

Blender Modeling 模組 9/14 討論 Straight Skeleton 原型，重點是處理一般 inset 容易自交或重疊的複雜多邊形，並傾向做成獨立 node；同時也在整理 bevel node 的底層 helper。

Blender ★★★★☆
完整分析

技術／流程變更

Straight Skeleton 可以把 polygon 邊界向內推進並保留事件拓樸，對凹多邊形、屋頂分割與複雜 inset 比單純 offset 更可靠；Blender 團隊傾向把它拆成獨立 node，讓其他工具可重用。

Production 影響

程序建築、道路、牆面 panel 與 Geometry Nodes 建模若能直接取得穩定 skeleton，可減少自交清理與自訂腳本；對大量模組化場景，比一次性手工 inset 更具 pipeline 價值。

導入測試與限制

目前仍是 prototype／設計討論，node 介面、效能與 degeneracy 行為未定；要等實作後用凹多邊形、洞、極短邊與非平面輸入驗證，不能把會議方向當成 5.3 已交付功能。

#12 · blender

Blender GPU Meshlets／PBVH 重構延後 5.4，Gaussian Splat 也同步檢查色彩標準

Blender 9/11 project update 顯示 PBVH drawing 重構延後至 5.4，未來設計會納入 meshlets 與 GPU culling；Gaussian Splat review 則持續處理色彩空間與標準問題。

Blender ★★★☆☆
完整分析

技術／流程變更

PBVH 是 sculpt／大網格 viewport 的核心資料路徑，團隊把重構目標往 meshlet 與 GPU culling 靠攏，但時程延到 5.4；同時 3DGS review 不只處理匯入，也在釐清色彩資料如何符合標準。

Production 影響

對高模雕刻、掃描與未來 GPU-driven viewport，底層 draw path 若改善會比單一 UI 功能更影響大型資產互動；3DGS 色彩標準則直接決定跨工具 reference 是否可靠。

導入測試與限制

兩者都屬進行中工程：PBVH 沒有 5.3 交付承諾，3DGS 也仍有 colorspace 風險；production 應維持現有基線，只在 daily build 做代表性大網格與 splat 色彩對照。

#13 · houdini

Houdini 22 Bake Pre-Process：在 viewport 直接修 UV seam、cage 與 ray offset

SideFX 的 Baking with Copernicus 示範 H22 Bake Pre-Process node，可在 viewport 互動式調整 UV seam、顯示 intersection、修 cage／ray-end offset，再把結果送到材質與引擎貼圖輸出。

Houdini ★★★★☆
完整分析

技術／流程變更

新的 bake pre-process 把 UV seam、交疊／穿插診斷與 cage／ray offset 拉進同一個可視化節點流程，不必先在 DCC 外猜測 bake 問題再反覆輸出；Copernicus 再接後續 texture processing。

Production 影響

對高低模烘焙與程序資產，能把『哪裡會投射錯』提前變成 viewport 可見資料，可降低 normal／AO 爆點的人工排查；如果同一 graph 能直接輸出 engine texture maps，也更適合批次與外包驗收。

導入測試與限制

應以硬表面、角色衣服與重疊零件各跑一組，檢查 seam、cage、自相交、tangent basis 與 Unity／Unreal 匯入一致性；教學案例並不代表所有複雜 mesh 都能自動修好。

#14 · houdini

Houdini 22：三種 Gaussian Splat Relighting 路徑，從快速近似到 Proxy＋Karma

SideFX 示範 H22 三種 3DGS 重打光方法：Labs Relight GSplats、把 splat rasterize 後再打光，以及投影到 proxy geometry 後交給 Karma；速度與原始外觀保真度各有取捨。

Houdini ★★★★☆
完整分析

技術／流程變更

Gaussian Splat 原本把拍攝時的光照烘在顏色裡，重新打光困難；H22 提供從直接近似 splat shading 到 rasterize／proxy geometry 的多條路徑，讓使用者依速度與品質選擇。

Production 影響

對掃描場景、virtual production 與環境 reference，能在 DCC 中重新配合 shot lighting，比只能當固定背景更實用；proxy＋Karma 也提供與既有 render pipeline 結合的方向。

導入測試與限制

SideFX 明確把這些方法定位為不同程度近似，最高保真仍受原始 capture 限制；應比較原照、直接 relight、proxy render 的色偏、陰影、SH 細節與 render cost，再決定用途。

Substance 3D Painter 12.1.5 Known Issues：重匯 Mesh、UV Seam、AMD Bake 等風險仍需列入升版測試

Adobe 9/15 更新的 Painter known-issues 列出 12.1.5 仍存在的 mesh reimport UV seam、heavy high-poly 在部分 AMD 裝置 device lost、geometry mask artifact、clone normal channel 色偏等問題，可直接轉成工作室升版 QA 清單。

Substance ★★★★☆
完整分析

技術／流程變更

這份官方清單的價值不是新功能，而是把特定 failure mode 明確化，包括重匯 mesh 後 UV seam、部分高模烘焙 GPU device lost、geometry mask 與 clone／normal channel 異常，能直接對應日常資產流程。

#19 · addon

299 Tools for Blender：把 AI／Figure Mesh 的切件、補洞與可列印檢查集中成免費工具

299 Tools for Blender 針對 AI 生成或公仔類模型的 3D print 準備，提供比例調整、自動／手動切件、補洞、backface 檢查與 clearance boolean 等功能；雖以列印為主，也涵蓋髒網格修補與分件。

外掛 ★★★☆☆
完整分析

技術／流程變更

工具把常見的列印前 mesh cleanup 做成一組 Blender 操作，包括切件、封口、背面檢查與接合間隙；對 AI 生成模型尤其有用，因為這類 mesh 常需要先修 non-manifold 與分件才能進下一階段。

Production 影響

雖然目標是 3D print，但其中 mesh integrity、cut plane、gap fill 與 clearance 的做法可轉用到需要分件的道具／公仔資產；也適合快速檢查 AI mesh 是否存在不可見幾何問題。

導入測試與限制

它不是遊戲 retopo 工具，不能因為可列印就視為 game-ready；應另外驗證 polycount、UV、normal、LOD、rigging 與 engine import。使用時也要避免 boolean cleanup 破壞原始輪廓。
