IHP for UE5.8：用 Implicit Heightfield Projection 取代固定步進 POM，無額外幾何做出更深的表面起伏

IHP 已在 UE5.8 的 Fab 發布，利用 heightfield cell traversal 取得深度表面交點，主打比固定步進 Parallax Occlusion Mapping 更有效率地表現磚縫、岩面與地表深度，並提供一般材質與 RVT 版本。

Unreal ★★★★★
完整分析

技術／流程變更

IHP 的差異在於不是用固定 ray-march 步數一直取樣高度，而是沿 heightfield cell 尋找交點，仍然不增加真正 mesh polygon，卻能讓視差深度比一般 offset／POM 更明顯，且已有 RVT 使用方向。

Production 影響

對 UE5 場景美術，牆磚、岩壁、地面裂縫與材質層次若可在不加幾何的情況下得到更穩定深度，可能降低 Nanite 幾何或 displacement 的使用量，特別適合中距離大量重複表面。

導入測試與限制

要用相同 height map 與鏡頭角度對比 POM、Nanite/displacement 與 IHP，量測 GPU 時間、近切 grazing angle、陰影／輪廓破綻、RVT 相容性與不同平台表現；它仍不能真正改變 silhouette。
