Unity 2026 Render Pipeline 策略：URP 成為新專案長期主線

Unity 將主要創新集中 URP、HDRP 轉向穩定與平台支援，Built-In 從 6.5 開始 deprecated。

新專案 URP 優先Built-In 6.5 Deprecated影響 ★★★★★
完整分析

內容：Built-In 至少保留到 6.7 LTS；URP 未來方向包含 physical lighting、dynamic sky、real-time GI、SSR 等。

影響：新 Toon／Stylized 專案的 Shader 技術基準應直接放在 URP，而不是再新增 Built-In 技術債。

限制：既有 Built-In 專案不應為了政策立刻硬遷；先盤點 GrabPass、custom shader、Renderer Feature 與平台成本。

實測：搬一個現有 Toon Material 到 URP，檢查 Ramp、Outline、透明與主光。

Serie：用 Blender、ZBrush 與手繪 Texture 壓低角色 3D 感

Mani Salguero 的角色案例把 sculpt、數位繪畫式貼圖與 shader 視為同一套 NPR 視覺系統。

NPR ★★★★★角色 高可複製 中高
完整分析

核心：先定義 2D 最終畫面，再分配模型、Base Color 與 Shader 各自負責的視覺資訊。

Production：比單純加 Toon Ramp 更值得參考，因為貼圖本身承擔形體與明暗設計，可降低不同燈光破壞角色臉部設計的機率。

限制：展示角色仍需轉成遊戲多光源、多動畫、多場景條件測試。

實測：同角色比較 PBR、手繪 Base Color + 簡化光照、手繪 + Toon Shader 三版。

2D Concept → Painterly 3D World：Stylized Environment 模組化流程
