Tripo P2.0 Preview：Native Quad 開始正面處理 AI 3D Retopo 成本

Tripo P2.0 Preview 把重點從「生成得像不像」推向「生成後能不能真的繼續做」。最大差異是 Native Quad Topology 與更高 Mesh Budget，官方直接把用途指向遊戲、Rig、Animation 與 Real-time pipeline；對 3D 美術而言，真正要驗證的是關節 edge flow，而不是只看它是不是四邊面。

更新內容

P2.0 Preview 已提供 Native Quad Topology，Mesh Budget 約可到 25K quads／50K triangles。它仍是 Preview，正式版還會繼續改善 mesh stability 與控制能力，因此目前不能把「Native Quad」直接等同人工 Retopo 品質。

Spider Walker：Blender 5.2 多足步態可先 Live 求解、最後 Bake

Roman “iltaen” Gibadullin 的免費 Spider Walker 會根據 root motion 預測 foot target、raycast 地面，再依腿序列抬腳落腳，最後可 Bake 成一般 Action。對怪物、機械蜘蛛、多足 Boss 的 locomotion first pass 很實用。

Prototype ★★★★☆正式動畫 仍需 Cleanup版本 Blender 5.2 LTS
完整分析

它比單純 IK 黏地多了一層 gait decision：依速度與方向預估下一步，再用 collision collection 找落點。Animator 可先快速得到 locomotion，再 Bake 後調 timing、body overlap 與 secondary motion。

3D 角色 / 場景實作案例與技巧

今天角色面最值得複製程序多足 locomotion；場景面則是 spline river 的資料導向生成。

ROLE

多足角色：Root Motion → 預估落點 → Ground Trace → Bake

可直接複製的步驟：獨立 leg controller、指定 root、建立 collision collection、依速度預測落腳、最後 Bake Action。最容易踩雷的是急轉彎交叉與 controller parenting。

ENVIRONMENT

Spline River：把 Geometry、Terrain、VFX、SFX 分層

先 spline 定形，再 segment mesh、流向 UV、terrain carving 與 streaming；比單一巨大 river mesh 更適合長距離 Open World。

09

Blender Tips

今天的技巧不是單一快捷鍵，而是一個值得放進 SOP 的動畫工作模式。

Blender 5.2

程序動畫先 Live、確認後再 Bake

先讓 constraint／Python／solver 產生可調整的 live result，確認 gait、spacing、ground contact 後再 Bake 成 Action。對應 3ds Max 的概念，就是先保留 procedural controller／constraint，再到最後 Collapse／Bake。

操作與限制

保留 root/controller 與 deform bones 分離；live system 只控制 controller；先調 step distance、速度、collision；循環確認後再 Bake；Bake 完另存版本，再用 Graph Editor 清理。常見錯誤是過早 Bake，或讓程序結果直接寫 deform bone。
