CHARACTER / NPRDISCOVERED · 08/12

Serie 角色案例：Blender 角色如何做出接近 2D 繪畫的質感

Mani Salguero 分享 ZBrush、Blender、Substance Painter 流程，以數位繪畫式貼圖與改良 shader 降低 3D 感。

NPR ★★★★★角色 高可複製性 中高
完整分析

視覺目標與關鍵決策

目標不是套一個 Toon Ramp，而是讓 3D portrait 保持數位繪畫式的 2D 閱讀。作者把 silhouette 與正面吸引力放在嚴格三維比例之前，尤其後腦與側面比例必須服務主要觀看角度。

Production 流程與原因

形體／silhouette 先確立，再把 2D 感分配給 Hair、UV、Texture、Shader。髮型採 single-sided planes + Backface Culling，減少體積與內部幾何干擾輪廓；UV 優先保護臉與視覺焦點，案例約 6 UDIM，以支撐近景與手繪細節。這套方法的核心是「先定 Final Look，再分配各層職責」，而不是讓 Shader 獨自承擔所有 NPR。

限制與 SOP

6 UDIM 與手繪近景品質偏作品集／特寫規格，不應直接套成 game budget。可複製 SOP：① 鎖主要鏡頭與 silhouette；② 測 hair plane；③ UV 優先焦點；④ 定義哪些明暗畫進 Texture、哪些交給 Shader；⑤ 用不同光向與動畫驗證。適合 Character、Surfacing、NPR／Toon Shader Artist。

Visual Evidence：目前沒有通過 QA 的可靠 Preview，因此不使用整頁 screenshot 或不確定替代圖。

20 分鐘實測：同一角色做純 PBR、手繪 Base Color＋簡化光照、手繪＋Toon Shader 三版，再從正面／3⁄4／側面比較 silhouette 與臉部陰影穩定度。

ENVIRONMENTDISCOVERED · 08/11

2D Concept → Painterly 3D World

從 UE blockout、Blender modular kit、Substance 材質到 Unreal composition 的完整 Stylized Environment 案例。

Environment ★★★★☆Modular 高可複製性 高
完整分析

視覺目標與 Modular Strategy

目標是把 painterly 2D concept 轉成即時 3D，同時維持構圖、比例與手工感。作者先在 Unreal 用 primitive blockout 驗證畫面，再到 Blender 拆成可管理模組；建築重用與一致命名是高資產量場景能維護的關鍵。

Material／Lighting／Engine Assembly

Substance Designer 負責可重用材質與 trim，brush-stroke alpha、Tile Sampler、roughness variation、decals、vertex paint 用來打破規律；Landscape Master Material 與選擇性 Custom Depth Outline 讓地面與前景 silhouette 能被 art-direct。植被則依 screen importance 簡化遠景 pine foliage，讓成本跟畫面價值對齊。

限制、SOP 與踩雷

風險是 unique mesh 太多、模組重複感、variation 失控，以及 DCC 內好看但 Engine 整體失衡。可複製 5 步：① UE blockout；② module／hero 分工＋命名；③ 共用 UV／trim／material；④ 依 screen importance 配置植被與細節；⑤ 回 Engine 做 composition／lighting／outline／repetition QA。案例約一個半月，不是速成技巧。適合 Environment Artist、Level Artist、TA。

Visual Evidence：目前沒有通過 QA 的可靠 Preview，因此不使用整頁 screenshot。

20 分鐘實測：用 5–8 個 modular pieces 重組三個街角，共用一組 trim／painterly material，檢查 silhouette、接縫與重複感。

UNREAL / MATERIALDISCOVERED · 08/14

Headcrab UE5 Substrate 材質案例

3ds Max → ZBrush → Substance → UE5.7.4 Substrate，並公開 LOD、UV、Texture 與 Shader 成本。

Material ★★★★☆3ds Max 高關聯Shader 約 3.2K instructions
完整分析

材質目標與架構思路

作者把生物材質當成 Substrate 教學缺口來研究，重點是皮膚、濕潤感、roughness 層次如何在 Unreal 裡成立，而不是只展示一張 final render。完整公開摘要未揭露所有 Node graph，因此不憑結果猜不存在的 Layer 架構。

Production Pipeline 與 Engine Cost

從生物／IP 研究、Sculpt、高模／Bake、Low-poly、Texture／Material、Rig／Animation，一路到 UE5.7.4 的 Substrate、手動 LOD、Lighting／VFX。公開成本包含 LOD0 約 16K triangles → LOD5 約 44 triangles、單一 Low-poly、單一 UV Set、4K Texture、約 40.36 texels/cm、3 組 idle，以及約 3.2K instructions 的 Substrate Shader。

Production 判斷、SOP 與限制

3.2K instructions 偏 Hero／Portfolio tier，不應直接當全平台 baseline。可複製 SOP：① 定 Target Platform；② 設 Hero／Reduced Material tiers；③ 鎖 UV／Texel Budget；④ 定 LOD targets；⑤ polish 前先 profile instruction／GPU；⑥ 用動畫與不同 Lighting 驗證。高品質表面要和成本一起交付，而不是最後才補 Optimization。適合 Material／Surfacing、Creature、TA 與 Max → UE 美術。

Visual Evidence：目前沒有通過 QA 的 Final Render／Engine Shot Preview，因此不使用整頁 screenshot 或錯誤作品替代。
