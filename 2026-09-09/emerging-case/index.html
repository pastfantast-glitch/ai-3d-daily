#06 · world-model

Hunyuan3D WorldClaw：Agentic 粗到細流程生成可編輯 3D Open World

WorldClaw 以規劃 agent 把文字需求拆成區域、地形、資產、材質與空間關係，再透過 Blender 與多個生成／分割模組建立可編輯場景，代表 world generation 往 production orchestration 前進。

世界模型 ★★★★☆
完整分析

技術方向

WorldClaw 採 coarse-to-fine agentic pipeline：先把 prompt 轉成結構化世界規格，再建立全域 terrain、放置 instance-level 3D assets，最後根據自己的 render 做視覺檢查與 refinement；公開資料顯示流程會協調 LLM、影像生成、SAM 3D、Hunyuan3D 與 Blender/MCP。

製作潛力

對場景美術真正有價值的不是「一句話出世界」，而是把地形、資產、材質與 placement 變成可分層控制的規格。若 instance 與 terrain 都保持可編輯，未來可能用在 blockout、世界配置提案、open-world variation 與自動化佈景，而不是只產生不可拆的 3DGS。

成熟度判斷

目前官方專案仍偏研究展示，不能把它視為現成遊戲關卡生成器。導入前要驗輸出是否有碰撞、LOD、導航、材質預算與 stable asset IDs；也要測 agent 重跑是否能只修改指定區域，而非整個世界重新生成。

#07 · 4d

R-DMesh：以參考影片驅動靜態 Mesh，直接輸出時間一致的 4D 動態網格

SIGGRAPH 2026 的 R-DMesh 可把靜態 mesh 對齊參考影片起始姿勢並生成時間一致的動態 mesh，同時支援 pose／motion retarget，程式與 checkpoint 已公開。

4D ★★★★☆
完整分析

技術方向

R-DMesh 針對靜態 mesh 與參考影片起始 pose 不一致的問題，先做 pose rectification，再以 dynamic-mesh VAE 與 rectified-flow DiT 生成整段動態網格；官方也把 pose retarget、motion retarget 與 4D generation 列為下游用途。

製作潛力

它與傳統骨架 retarget 的差別在於輸出可包含每幀幾何變化，因此對衣物、軟體變形或非標準拓樸角色有研究價值。若能穩定轉成 morph/mesh cache，可能成為 previs、特殊角色與參考動作轉換的補充工具。

成熟度判斷

目前完整流程依賴 Wan2.2-TI2V-5B、custom CUDA extensions 與 GPU 計算，示範輸出甚至以 morph animation 為主，離即時 gameplay skeleton 還有距離。測試要檢 topology identity、幀間抖動、接縫、匯出大小，以及是否能再轉成骨架或 VAT。

#08 · research

DETRAM：單一 Transformer 同時做人形 Mesh 重建、多人追蹤與 Prompt 指定人物

NVIDIA 研究 DETRAM 以持續跨幀的 query 同時完成多人偵測、human mesh recovery 與 tracking，並可用 prompt 指定人物，在 PoseTrack21、3DPW 等資料集展示競爭力。

研究 ★★★☆☆
完整分析

技術方向

DETRAM 把傳統分開的人體 detector、mesh recovery 與 tracker 收斂到同一 transformer decoder：detection query 找新人、tracking query 維持既有人物身份、prompt query 追蹤使用者指定對象，因此跨幀身份管理直接成為模型狀態。

製作潛力

對 mocap 前處理、群眾參考與影片轉 3D 的價值在於少掉獨立 detector 串接與 ID switch 修補；如果之後能輸出穩定骨架或 SMPL 類參數，可作為多演員 video-to-animation 的上游資料來源，也有利於挑選特定表演者。

成熟度判斷

目前是 ECCV 2026 研究而不是動畫商品；benchmark 的 tracking/HMR 準確率不等於可直接用於遊戲動作。實測要特別看遮擋後 identity、手腳細節、root trajectory、鏡頭切換與長序列 drift，再評估後續 retarget/cleanup 工時。
