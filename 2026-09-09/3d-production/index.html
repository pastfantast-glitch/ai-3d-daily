#10 · prop-production

印度 Bioscope 道具：用「實際接觸區」而非隨機 grunge 決定磨損

PixelDhara 的 Bioscope breakdown 從歷史研究、3ds Max high/low poly、Painter baking/texturing 到 UE5 MRQ，核心是依觸摸、保護區與積塵位置設計可信磨損。

物件製作 ★★★★★
完整分析

製作流程

流程先研究 Bioscope 的真實構造與使用方式，再以 3ds Max blockout/high-poly、低模與 UV 進 Painter baking/texturing。鏈條與膠帶用 Path Deform 沿 spline 建立，材質磨損則依「哪裡常被手摸、哪裡受保護、哪裡會積塵」分區，而不是平均撒 grunge。

流程價值

這種 usage-driven wear 對遊戲 prop 特別可轉移：同一套 smart material 若不理解使用情境，很容易把每條邊都磨亮。把接觸頻率、重力積塵與材質老化寫成檢查表，可提高 outsourcing 與內部驗收的一致性，也更容易講出資產故事。

實測

挑三件不同使用情境的 prop，先標 touch map、protected map 與 dirt accumulation zone，再與純 generator 版本盲測；比較視覺可信度、手工修正時間與不同 lighting 下 roughness 是否成立，最後在 UE5 Sequencer/MRQ 檢查高光是否把磨損放大過頭。

#11 · prop-production

Wayfinder 風格鐮刀：ZRemesher 分層雕刻＋高對比 Base Color 驅動 Roughness／Metallic

Artem Romanov 的 stylized scythe 流程用 Blender blockout、ZBrush ZRemesher/Divide、UVPackmaster、Marmoset baking，再以 Painter 高對比 Base Color、anchor points 與 hand-painting 建立 stylized PBR。

物件製作 ★★★★★
完整分析

製作流程

硬表面先在 Blender 以低模、crease、subdivision 建好乾淨形，再進 ZBrush；有機主體用 sphere + DynaMesh 起形，之後改用 ZRemesher/Divide，在低 subdivision 調大形、高 subdivision 拋光細節。UV 回 Blender 用 UVPackmaster，4K maps 在 Marmoset 烘焙。

流程價值

貼圖重點是先把 Base Color 做出足夠的亮暗、gradient、cavity/convexity 與色相變化，再以 anchor points 衍生 Roughness/Metallic，最後手繪修正。這種做法讓 stylized PBR 的材質反應跟著設計好的色塊，而不是靠金屬度與粗糙度各自亂長。

實測

用同一 prop 做「先 PBR 通道」與「先高對比 Base Color 再 anchor」兩版，在 Marmoset 與 UE/Unity 不同 HDRI 下比較讀形、材質分離與跨 renderer 穩定性；也要檢查 Sharpen/Height 是否在低 mip 或遠距造成閃爍。
