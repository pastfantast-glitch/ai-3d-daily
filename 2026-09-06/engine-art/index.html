Unreal Engine 5.8：Mesh Terrain、PCG、LLM MCP 與更成熟的角色／世界製作

UE 5.8 強化 worldbuilding、terrain、vegetation、character/animation 與 iteration，並加入 Experimental MCP plugin、Sandboxes；Epic 同時提醒 Beta/Experimental 功能不可直接視為 production-ready。

★★★★★
完整分析

引擎工作流

Mesh Terrain、PCG 與 vegetation authoring 直接影響大型場景製作方式；統一 Gizmo 也改善 DCC artist 在引擎內操作的一致性。

FluidNinja LIVE-2 重構 UE VFX：CPU Blueprint 邏輯大幅移向 GPU／Niagara Simulation Stages

FluidNinja Live 2 重新設計底層，把更多 Blueprint function 搬到 GPU，fluid simulation 改用 Niagara Simulation Stages，並新增 surface alignment、preset 與更多輸入來源。

★★★★☆
完整分析

引擎工作流

LIVE-2 是重構而非小更新，核心目標是降低 CPU 成本並把 simulation 更完整放進 Niagara GPU pipeline。

製作價值

新的 surface alignment、單一 preset、Mesh Distance Field/Chaos input 能降低大型水、煙、沙雪效果反覆配置的負擔。

導入測試

目前 Live 2 只支援 Windows，正式專案若含 console/mobile 必須把平台限制列為 gate，不能因 PC Demo 效能好就直接替換 Live 1。

Shape Cage 用 WPO 做 UE5 Runtime Mesh Deformation：軟體感變形但不跑真正 Soft Body

Shape Cage 以 Material World Position Offset 在 GPU 端對 static mesh 做壓、彎、凹與 curtain 類變形，支援碰撞驅動、狀態同步與 Nanite。

★★★★☆
完整分析

引擎工作流

工具把 Box/Sphere/Curtain cage 與 WPO 結合，讓 static mesh 在 runtime 有受力感，同時避開 CPU mesh deformation 與完整 soft-body solver。

製作價值

支援 network sync、join-in-progress state 與停止後自動停 Tick，表示它不只是視覺 Demo，而有考慮實際遊戲狀態管理。

導入測試

限制是 WPO 變形不等同碰撞幾何與真實物理；測試時要確認 shadow、Nanite、collision、LOD 與 multiplayer replication 是否符合需求。

MetaHuman 5.7 Body Conforming：FBX Round-trip、任意 Pose 與極端比例 Joint Fitting 大幅放寬

MetaHuman 5.7 以 UV-space vertex correspondence 解決外部 DCC FBX round-trip，並放寬 A/T Pose、高度限制，新增 volumetric joint fitting 與 mesh/joint import。

★★★★☆
完整分析

引擎工作流

UV mapping 可保留 vertex ID correspondence，讓 Blender、ZBrush 等不支援 DNA 的 DCC 也能 sculpt 後用 FBX 回 MetaHuman Creator。

製作價值

Volumetric joint fitting 對 troll 類極端比例角色更友善，且 import mesh/joints 能保留核心 skeleton，方便做角色變體共用動畫。

導入測試

仍要測極端比例的 deformation、corrective system、眼口與 cloth compatibility；官方也明確表示比例越極端結果越可能變動。

#21 · optimization

Unity 官方示範用 Preset 自動化 Texture／Model Import：把資產規範前移到 Import Gate

Unity 技術文章說明用 Preset Manager 統一 texture、video、3D model 等 import 設定，特別強調 mipmap、Max Size 與團隊共享 preset，避免錯誤資產設定進 Build。

★★★★☆
完整分析

引擎工作流

把 Max Size、mipmap 等規則變成 import preset，可從『事後找超規資產』轉成『資產一進專案就套規範』，降低 memory 問題累積。

製作價值

Preset 本身是可版控的 asset，可跨專案共享，適合做團隊 texture/model import baseline，而不是靠每位美術記住設定。

導入測試

注意 Preset Manager 只影響新 import；既有資產要 reimport/reset，所以導入時應先跑 inventory，避免新舊資產規則不一致。

#27 · rendering

Unity Render Graph Viewer：用 Pass／Resource 關係直接檢查 URP 自訂 Renderer Feature 的成本

Unity 官方教學示範 Render Graph Viewer 如何查看 URP pass、texture/resource read-write 關係，協助找 redundant buffers、pass fragmentation 與 custom Renderer Feature 的效能影響。

★★★★☆
完整分析

引擎工作流

Render Graph Viewer 能把 SSAO、opaque、transparent 等 pass 對 resource 的 read/write 直接展開，比只看最終 profiler 數字更容易定位美術 feature 造成的額外 buffer。

製作價值

對 URP Renderer Feature/自訂後處理特別有用：可以先看 pass 插入位置與資源生命週期，再決定 shader 或 feature 是否值得保留。

導入測試

導入建議建立代表性 toon/character 場景，把 SSAO、outline、custom pass 逐一開關，對照 GPU profiler 與 Render Graph，形成可重複的 TA 檢查流程。
