#03 · character-production

A.K.I. 角色拆解：連接對稱低模與擺姿高模，簡化服裝貼圖

Jessie Chan 以 ZBrush 製作 A.K.I. 同人角色，將有 UV 的對稱低模連接到擺姿高模，再於 Substance 3D Painter 處理花紋，最後以 Marmoset Toolbag 打光呈現。

角色製作 ★★★★☆
完整分析

以姿勢圖層連接高低模

作者另建對稱且帶 UV 的低模，透過圖層把它移到接近高模的姿勢，再匯入高模第一細分層並轉移高解析細節；保留的圖層可切換姿勢，讓對稱低模的貼圖延用到擺姿高模。

花紋與刺繡拆成可控制遮罩

在對稱 UV 上製作服裝花紋後，作者使用 Painter 錨點分開花朵遮罩與刺繡效果，再以條紋和雲紋打散針腳。這讓圖案與表面效果能分開調整；作者指出，在擺姿狀態直接貼圖會耗費更多時間。

固定姿勢作品不等同遊戲資產

作者明確以高模展示作品為目標，擺姿後部分修改具有破壞性，並沒有替全身重拓撲；只有衣服與頭髮走一般低模貼圖流程。其餘資產使用頂點上色、減面與材質調整，不能視為已完成可動畫的遊戲角色。

#06 · production-workflow

CozyBlanket Pro 桌面版：以手繪引導線輔助重拓撲與 UV

Sparseal 的 CozyBlanket Pro 由使用者在模型表面畫引導線，再輔助生成拓撲與 UV；這篇更新加入 Windows、macOS 桌面版資訊，並說明烘焙及匯出功能。

製作流程 ★★★★☆
完整分析

人工決定輪廓再補拓撲

使用者用 Pencil 工具在模型表面畫出拓撲區塊邊緣，再由軟體補出面；可繼續加引導線或手動調整頂點。UV 也先畫接縫，再自動補其餘接縫，結果仍可人工修改。

從高模接到低模與貼圖輸出

工具可把高模的頂點色、切線空間或環境遮蔽資訊烘焙到低模，支援 UDIM；模型可匯出 OBJ 或 glTF，貼圖包含 EXR 等格式。開發者稱輔助模型採合成資料訓練，並在使用者本機運行。

引導線品質與版本相容限制

來源指出早期展示的臉部拓撲並不常規，結果仍取決於引導線放置；Pro 與舊版架構及檔案格式不同，沒有直接升級途徑。桌面版需另購，與桌面 DCC 交換場景的橋接工具則仍在開發、尚無日期。

BRIEF｜來源已驗證；證據深度較有限，完整分析會明確區分已知資訊與待驗證事項。

#07 · environment-production

Brigador Killers：以精靈圖管線連接建築崩塌、穿透與爆炸效果

Stellar Jockeys 說明 Brigador Killers 如何把子彈穿透、相鄰建築崩塌與車輛碰撞串成破壞玩法，並以 Blender 渲染精靈圖及深度資訊，支援遊戲中的遮擋與照明。

場景製作 ★★★☆☆
完整分析

三維製作轉為帶深度的精靈圖

資產在 Plasticity 或 Blender 製作、以 Painter 處理貼圖，再由 Blender 腳本旋轉渲染。輸出不只包含漫反射，也包含深度資訊，用於引擎中的精靈圖相互穿插及推導照明法線。

破壞回饋與關卡通路共同設計

系統讓鄰近受損建築帶動相鄰區塊崩塌，穿透彈與車輛碰撞也參與互動；全場景可破壞使傳統關卡封鎖方式失效，團隊必須教玩家穿牆創造路徑，並依傷害程度調整效果回饋。

精靈圖仍有光照與貼圖成本

團隊仍需控制繪製呼叫、貼圖解析度和動態光源範圍，大爆炸的強光只短暫保留；受損物件也降低對比與色彩，避免碎片和煙塵搶走玩家對角色、敵人與危險車輛的注意力。
