Blender 9/21 開發更新：GSplat 匯入／顯示、Cycles 初步渲染與 CUDA 13／DLSS

Blender 9/21 weekly update 集中了一批 Gaussian Splat 工作：EEVEE／Workbench／Overlay 顯示、PLY／SPZ import、Cycles 初步 rendering、Geometry Nodes 的 Import SPZ 與 Point Cloud type；同週 Cycles 也切到 CUDA 13 並啟用 DLSS。

綁定 ★★★★☆
完整分析

技術／流程變更

GSplat 已從單一 importer 往 Blender data-block、viewport、Cycles、USD 與 Geometry Nodes 多層整合：PointCloud 增加 type、PLY／SPZ 可辨識 splat，USD 也開始支援 UsdVolParticleField3DGaussianSplat。

Production 影響

如果團隊正在評估 3DGS 掃描、world capture 或混合 3D 資料，Blender 開始具備較完整的讀取、顯示、節點處理與 render 路徑，未來可減少為了查看 splat 資料一直切換專用 viewer 的需求。

導入測試與限制

這是 weekly development change，不等於所有功能都已進穩定版。應以實際 nightly／release build 測 PLY、SPZ、USD round-trip、viewport 與 Cycles 一致性、檔案大小及大量 splat 的 VRAM／互動效能。
