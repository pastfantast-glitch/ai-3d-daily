綁定 ★★★★☆
完整分析

技術／流程變更

Studio Orange：以 3D 動畫重建 2D Anime 語言的製作方法

分析整理 Studio Orange 如何結合 2D／3D workflow、演算法 camera 技術與傳統 2D key-frame drawing，形成《BEASTARS》《TRIGUN STAMPEDE》式表現。

動畫 ★★★★☆
完整分析

技術／流程變更

核心不是把 3D 渲染成單一 toon shader，而是將 3D animation、2D key-frame drawing 與 camera 方法共同組成視覺語言，讓姿勢、鏡頭與 timing 一起服務 2D anime 的閱讀方式。

Production 影響

對 NPR 動畫 production 很重要，因為它提醒團隊不要只把『像動畫』問題交給材質；角色 pose、camera、spacing 與 2D 修飾需要在流程上協作才能穩定得到目標風格。

導入測試與限制

文章屬製作分析而非 Studio Orange 的完整內部技術文件；若要複製做法，仍需分別測試線條、陰影、動畫抽格、鏡頭以及 2D overlay 的成本與交接方式。

Blender Cyberpunk 動畫案例：高細節 3D 場景混合 Stylized 2D VFX

Wonki Choi 以 Blender 重製《Fight Club》結尾場景，使用寫實 3D 環境／角色搭配 stylized 2D explosion VFX，形成強烈混合風格。

動畫 ★★★★☆
完整分析

技術／流程變更

案例把高細節 3D character／environment、grungy texture、camera motion 與 stylized 2D explosion VFX 疊在同一鏡頭，不靠單一 shader 完成風格化，而是跨媒材整合。

Production 影響

對遊戲 cinematic 或 NPR cutscene 的參考價值在於：寫實幾何與材質可以保留空間可信度，再由 2D VFX 與色彩／光線把視覺語言拉回插畫感，減少全流程都卡通化的負擔。

來源主要是 showcase，沒有完整節點或 compositing breakdown；若作為 production 方向，需先驗證 2D FX 與 3D camera 的 tracking、多人協作版本管理與輸出解析度需求。

#19 · rigging

Houdini KineFX / APEX：SOP 層級角色 Rig、Retarget 與程序化 Rigging

SideFX 官方文件整理 KineFX 角色工具：SOP 級 skeleton / capture weights、APEX 程序化 rig、retarget、MotionClips 與 animate state。

綁定 ★★★☆☆
完整分析

技術／流程變更

KineFX 將 skeleton、capture weights 與角色資料保持在 SOP 幾何層，rig logic 由 APEX graph 表示並可延後 evaluation，讓 rig 組裝與執行分離，支援程序化重用與 retarget。

Production 影響

對需要大量角色變體或自動化綁定的 pipeline，這種資料導向方式比手工 scene hierarchy 更容易批次修改、建立共用 rig component，並串接 mocap／secondary motion。

導入測試與限制

官方文件證明能力但不是特定 studio 的效能 benchmark；導入前要測與 Maya／Unreal／Unity 的 FBX/USD 交換、骨架命名、custom attributes 與動畫 round-trip。
