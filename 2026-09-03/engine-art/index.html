#05 · tools

Vizibeat：UE5 以音樂節拍程序化驅動 Camera／Light／Material／Particle

Vizibeat 將音訊節拍映射到 UE5 場景參數，讓鏡頭、燈光、材質與粒子可依不同節奏程序化動畫，減少逐拍 keyframe。

UE5 Tools ★★★★☆
完整分析

程序動畫流程

Vizibeat 以 node graph 把音訊 amplitude／beat 映射到 UE5 的 camera、light、material 與 particle 控制，並以 bars/beats 而非單純 frames 來定位音樂事件。

製作價值

對音樂視覺、VJ、節奏型宣傳片與需要大量同步變化的場景，最大的價值是把重複逐拍 keyframe 轉成可重用規則，再由 artist 做關鍵段落修整。

導入邊界

它適合節奏驅動的 scene animation，不等同角色 body animation；導入時應測 tempo change、非四四拍、音樂重剪後的可維護性，以及 node graph 是否能被團隊版本控管。

#07 · rendering

Unity URP：Screen Space Reflections 預覽進入 6.7 Alpha

Unity 正在 URP 導入 Screen Space Reflections，以螢幕空間 ray marching 取樣 camera color/depth，並在資訊不足時回退 reflection probe 或 skybox。

Unity Rendering ★★★★☆
完整分析

反射流程

URP SSR 以螢幕空間 ray marching 取樣相機 color/depth buffer，因此可即時反映畫面中可見物件，不需要為每個表面另外烘焙反射資訊。

遊戲美術價值

對濕地面、水面、金屬與高 smoothness 材質，SSR 可補強 reflection probe 的空間細節；若專案原本為了反射大量佈 probe，這會改變環境材質與燈光 authoring 的取捨。

限制與測試

螢幕外或被遮蔽物件無法命中，Unity 會回退 probe/skybox；導入時需在實機測試解析度、ray length、roughness、camera movement 與 fallback 接縫，不能只看靜態畫面。
