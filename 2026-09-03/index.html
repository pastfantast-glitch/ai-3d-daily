Meshy 7：Multi-Image to 3D API 新增 Ultra Mode

Meshy 將 Ultra 高細節幾何生成擴展到多視圖輸入，API 可直接以 1–4 張參考圖生成更高保真模型。

AI 3D ★★★★★

完整分析

多視圖生成流程

9 月 1 日的 API 更新把 ultra_mode 加到 Multi-Image to 3D，且僅支援 meshy-7／latest；這代表多視圖不再只提升一致性，也能直接接上 Ultra 的高細節幾何 pass。

Vizibeat 將音訊節拍映射到 UE5 場景參數，讓鏡頭、燈光、材質與粒子可依不同節奏程序化動畫，減少逐拍 keyframe。

UE5 Tools ★★★★☆

完整分析

程序動畫流程

Vizibeat 以 node graph 把音訊 amplitude／beat 映射到 UE5 的 camera、light、material 與 particle 控制，並以 bars/beats 而非單純 frames 來定位音樂事件。

製作價值

對音樂視覺、VJ、節奏型宣傳片與需要大量同步變化的場景，最大的價值是把重複逐拍 keyframe 轉成可重用規則，再由 artist 做關鍵段落修整。

導入邊界

它適合節奏驅動的 scene animation，不等同角色 body animation；導入時應測 tempo change、非四四拍、音樂重剪後的可維護性，以及 node graph 是否能被團隊版本控管。

Blighted Harbour：Blender→ZBrush→Substance→UE 的環境製作 Case

Helena Hansen 分享以 Blender、ZBrush、Substance、SpeedTree、Houdini 與 Unreal Engine 完成幻想港口場景的資產與組裝流程。

Environment ★★★★☆

完整分析

環境資產流程

案例將 blockout 視為構圖草圖，主要資產在 Blender blockout、ZBrush sculpt、回 Blender retopo/UV，再進 Substance Painter；這種跨 DCC 分工很接近實際環境美術 production。

材質與場景一致性

作者不是只在單一資產上確認貼圖，而是把已貼圖資產放回 Unreal 的中性光環境互相比對，並用 gradient shader 打破共用木材 kit 的重複感，這是可直接套用的 art-direction 檢查點。

導入做法

對固定視角或模組化場景，可借用其『先構圖／尺度、再資產細化、最後以光影和值域支持焦點』順序；尤其適合避免每個資產都精緻但組起來讀不清楚的問題。

3DGS：弱紋理／高反光物體的高保真重建實驗

Scientific Reports 9 月 2 日研究以改良影像配準加 3D Gaussian Splatting，改善弱紋理、高反光柳橙表面的重建與 novel-view 品質。

3DGS ★★★★☆

完整分析

重建能力

研究針對弱紋理與高 specular 表面這類傳統 SfM 容易失配的輸入，先改善影像註冊，再以 3DGS 做 dense reconstruction 與 neural rendering。

製作潛力

雖然題材是農業數位化，但它對掃描資產流程的啟示在於：光滑、重複紋理或高反射物件不一定要直接放棄影像式重建，可透過 registration 與 representation 組合提高可用率。

限制

輸出仍偏向高保真視覺重建而非 game-ready mesh；若用於遊戲美術，仍需另外評估 mesh extraction、UV／材質轉換、碰撞與 LOD，不能把 novel-view 品質直接等同可編輯資產品質。

Character Creator 5.13：AI Studio 解耦與角色工作流修正

CC 5.13 將 AI Studio 改為獨立應用並保留 Render 入口，同時修正 Hide Mesh、ZBrush Face Tools jaw deformation 等角色製作問題。

Character DCC ★★★★☆

完整分析

角色製作流程

CC 5.13 與 iClone 同步把 AI Studio 從主程式拆出，但仍保留 Render menu/panel 的直接入口，讓角色建置與生成後處理不必綁在同一個程序生命週期。

幾何修正

這版修正 Hide Mesh 在 SubD level 切換後不同步，以及 ZBrush Face Tools 在 Jaw Bone Y/Z scale 大於 100 時可能造成 mesh distortion；對既有角色 pipeline 比單純 UI 改版更值得升版驗證。

升版測試

建議挑有 Hide Mesh、SubD、多表情與 ZBrush round-trip 的代表角色做 regression，特別檢查 jaw open、臉部 blendshape、LOD 與 export 後在引擎中的變形一致性。
