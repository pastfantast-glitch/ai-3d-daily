Character Creator 5.13：AI Studio 解耦與角色工作流修正

CC 5.13 將 AI Studio 改為獨立應用並保留 Render 入口，同時修正 Hide Mesh、ZBrush Face Tools jaw deformation 等角色製作問題。

Character DCC ★★★★☆
完整分析

角色製作流程

CC 5.13 與 iClone 同步把 AI Studio 從主程式拆出，但仍保留 Render menu/panel 的直接入口，讓角色建置與生成後處理不必綁在同一個程序生命週期。

幾何修正

這版修正 Hide Mesh 在 SubD level 切換後不同步，以及 ZBrush Face Tools 在 Jaw Bone Y/Z scale 大於 100 時可能造成 mesh distortion；對既有角色 pipeline 比單純 UI 改版更值得升版驗證。

升版測試

建議挑有 Hide Mesh、SubD、多表情與 ZBrush round-trip 的代表角色做 regression，特別檢查 jaw open、臉部 blendshape、LOD 與 export 後在引擎中的變形一致性。

Blender GSoC：MaterialX 原生 Shader Authoring 與 Cycles OSL 執行

Blender 的 GSoC MaterialX 專案正在把 MaterialX nodedef 做成原生 ShaderNodeMaterialX，支援圖形 authoring、import/export 與 Cycles OSL 執行原型。

Blender Shader ★★★★☆
完整分析

材質X Authoring

專案把大量 MaterialX nodedef 收斂到單一 ShaderNodeMaterialX 類型，由節點狀態切換 socket 組合，目標是讓 Blender 不只匯出 MaterialX，而能直接 author 標準節點網路。

跨 DCC 價值

若 round-trip 與 USD/MaterialX 串接成熟，Blender 材質在 Maya、Houdini、USD pipeline 間的語意落差可降低；對需要跨 DCC 外包或資產交換的團隊，價值高於單純新增 shader 節點。

執行限制

目前執行原型依賴 Cycles OSL，早期規劃明確不是 EEVEE 路徑；導入評估應把 authoring/interchange 與即時引擎 shading 分開驗證，避免把 MaterialX 可交換誤認為遊戲引擎可直接等效渲染。

Silo 2026.2：FBX／USD／GLB 匯入匯出與數值欄位工作流升級

Silo 2026.2 加入數值欄位數學運算，並改善 FBX PBR 材質、USD smoothing groups 與 GLB embedded textures 的 I/O。

DCC Workflow ★★★★☆
完整分析

交換格式改善

這版把改動集中在 production I/O：FBX 的 PBR material、USD smoothing groups、GLB embedded textures 都直接影響資產在 DCC 與引擎之間 round-trip 的完整度。

建模操作

所有 numerical input field 可直接做基本數學運算，對需要比例縮放、精準 inset/offset 或以規格值建模的工作，能減少外部計算與反覆輸入。

導入測試

升版前應用同一組含 hard/soft edge、PBR texture、GLB embedded image 的資產做雙向測試，特別確認 smoothing、material slot、texture path 與 scale 不因格式改善而產生新的差異。

FreePencil2：Blender 一鍵把 3D 模型轉成可調整 Line Art

FreePencil2 以自動 vertex-color 分區加 compositor edge detection 產生線稿，並自動處理分割角度、鄰接區域著色、微小區域合併與 rig 分區。

Blender NPR ★★★★☆
完整分析

線稿生成流程

工具先自動把模型依區域寫入 vertex color，再於 compositor 以顏色邊界做 edge detection；核心價值是把最麻煩的『怎麼分區著色』前處理自動化，而不是只套一個 outline filter。

效能與規模

作者展示 155 parts 約 5.5 秒完成，並表示 128 萬 polygon 模型可在 30 秒內處理；這使它更接近可放進 NPR look-dev 的批次工具，而不只是單一模型 demo。

導入邊界

自動分區仍可能與 art direction 想要的線條層級不同；實際使用應測 touching parts、角色骨架分區、細碎配件與不同鏡頭距離，並保留 artist 後續調整 line volume 的步驟。
