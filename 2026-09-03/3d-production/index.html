Blighted Harbour：Blender→ZBrush→Substance→UE 的環境製作 Case

Helena Hansen 分享以 Blender、ZBrush、Substance、SpeedTree、Houdini 與 Unreal Engine 完成幻想港口場景的資產與組裝流程。

Environment ★★★★☆
完整分析

環境資產流程

案例將 blockout 視為構圖草圖，主要資產在 Blender blockout、ZBrush sculpt、回 Blender retopo/UV，再進 Substance Painter；這種跨 DCC 分工很接近實際環境美術 production。

材質與場景一致性

作者不是只在單一資產上確認貼圖，而是把已貼圖資產放回 Unreal 的中性光環境互相比對，並用 gradient shader 打破共用木材 kit 的重複感，這是可直接套用的 art-direction 檢查點。

導入做法

對固定視角或模組化場景，可借用其『先構圖／尺度、再資產細化、最後以光影和值域支持焦點』順序；尤其適合避免每個資產都精緻但組起來讀不清楚的問題。

WoodLand Pizzeria：把 2D 手繪感轉成 Unreal 3D 環境

Shuming Zhang 從 2D illustration 出發，使用 Maya、ZBrush、SpeedTree、Substance 與 Unreal，並以季節、時間與程序化流程測試手繪視覺的一致性。

Stylized Environment ★★★★☆
完整分析

2D 到 3D 轉譯

這個 case 的核心不是把概念圖逐物件複製，而是把手繪圖中的形狀語言、色塊與氛圍拆成可在 3D 場景維持的規則，讓模型與材質服務畫面而不是追求寫實。

場景變體測試

作者特別測試不同季節與時間，這能驗證 stylized asset 是否只在單一 lighting setup 成立；對遊戲場景而言，材質值域與色彩分層能否跨 lighting condition 保持 readability 是實際 production 問題。

程序化工作流

以程序化方法輔助重複資產與自然元素，可在保留手繪方向的同時降低手工變體成本；導入時應把可參數化部分與必須由美術手調的 hero shape 分開，避免 procedural noise 稀釋 art direction。
