京都動畫《二十世紀電氣目録》：Blender／Houdini 3DCG 背景追求『動畫手繪印象』而非寫實

CGWORLD 拆解京都動畫新作背景／ED 的 3DCG 與攝影方法，展示 Blender、Houdini 等工具如何服務手繪動畫質感，而不是單純提高 PBR 寫實度。

場景製作 ★★★★☆
情報簡析

BRIEF｜來源已驗證，但目前證據深度不足以支持完整 Production Analysis。

情報重點

案例的核心是把 3D 場景當成『支援 2D 動畫印象的結構工具』：Blender／Houdini 提供空間、程序化與鏡頭一致性，再透過材質、攝影與 compositing 把結果拉回手繪感。這與一般追求高寫實的 3D pipeline 目標不同。

導入判斷

對固定視角或 2.5D 遊戲場景很值得參考：可先用 3D 保證透視與重複資產，再主動壓低 AO、物理高光與細碎陰影，讓畫面更接近設定圖。文章是作品 case，若要轉成遊戲規格仍需自行量化材質、輪廓與後處理成本。

《World is Dancing》背景製作：3D／美術背景協作維持舞蹈鏡頭的一致空間

CGWORLD 後續篇聚焦背景與場景協作，展示在大量舞蹈鏡頭下如何利用 3D 空間基準與美術處理維持場景連續性與畫面風格。

場景製作 ★★★★☆
情報簡析

BRIEF｜來源已驗證，但目前證據深度不足以支持完整 Production Analysis。

情報重點

舞蹈作品需要鏡頭移動與角色站位高度一致，因此背景流程的重要性不只在畫得漂亮，而在先建立可靠的空間基準，再讓美術背景針對構圖、色彩與層次重新設計。3D 在這裡扮演 layout／continuity 工具。

導入判斷

固定鏡頭遊戲場景也可採類似方式：先用簡單 proxy 保障出入口、角色路徑與透視，再把最終背景拆成平面或低模層。這篇主要提供 production case 思路，並未直接給遊戲效能數據，因此列 BRIEF。

CAD／高模 Polygon Reduction 實測：Unity ATT、ZBrush、Blender、InstaLOD 放在同一 production 題目比較

CGWORLD 專題把 Unity Asset Transformer Toolkit、ZBrush、Blender 與 InstaLOD 用在 CAD／高模 reduction，比較減面後外觀與後續 realtime／LOD 工作流。

製作流程 ★★★★☆
情報簡析

BRIEF｜來源已驗證，但目前證據深度不足以支持完整 Production Analysis。

情報重點

這份比較把 reduction 工具放在同一類高密度／CAD 資產情境，而不是只看單一演算法。對 production 最有用的是能觀察自動減面後輪廓、孔洞、小零件與法線保留，以及不同工具在批次化與 LOD pipeline 的操作差異。

導入判斷

可用公司內一個機械資產建立固定 triangle budget，例如 100%、25%、10%，比較四種工具的 silhouette error、UV／material preservation、處理時間與人工修補量。文章提供實務比較，但不同資產類型差異很大，結果不能直接當唯一工具選型。
