#08 · blender

Blender 5.3 Cycles 原生 Dispersion：Principled BSDF 以 Abbe Number 控制色散

Blender 5.3 的 Principled BSDF／Cycles 加入原生 dispersion，採 Abbe number 控制折射色散，讓玻璃、寶石等材質不再完全依賴複雜節點 hack。

Blender ★★★★☆
情報簡析

BRIEF｜來源已驗證，但目前證據深度不足以支持完整 Production Analysis。

情報重點

新版 Cycles 將 dispersion 納入 Principled BSDF，透過 Abbe number 控制不同波長折射差異，做玻璃、水晶、稜鏡與寶石材質時可少掉手工拆 RGB／多層 refraction 的節點 workaround，並與 OpenPBR 方向更一致。

導入判斷

建議把現有水晶／玻璃 shader 做新舊對照，檢查 render time、firefly、噪點與不同 IOR 的可控性。這是 Blender 5.3 開發期功能，正式版前 API／參數仍可能調整；遊戲即時材質也不能直接等同 Cycles 物理色散。

#09 · addon

Caustica：把 Progressive Photon Mapping 帶進 Blender Cycles，專攻真正的 Photon Caustics

Caustica 提供 Blender 5.2 LTS 自訂 build，以 GPU Progressive Photon Mapping 補足 Cycles 的 caustics，面向玻璃、水晶、珠寶與光學效果。

外掛 ★★★★☆
情報簡析

BRIEF｜來源已驗證，但目前證據深度不足以支持完整 Production Analysis。

情報重點

Caustica 不是材質節點假 caustic，而是在 Cycles 自訂 build 中加入 progressive photon mapping，讓光經折射／反射集中形成真正的 caustics。對產品視覺、珠寶、玻璃與材質測試，比手工貼圖或光斑投影更接近物理結果。

導入判斷

若團隊有水晶／玻璃宣傳圖，可用同一場景比較標準 Cycles 與 Caustica 的收斂時間、GPU VRAM、噪點與 art-directability。它目前要求特定 Blender build、RTX 2000+ 且屬單 GPU 路徑，pipeline 維護成本比一般 addon 高，因此列 BRIEF。

#10 · addon

JiggleGen 2.0：Blender 身體、衣物與頭髮 Secondary Motion 自動化，加入獨立模擬 Mesh

JiggleGen 2.0 重寫 secondary motion 工作流，可用 vertex group 控制身體、衣物與頭髮的 jiggle，並替衣物建立獨立 simulation mesh，降低直接在高模上算 cloth 的負擔。

外掛 ★★★★☆
情報簡析

BRIEF｜來源已驗證，但目前證據深度不足以支持完整 Production Analysis。

情報重點

2.0 版把 secondary motion 從簡單骨骼抖動往可控 simulation workflow 推進：用 vertex group 指定作用區域，衣物可建立獨立 simulation mesh，再把結果回傳到原資產；同時作者也在試驗 Geometry Nodes Cloth 路徑。

導入判斷

適合拿角色胸腹軟組織、裙擺與長髮做三種測試，記錄 setup 時間、collision 穩定度、cache 與 bake 後可編輯性。這是第三方 addon，尚需確認高密度角色、角色縮放與輸出到 UE/Unity 時是否保持一致。

#11 · blender-tip

Blender Painterly Texture：用類 Kuwahara 鄰域取樣把任意貼圖轉成較大筆觸色塊

一套 Blender Shader Editor 做法以鄰域取樣與類 Kuwahara 思路，把原貼圖整理成 painterly 色塊，並可封裝成重用 Node Group。

Blender 技巧 ★★★★☆
情報簡析

BRIEF｜來源已驗證，但目前證據深度不足以支持完整 Production Analysis。

情報重點

這個做法在 shader 端對鄰近 texel 做區域統計／取樣，把高頻細節重新組成較大片的色塊與筆觸感，概念接近 Kuwahara filter。重點是可做成 reusable node group，直接套在既有貼圖上調整 painterly 程度。

導入判斷

對 Stylized／NPR 專案可用同一張 BaseColor 比較離線 Photoshop 處理與 shader 即時處理，觀察 UV seam、遠距 mip、動畫中的 shimmer 與成本。若要進遊戲引擎，最好把效果烘焙或改寫成較低取樣版本，避免高次數 texture sample。

#12 · addon

Blender Procedural Stylized Sky：多層雲速率、12 組預設與可動畫參數做成一套天空生成器

新 stylized sky generator 以程序化方式產生多層雲與天空，可控制不同 layer 速度、密度與造型，提供 12 組 preset，支援 Eevee／Cycles。

外掛 ★★★★☆
情報簡析

BRIEF｜來源已驗證，但目前證據深度不足以支持完整 Production Analysis。

情報重點

這套工具把 stylized sky 的雲層、色彩、速度與動畫參數集中成可重用 generator，而不是每個 shot 重新手搭 volume／mesh cloud。不同 layer 可用不同移動速度，有利做出 parallax 與遠近層次。

#19 · other-dcc

OpenUSD Typhoon：以 hdEmbree 打造 Reference Renderer，補強跨 DCC／Renderer 一致性檢查

新 OpenUSD reference renderer Typhoon 以 hdEmbree 為核心，提供 Linux／macOS／Windows 支援，目標是讓 USD shading、lighting 與 interoperability 有較一致的基準。

其他 DCC ★★★★☆
情報簡析

BRIEF｜來源已驗證，但目前證據深度不足以支持完整 Production Analysis。

情報重點

Typhoon 的定位不是取代 production renderer，而是提供較中立的 OpenUSD reference rendering 基準；透過 hdEmbree 讓同一 USD 場景在不同 DCC／renderer 之間有一個可比較的 shading、lighting 與 schema 解讀結果。

導入判斷

若 pipeline 正在推 USD，可挑包含 MaterialX、instance、variant 與 light 的資產，在 Typhoon、Karma／Arnold／UE 之間做 parity test，快速區分『資產資料有問題』還是『renderer 實作差異』。新工具生態與特性覆蓋仍需觀察，因此先 BRIEF。
