SketchUp 2027：程序元件、USDZ 匯入與 LayOut 1:1 無紙畫布

SketchUp 2027.0 新增可非破壞編輯的程序元件與 Copy Along，支援 USDZ、DWG／DXF 匯入控制；LayOut 加入 1:1 無紙畫布和視窗內圖片調整。

程序化 ★★★★☆
完整分析

程序建模技術流程

SketchUp Procedures 產生可非破壞編輯的程序元件；Copy Along 可沿路徑分布物件，Follow Me 與部分 Solid 布林工具也能輸出程序元件。

文件與交換製作影響

LayOut 可在 1:1 無紙畫布作圖，並直接調整視窗圖片的透明度、色相飽和度及明暗對比；SketchUp 與 LayOut 統一 Windows／macOS 介面，並新增 USDZ 與 DWG／DXF Tessellation、註記、Metadata 選項。

效能與版本限制

隱藏線向量輸出宣稱改善複雜模型效能，但 Trimble 未提供加速數字；來源系統需求段仍寫 SketchUp 2026.0，因此 2027.0 的精確相容性需再以官方版本頁核對。

#05 · case-study

Continuum 2027：向量文字、3D Noise、時間位移與更精細的 ML 遮罩

Boris FX 發布 Continuum 2027.0，新增向量式二維文字、三維程序雜訊與五種扭曲效果，並更新遮罩強度控制、臉部和邊緣細節的機器學習遮罩，以及粒子系統。

製作案例 ★★★★☆
完整分析

文字與扭曲技術流程

BCC Text 可把文字放入 3D 空間、逐字元動畫並產生計數器、Timecode 與日期；Noise Map Studio 可合成多層 3D Noise。Time Displacement 以時間而非空間位移像素，另有 Curl、Waves、Bulge 與 Vector Blur。

遮罩與粒子製作影響

PixelChooser 的 Drive Effect 可調整遮罩區域內效果強度；Face ML 擴大到完整臉形與耳朵，Matte Refine ML 改善髮絲細節，Witness Protection ML 改用精確遮罩。Particle Illusion 也加入快取與 STL 匯入。

相容性與成本限制

Continuum 2027.0 支援 After Effects、DaVinci Resolve、Nuke 等宿主，系統需求為 Windows 10+ 或 macOS 12.0+；價格依宿主與永久／訂閱方案差異很大，導入前需核對實際宿主版本與授權。
