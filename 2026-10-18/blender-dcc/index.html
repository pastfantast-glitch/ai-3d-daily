Blender 公告資深軟體工程師與初階／一般 DevOps 工程師職缺：前者著重 C++ 與 Python，後者著重腳本、版本控制及基礎設施；不是 Blender 新功能發布。

工具開發與基礎設施技能重點

軟體工程師要求熟悉 C++，理解 Python 腳本，並具備跨平台開發及 CMake 等工具經驗；DevOps 則要求 Python 或 Shell、Git／Git LFS 與類 Unix 系統知識。兩個職位支援的環節不同，不能把職缺名稱當成相同的技術工作。

對技術美術職涯規劃的參考價值

DevOps 額外列出自架服務、基礎設施即程式碼、容器與虛擬化等經驗。推論上，熟悉 DCC 操作的美術若想往工具或管線方向延伸，可以從這些要求辨認尚需補足的工程技能，但不能據此認定建模資歷本身已符合職務資格。

遠端工作與招募時效限制

DevOps 明確要求在阿姆斯特丹總部現場工作，軟體工程師則可考慮遠端。這只是十月十六日的職缺報導，未提供錄取保證或今日缺額確認；申請前仍須以實際招募頁為準，不能把兩個職位都解讀為可遠端。
