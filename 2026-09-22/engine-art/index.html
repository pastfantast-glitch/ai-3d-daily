#02 · tools

UNIGINE 2.22：新 Sequencer、動畫串流與 Animation Graph IK／Constraint

UNIGINE 2.22 把 Sequencer、非同步動畫串流、IK／Look At／Joint Constraint、Dynamic Resolution 與渲染更新一起推進，對即時 3D 與技術美術管線有直接影響。

引擎工具 ★★★★★
完整分析

技術／流程變更

2.22 以 Sequencer 取代舊 Tracker 路線，加入 auto-key、可重用 sequence、物件綁定與 C++／C# API；Animation Graph 同時新增 IK、Look At、關節約束與程序姿態控制。

Production 影響

動畫密集場景可使用非同步動畫串流，搭配新的 timeline 與 graph 能把過場、角色動作與工具自動化更集中在 Editor 內完成，減少外部工具往返。

導入測試與限制

官方同時列出 Dynamic Resolution、陰影與效能改進，但實際收益仍需用目標角色數、骨架複雜度與平台做 benchmark；先驗證 Sequencer／Animation Graph 與既有資產相容性。

#03 · unity

Unity 6.6 正式推出：Supported Release 銜接 6.7 LTS

Unity 6.6 已成為 Unity 6 系列最後一個 Supported Release；對正在 Unity 6 生產線上的團隊，重點是評估新功能、修正與升級風險，而不是只追版本號。

Unity ★★★★★
完整分析

技術／流程變更

Unity 官方確認 6.6 已可用，並把它定位為 Unity 6 家族最後一個 Supported Release，維護到下一個 6.7 版本到來；團隊可從 6.6 開始逐步銜接後續 LTS。

Production 影響

對 URP／角色／技術美術專案，價值在於能提早取得 6.6 的新功能與修正，同時用正式 upgrade guide 規劃專案升級，而不是等到下一個 LTS 才一次承擔全部變更。

導入測試與限制

目前此候選以官方發布貼文為主要證據，不能把所有 6.6 功能都視為已適合既有專案；應先用分支驗證 Shader、Renderer Feature、平台 build 與套件相容性再決定導入。

#08 · unity

Flesh Dynamics：Unity 角色局部軟組織變形，直接塗抹模擬區域

Flesh Dynamics 疊在既有 Rig／Animation 上，以 paint mask 指定軟組織區域，再用 GPU vertex deformation、Jobs 與 Burst 做碰撞和體積感變形。

Unity ★★★★☆
完整分析

技術／流程變更

工具讓美術直接在角色上塗抹需要軟組織物理的區域，未塗抹部位維持原 Rig 動畫；碰撞物可壓縮指定區域，並以 GPU vertex deformation、Jobs、Burst 執行。

Production 影響

若能穩定使用，角色不必為每個胸腹、尾巴或軟組織額外建立複雜 secondary rig，就能在 Built-in、URP、HDRP 上加入局部動態反應。

導入測試與限制

效能數字目前主要來自開發者示範，實際成本會隨網格密度、模擬面積與同屏角色數變動；導入前應用目標角色 LOD 與最差同屏數做 GPU／CPU profile。

BRIEF｜來源已驗證；證據深度較有限，完整分析會明確區分已知資訊與待驗證事項。

#16 · unreal

PopcornFX＋UE5：把蝴蝶法術拆成 Vortex→主蝴蝶→氣流→Explosion

Elenna Raguin 先用概念草圖把 stylized spell 分段，再以 PopcornFX Unreal plugin 組成可讀性清楚的即時蝴蝶法術。

Unreal ★★★★☆
完整分析

技術／流程變更

效果在製作前先拆成蝴蝶 vortex、巨大主蝴蝶、氣流帶動小蝴蝶、終點爆發四段，並透過 PopcornFX 的 Unreal plugin 在 UE5 中即時組合。

Production 影響

可直接借鏡的是『先拆視覺節拍再做粒子』：複雜法術不必從單一 emitter 開始，而是用主讀點、引導流與收尾爆發建立清楚 timing 與 silhouette。

導入測試與限制

文章沒有提供粒子數、overdraw、GPU cost 或不同平台 benchmark；若用於實際戰鬥特效，仍需用目標鏡頭距離與同屏技能數測試透明排序與 fill-rate。
