#04 · character-production

Water Woman：Maya／Blender 造型＋黑白貼圖後再統一換色

角色案例先以黑白關係建立材質層次，再調整整體色盤，適合作為 stylized lookdev 參考。

角色製作 ★★★★☆
完整分析

技術／流程變更

流程先建立角色形體，再以黑白貼圖鎖定材質明度與層次，最後才把 palette 推到目標色彩，減少早期被顏色干擾。

Production 影響

對 stylized／NPR 角色，先鎖 value 再換色有利於多材質快速迭代，也能讓不同光線下的視覺階層更清楚。

導入測試與限制

單一藝術家案例不代表免 retopo 適合所有遊戲資產；仍要檢查 deformation、UV、LOD 與引擎效能。

#05 · environment-production

中世紀花磚材質：Substance Designer 模組化破損狀態＋UE5 落地

Alisa Prakapenka 將 clean／broken／damaged tile 拆成可重用 subgraph，從 Height、Grout、Base Color 到 Roughness 建立可控制的老化花磚材質，再放進 UE5 檢視。

場景製作 ★★★★★
完整分析

技術／流程變更

流程不是只做一張乾淨 tile，而是把高度、填縫、花紋、底色與粗糙度拆成模組，再建立 clean、broken、damaged 狀態，讓缺角、磨耗與污垢能受控疊加。

Production 影響

這種 subgraph 分層讓同一套材質可以快速產生年代感與變體，對模組化場景尤其有價值；美術可調破損比例而不必為每個區塊重做獨立貼圖。

導入測試與限制

文章屬單一作品 breakdown，但技術步驟足以重現；實際導入時仍應用專案 texel density、壓縮格式與 UE5 shader 成本測試，確認細節密度不會只在近距離展示成立。

#11 · production-workflow

RealityScan Mobile 1.9：拍攝後可刪照片、離線補拍與 iOS 過熱警告

RealityScan Mobile 1.9 強化 capture／review／processing 的可靠性，讓行動 photogrammetry 在現場更容易清理壞照片、斷網續拍並避免裝置過熱中斷。

製作流程 ★★★★☆
完整分析

技術／流程變更

1.9 允許在 Review 階段刪除不需要或不可用照片，未處理物件即使沒有網路也可繼續補拍；iOS 另外加入過熱警告，降低突然 crash 或 throttling 的風險。

Production 影響

這些不是重建演算法大改版，但直接改善外景掃描的容錯：現場可以先完成資料收集，再整理照片品質，不必因網路或裝置狀態中斷 capture session。

導入測試與限制

若要納入遊戲資產流程，仍需驗證不同手機、光線與物件材質下的 mesh／texture 品質，以及後續 retopo、UV、LOD 的人工成本；本次更新重點是可靠性而非品質 benchmark。

光リファレンス：105 組光源／材質／反射／大氣預設做 Lookdev Reference

互動網站可比較 lighting/material 變因並輸出 PNG 或旋轉 GIF，適合 shader 與外包溝通。

製作流程 ★★★★☆
完整分析

技術／流程變更

工具把光照與材質變因拆成可調參數，提供 105 preset 比較反射、粗糙度、大氣與鏡頭差異，並可輸出 PNG／GIF。

導入測試與限制

它不是目標引擎的物理真值；使用時應標清曝光、tone mapping、HDR、色域與 shader 差異，避免把 reference 當數值規格。

#25 · production-workflow

MAALAT：Blender／Cycles＋實拍材質＋Photoshop 後製的 Painterly Still Life

Kem 以 Blender 建模雕刻、Cycles 渲染，自行拍攝紋理後在 Photoshop 整理，再與 node shader 混合，最後用 color grading 統一成傳統繪畫感。

製作流程 ★★★★☆
完整分析

技術／流程變更

作品把 Blender 建模／雕刻與 Cycles 渲染作為 3D 基底，再使用自行拍攝的 texture，於 Photoshop 處理後混入 node shader，最後以後製 color grading 統一畫面。

Production 影響

對非寫實 lookdev 的啟示是材質不必全部程序生成；把真實攝影紋理當作局部色塊與筆觸來源，再透過節點與後製控制，可更快建立有手作痕跡的表面。

導入測試與限制

這是 still-life 視覺開發案例，尚未證明可直接用於即時遊戲；若轉成 realtime，需要驗證光照變化、不同視角下的材質成立度，以及哪些 painterly 特徵要 baked 或 shader 化。

BRIEF｜來源已驗證；證據深度較有限，完整分析會明確區分已知資訊與待驗證事項。
