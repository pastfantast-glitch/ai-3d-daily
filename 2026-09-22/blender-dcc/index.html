Blender Glitter Tights：用視角變化驅動布料閃點

亮片高光會隨鏡頭角度改變，適合作為角色服裝與 NPR 高光設計參考。

Blender ★★★☆☆
完整分析

技術／流程變更

核心是把亮片視為 view-dependent response，而不是固定貼圖亮點；鏡頭移動時高亮位置改變才形成細碎閃爍。

導入測試與限制

沒有跨引擎成本數據；導入時要測 aliasing、TAA／TSR 穩定性、遠距離閃爍與行動裝置 shader cost。

#10 · blender

Anime Clouds：Blender 用幾何＋Shader＋Kuwahara 做卡通雲

教學把 stylized cloud 拆成 silhouette、受光與濾鏡三層，而不是只靠材質。

Blender ★★★★☆

先用幾何決定雲塊大形，再用 shader 控制明暗色階，最後以 Kuwahara 整理細碎變化，因此不是單一材質節點完成。

#12 · addon

TopoPen：Blender 直接在高模表面畫 Quad Flow

TopoPen 把 Draw、Precise Draw、Boundary Fill、Edge Flow、Circle Loop、Surface Cut 等 retopo 操作放進 Blender Edit Mode，支援角色與硬表面。

外掛 ★★★★★
完整分析

技術／流程變更

使用者可直接在來源模型表面畫線並自動建立 quad grid，並用 quad size 控制密度；Edge Flow、Circle Loop 與 Surface Cut 則補足眼口、管線與硬表面切線等局部拓樸需求。

Production 影響

這類工具的價值是把 retopo 規劃與落點保持在同一個 Blender Edit Mode，降低反覆 shrinkwrap、手動貼面與調整 vertex spacing 的操作成本。

導入測試與限制

目前證據主要來自產品示範；應拿角色臉、服裝摺痕、硬表面轉折三類網格測試 edge flow、密度一致性與修正時間，再和現有手工／外掛流程比較。

BRIEF｜來源已驗證；證據深度較有限，完整分析會明確區分已知資訊與待驗證事項。

#14 · blender

Blender Geometry Nodes 卡通 VFX：用 Mapping 驅動 Noise／Voronoi

Good Good 以 Geometry Nodes、Noise／Voronoi 與 Mapping 做 stylized VFX，重點放在 timing、色彩與往 game engine 延伸時較乾淨的控制方式。

Blender ★★★★☆

#15 · houdini

RiverFX：Houdini 用 Lagrangian Wave Curves＋自訂 Velocity 場做溪流

Fred Bello 依 Wētā 的 Lagrangian wave 研究建立 Houdini 河流：岩石周圍 velocity field、wave curves、low/high mesh 與 whitewater 分層完成。

Houdini ★★★★☆
完整分析

技術／流程變更

流程先在岩石周圍建立自訂 velocity field，再配置 wave curves 形成自然流向；低模建立整體流體後，再由 wave curves 製作高模細節，最後疊 whitewater 表現撞擊泡沫。

Production 影響

這提供一個比單純高度場更可控的河流 VFX 參考：障礙物附近的流向、浪形與泡沫可以分層處理，適合轉譯成離線 sim、cache 或引擎用 flow／foam 資料。

導入測試與限制

目前案例是個人作品且未提供完整效能與 cache 成本；若用於遊戲，應先確認低高模轉換、白水 bake、UV／velocity 輸出與目標引擎 runtime 表現。

Plugin Hub：把 Blender 多個 Add-on Sidebar 整併成單一可還原選單

Plugin Hub 可掃描 3D Viewport Sidebar，把多個 add-on panel 合併成一個 Plugins 區域／選單／浮動視窗，並保留原 panel code 與還原機制。
