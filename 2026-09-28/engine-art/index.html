#01 · unreal

Flesh Dynamics：在 Unity 角色上加入即時軟體物理與碰撞變形

FrostPunchGames 推出的 Flesh Dynamics 可疊加在既有 SkinnedMeshRenderer 動畫之上，為指定身體區域加入柔軟組織的二次晃動與碰撞變形。Unity 版本已推出，Unreal Engine 版本仍在開發中。

Unreal ★★★★☆
完整分析

技術／流程變更

Flesh Dynamics 的核心不是取代骨架動畫，而是在既有角色動畫結果上再加入 soft-body 次級運動與碰撞變形，讓需要柔軟感的身體區域能以物理方式補足純 skinning 的表現。

Production 影響

對角色製作流程而言，這類工具可把原本需要額外骨骼、手動畫曲線或特製 shader 的局部晃動改成物理層處理；美術與動畫仍保留原始動作，只把柔軟變形交給 runtime 系統。

導入測試與限制

導入時要實測不同角色比例、碰撞體、快速動作與鏡頭距離下的穩定度，也要量測 CPU／GPU 成本與行動裝置表現。Unreal Engine 版本仍在開發，不應把 Unity 端結果直接視為 UE 可用性。

#07 · rendering

Godot 4.6：Rendering、Animation、Physics 與工作流重點更新

CG Channel 整理 Godot 4.6 對 CG 藝術家較重要的更新，重點涵蓋 rendering、animation、physics，以及多項改善日常操作效率的 quality-of-life 功能。

渲染 ★★★☆☆
完整分析

技術／流程變更

Godot 4.6 的改動不是集中在單一模組，而是同時落在 rendering、animation、physics 與編輯器操作，代表美術端升版時需要做跨系統回歸，而不是只驗 shader。

Production 影響

對使用 Godot 的 3D 團隊，可優先把版本測試拆成畫面、動畫、物理與 editor workflow 四組，快速判斷哪些更新能直接減少手工操作或改善最終呈現。

導入測試與限制

這是版本功能整理，不代表每項更新都適合現有專案。升版前應用代表場景與角色測 render parity、動畫播放、physics 行為與匯入流程，再決定正式基線。

#20 · unreal

Military Airport：100+ 模組化機場資產，可用於 Unity／Unreal Engine

Freshcan 3D 的 Military Airport 套件包含超過 100 個模組化機場資產，涵蓋建築、道路與箱子、貨櫃、管線、標誌、圍欄等 props；提供 Unity 與 Unreal Engine 套件，Fab Standard 授權允許在不同引擎與工具中商用。

Unreal ★★★☆☆
完整分析

技術／流程變更

資產包以 modular environment 為核心，建築搭配 tileable materials，並用道路與大量 props 組成軍用機場環境；這類結構適合觀察模組尺寸與重用方式。

Production 影響

對場景團隊而言，可拿來做 modular kit、材質覆用與場景組裝的 reference，也能測 Unity／UE 匯入後 prefab／material／collision 的整理成本。

導入測試與限制

來源中的限時免費日期是 2024 年資訊，現在不能再視為仍免費。實際使用前應重新確認 Fab 上架狀態、授權、引擎版本與資產技術規格。
