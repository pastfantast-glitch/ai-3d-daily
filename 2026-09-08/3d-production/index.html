#03 · character-production

Punk Knight：把 2D 概念直接投射到 ZBrush 雕刻以鎖定造型與配色

David Papunashvili 分享 stylized character 流程，直接把 2D concept 投射到 sculpt 作比例與色彩比對，並以 PolyPaint 建立插畫式 3D 外觀。

角色製作 ★★★★☆
完整分析

角色製作流程

這個流程不是只把 2D concept 放在旁邊參考，而是直接投射到 ZBrush sculpt 上，用原畫的比例、輪廓與色彩位置持續校正 3D 造型，再以 PolyPaint 建立接近插畫的表面方向。

製作價值

對設計語言強、比例刻意誇張的 stylized character，投射參考可把「像不像原畫」變成可直接對照的判斷，降低 sculpt 過程逐步寫實化或局部比例漂移後再大幅回修的機率。

實測

用同一份正面／側面概念各做一次傳統 eyeballing 與投射參考流程，記錄 blockout 到 final sculpt 的修改回合，並比較 silhouette、五官位置、服裝色塊與最終遊戲鏡頭下的辨識度。

#04 · prop-production

科幻道具磨損製作：以四組 Texture Set 管理金屬、玻璃與塑膠

Dragoslav Vugdelija 拆解科幻 prop 的表面損傷與材質規劃，將資產拆成四組 texture sets，適合對照高品質道具的 texel／材質責任分配。

物件製作 ★★★★☆
完整分析

道具製作流程

案例把科幻道具的金屬、玻璃、塑膠與其他表面責任拆成四組 Texture Set，再配合表面損傷與磨耗雕刻處理，重點是依材質族群與畫面重要性規劃貼圖資源，而不是單純依零件切組。

製作價值

Texture Set 數量會同時影響 texel density、Substance authoring 隔離性、材質 slot、記憶體與 draw cost；對 hero prop 而言，四組配置提供一個可量化的畫質與效能取捨基準。

實測

拿同一件道具做 1／2／4 組 Texture Set A/B，固定最終解析度需求，比較可見細節、貼圖容量、材質 slot、engine 記憶體與 draw calls，同時記錄 Painter 內修改單一材質時的返工時間。

#06 · character-production

64×64 sprite 轉 3D：以 pose 建模與 stylized PBR 保留像素角色辨識度

Paul Thureau 從 Pokémon 64×64 sprite 建立 stylized 3D 角色，採直接 pose 建模並針對眼睛與服裝設計貼圖，適合作為低資訊概念轉 3D 的案例。

角色製作 ★★★★☆
完整分析

角色製作流程

從 64×64 sprite 建 3D 時，可用資訊非常有限，因此流程先鎖定 silhouette、主要色塊與角色招牌特徵，再以直接 pose 建模和眼睛／服裝貼圖補足 3D 所需資訊，而不是先追求寫實解剖細節。

製作價值

這種做法適合 retro IP、舊遊戲重製或只有低解析概念的角色：評估標準應優先放在縮圖與遊戲鏡頭的辨識度，避免新增過多 3D 細節反而破壞原本像素角色的視覺記憶。

實測

用原 sprite、正交 render 與實際 game-camera render 同時比對 silhouette、頭身比例、眼睛位置、服裝主色與 pose，並在縮小尺寸後做辨識測試，再決定哪些 3D 細節值得保留。

#11 · production-workflow

Blender＋Photoshop 2D/3D 概念流程：從 reference、blockout 到 final paintover

Eugenia Chernova 展示環境概念如何先在 Blender 建立 3D scene，再進 Photoshop paintover，適合快速控制透視、構圖與場景層次的 concept workflow。

製作流程 ★★★★☆
完整分析

場景製作流程

這套 Blender＋Photoshop 流程先用 3D blockout 解決透視、相機、建築尺度與前中遠景關係，再把 render 帶進 Photoshop paintover 完成氣氛與風格，因此空間設計與最終插畫可以分階段迭代。

製作價值

如果 concept 後續還要拆成 3D 遊戲場景，先建立可重用的相機與 blockout 能降低概念圖很漂亮、但回到 3D 後透視與尺寸無法落地的風險，也方便設計修改時快速重出底稿。

實測

用同一個近／中／遠三層場景比較純 2D 與 3D-assisted concept，記錄改相機、移建築、調比例與最終 paintover 的時間，並檢查 3D blockout 是否能直接交給後續場景製作繼續使用。
