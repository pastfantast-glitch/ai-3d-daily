#15 · 4d

RAGA：3DGS Avatar／Scene Interaction 的 Real-time Gaussian Ray-traced Shadows

RAGA 直接在 Gaussian space 進行 ray-traced shadow casting，不依賴 mesh reconstruction，並以 avatar proxy 穩定服裝變形時的陰影；論文報告約 50 FPS。

4D ★★★★☆
完整分析

動態 3DGS 渲染

方法直接計算 ray-Gaussian opacity integral，讓 animated Gaussian avatar 在既有 Gaussian scene 裡能有更一致的陰影互動。

Production 潛力

若 3DGS 逐步進入 virtual production 或 real-time avatar 場景，陰影一致性是從展示走向可用 rendering pipeline 的重要缺口。

限制與測試

目前依賴 CUDA/OptiX；應先測多角色、透明衣物、快速動作與不同 Gaussian density 下的 temporal stability。

#16 · research

FastGHA：Few-shot Images 直接生成可 Real-time Animation 的 3D Gaussian Head Avatar

Disney Research 等提出 FastGHA，以少量影像 feed-forward 生成高品質 Gaussian head avatar，並以輕量 MLP 根據 expression codes 預測 Gaussian deformation，支援 real-time animation。

研究 ★★★★☆
完整分析

Avatar 生成

few-shot feed-forward 路線避免每個角色長時間 per-identity optimization，對大量 avatar 建立更接近可擴展 production 模式。

動畫控制

每個 Gaussian 帶 feature，再由輕量 dynamic network 依 expression code 預測 deformation，使重建與即時 facial driving 能放在同一 representation。

成熟度判斷

仍屬研究型 Gaussian avatar；應比較 capture 張數、側後視角、極端表情與轉成傳統 mesh/rig pipeline 的成本。
