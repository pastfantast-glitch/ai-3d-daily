# 收集工作區與發布預演

來源配置與今日運作分成兩種畫布；固定流程不能拉線改寫或繞過審稿。
節點相關文章、摘要與分析在右側查看，來源與主題編輯留在同一畫布。
長文可展開詳情、返回清單；外部來源與 Actions 另開連結。

滾輪以游標為中心縮放，空白處／中鍵拖曳平移；Shift 拖曳框選後可聚焦。
節點位置、視角、模式與選取保存在該站主的瀏覽器。設定、憑證及正文不存入
畫布快取。復原／重做作用於本次本機設定草稿與位置，不能撤銷已生效的遠端設定。
來源設定仍須儲存、驗證、站主套用。待套用變更摘要比較現行設定，不把儲存當啟用。

後臺備稿索引合併 rolling backlog 與 180 日內已合併的核准審稿檔，排除已發布 URL、
逾 12 個月來源、停用來源／主題、暫緩與暫時無法擷取的稿件。核准備稿使用前仍需
Collector 重新擷取並核對正文雜湊、日期與品質。索引讀取失敗顯示未知，不顯示假零。
目標以 AI／3D 每期目標的兩倍估算；目標不是實際庫存。

審稿概況只宣稱可驗證的已合併核准數與 Collector 待審紀錄。本機未提交進度未知，
由既有每日任務的 tools/editorial_progress.py 接續，不由後臺冒充另一位審稿者。
同一原始 run 不重複合併，成功後仍可依現行 reserve 契約審閱尚未提交的來源包。

每個來源的正文可讀、審稿核准、品質去重通過、入選與備稿數，取自 Collector 的
實際階段結果；已發布數取自核對通過的當日收據。未知欄位顯示「—」。

發布失敗提示接續原 Publisher；交接失敗沿用既有初次加兩次修正上限，輸入未變
不得重試。後臺不新增 writer 或自動重跑；DONE 不重新開啟。

PR CI 執行 scripts/check_release_preflight.py，從最新正式日報建立可丟棄副本，
重跑現行 prepare、ready gate、首頁／日報／主題生成與歷史回歸。影像使用既有
cache，不做正式 Discovery、網路擷取、部署或修改工作目錄的 canonical／DONE。
12／20／30 篇、缺漏／重複／排序錯誤與隔日歷史分支另由現有回歸測試涵蓋。

來源提案變更 PR 才做外站試讀；一般程式 PR 執行擷取器／設定測試，避免未變更的
站主草稿遭外站 403 而擋住其他修復。main 上套用前的即時來源驗證仍保留且不能略過。
外站拒絕存取不代表程式可修復，必須改用可讀的官方入口或由站主暫停該來源。
