#06 · blender-tip

Blender 曲面 Pinching 修正：Alt+S、LoopTools Curve 與 Grid Fill

Jan van den Hemel 示範多種消除曲面凹凸與 pinching 的建模修正法，涵蓋法線方向縮放、Curve 與重建局部拓樸。

Blender 技巧 ★★★★☆
完整分析

技術／流程變更

小範圍凹凸可用 Alt+S 沿法線調整，或反選後以 LoopTools Curve 重整曲面；較大的問題則刪除異常區域，再利用邊界與 Grid Fill 重建局部拓樸。

Production 影響

這些方法適合 hard-surface SubD、布林後清面與角色局部修形，能避免只靠細分或 Smooth 掩蓋拓樸問題，讓輪廓與高光帶在最終烘焙或即時渲染中更穩定。

導入測試與限制

不同曲率與 edge flow 對 Grid Fill 結果差異很大；導入 SOP 時應在高光反射明顯的曲面上檢查 shading，再決定是修點、重拓樸或改變 boolean 前的基礎拓樸。

#10 · substance

Substance Designer 3D Scenes：在場景脈絡中編材質並保留 USD 非破壞輸出

Designer 可載入 3D scene，在原場景脈絡替換材質、保留 session 狀態，並以 USD 工作流輸出只包含修改與新增內容。

Substance ★★★★☆
完整分析

技術／流程變更

Designer 的 3D Scene 工作流讓材質不再只在單一 preview mesh 上編輯，而是可載入完整場景、覆蓋指定材質並從既有材質抽取值或貼圖作為起點；USD 還能以非破壞方式輸出差異。

Production 影響

對環境材質與 lookdev 很實用，材質師可直接在實際比例、燈光與鄰接材質脈絡中判斷結果，減少 Designer 與 DCC／引擎之間反覆猜測。

導入測試與限制

需確認團隊使用的 scene format、USD variant／layer 規則與 downstream DCC 支援；如果專案不使用 USD，仍要測試 FBX/其他格式下材質覆蓋與導出是否符合現有 pipeline。

BRIEF｜來源已驗證；證據深度較有限，完整分析會明確區分已知資訊與待驗證事項。

#16 · substance

800+ PBR 材質庫：4K 貼圖、SBS/SBSAR 與 Blender 檔案並存

Julio Sillet 的材質庫已超過 800 組，提供 4K PBR maps、Blender 4.5+、SBS/SBSAR 與部分生成器，可作為材質基底與參考。

Substance ★★★☆☆
完整分析

技術／流程變更

材質庫同時提供 base color、roughness、normal、height 等 4K maps，以及 Blender 檔與 SBS/SBSAR；部分材質保留程序化生成器，方便從貼圖使用延伸到可調參數版本。

Production 影響

對場景與原型製作可作為快速 base material 或 reference library，尤其當團隊需要跨 Blender/Substance 共用來源時，比只拿 JPEG/PBR 貼圖更容易保留可編輯性。

導入測試與限制

素材庫不等於專案標準化材質；導入前仍要檢查授權、色彩空間、貼圖通道、實際 texel density 與目標引擎壓縮格式，避免 4K 全量直接進 runtime。

BRIEF｜來源已驗證；證據深度較有限，完整分析會明確區分已知資訊與待驗證事項。

#19 · substance

Substance SBSAR 發布：把程序材質封裝成獨立、可攜且可調的資產

Adobe 文件說明 Designer package 如何發布為 SBSAR，將 graph 與必要資源打包成單一可攜檔，供 Substance 生態與支援的 DCC/Engine 使用。

Substance ★★★☆☆
完整分析

技術／流程變更

SBSAR 會發布整個 package，而不是單一 graph，並把所需資源封裝成獨立檔案；相比固定 bitmap，參數化資產可在支援環境中重新生成不同解析度與變體。

Production 影響

對跨專案材質庫、外包交付與可調式地表／道具材質很實用，能把『一組貼圖』升級成可維護的程序資產，也更容易建立統一參數與命名規範。

導入測試與限制

不是所有 runtime 都適合直接求值 SBSAR；團隊需決定是在 DCC 預烘焙、build pipeline 產圖，或引擎端支援程序材質，同時管理版本與 embedded resource 大小。

BRIEF｜來源已驗證；證據深度較有限，完整分析會明確區分已知資訊與待驗證事項。

#20 · substance

Substance Designer OpenPBR Material Samples：以可拆解範例 Graph 建立材質模板

Designer 提供一組以 OpenPBR 為基礎的 material sample graphs，可直接複製、拆解與修改，作為新材質的可編輯模板。

Substance ★★★☆☆
完整分析

技術／流程變更

Material Samples 不是只能看的 preset，而是建立新 graph 時可複製出的完整可編輯模板；目前範例以 OpenPBR material model 為基礎，方便學習節點結構與快速延伸。

Production 影響

對建立團隊材質 starter graph 很有價值，可以官方範例作為結構參考，再包成公司內部的命名、輸出與參數規格，降低每個人從空白 graph 開始造成的差異。

導入測試與限制

OpenPBR 在不同 renderer／engine 的落地仍可能有映射差異；採用前應對 base color、roughness、specular、coat 等通道做跨 DCC/引擎比對，不要假設視覺完全一致。

BRIEF｜來源已驗證；證據深度較有限，完整分析會明確區分已知資訊與待驗證事項。
