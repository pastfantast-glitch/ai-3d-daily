#04 · rigging

UE5.8 Control Rig × Animation Blueprint：把 Rig 控制器帶進 gameplay 程序動畫

Epic 文件說明 Control Rig node 可直接放進 Anim Graph，並傳入 pose、curve、特定 bones、controls 與 variables；常見用途是地面對齊或接觸點等 gameplay 程序修正，同時可選 global／local pose transfer 取捨一致性與效能。

綁定 ★★★★☆
完整分析

Rig 工作流

Control Rig 可作為 Animation Blueprint 的 Anim Graph node 使用，將輸入 pose、curve、指定 bones 與 exposed variables 傳進 Rig。這讓動畫師建立的控制邏輯可以直接被 gameplay 驅動，而不必把所有程序修正重新寫成另一套骨架節點。

Production 影響

地面對齊、接觸點、局部 IK 或可調參數都能在既有動畫藍圖中接上 Control Rig；同時可限制只傳特定 bones，並選擇 global 或 local transfer。對角色管線而言，這提供了在美術可編輯 Rig 與 runtime 動畫系統之間較清楚的交界。

導入測試

需要實測 global transfer 的一致性與成本，特別是骨架階層不同或 Rig 很大的角色；建議比較全骨架與限定 bones 的 CPU 時間、curve 傳遞、LOD／多人角色數，以及關閉 global transfer 後是否出現姿勢偏差，再決定 gameplay 層應保留多少 Control Rig 計算。

#10 · rigging

Bone Damped Track Batch 3.6：Blender 批次建立骨骼 Damped Track 約束的輕量 Rig 外掛

Blender Extensions 9/16 上架的 Bone Damped Track Batch 3.6 專注動畫綁定效率，可對多骨骼批次建立 Damped Track 類約束；它是小工具型外掛，價值在減少重複 Rig 操作而非改變整套角色架構。

綁定 ★★★☆☆
完整分析

Rig 工具

此 extension 的定位很單純：把原本要逐骨設定的 Damped Track 類操作批次化，適合需要多條骨鏈朝向同一目標、觸手／附件／機械連桿或大量輔助骨的 setup。3.6.0 是 9/16 的初次公開版本，支援 Blender 4.2 LTS 以上。

Production 價值

小型 rig 工具最直接的收益是降低重複點選與漏設參數，特別是同一約束規則要套到很多骨骼時。若團隊已有自製 rig script，它也可作為『哪些步驟值得批次化』的參考，而不一定需要整個納入正式 pipeline。

導入測試

目前下載量與實戰證據有限，應先在測試 rig 驗證 bone selection、target、axis、existing constraint、undo、鏡像命名與重複執行是否 idempotent；再確認它不會破壞既有 driver／constraint 順序，才適合放進 production 工具箱。
