#01 · character-production

SUMIGIRI：四色限制下的 Unity 漫畫風 3D 動作遊戲

Kenji Ma 的 Game Jam 作品 SUMIGIRI 以 Unity 製作，除黑白外只能使用四個指定色，並可調整明度與飽和度；角色以巨大畫筆潑墨戰鬥，讓色彩限制同時影響畫面辨識與玩法表現。

角色製作 ★★★★☆
完整分析

技術／流程變更

這個案例把四色 palette 限制直接放進 3D 場景與戰鬥設計：角色、敵人、墨跡與戰場都必須在極少色彩下維持層次，因此重點是明暗、輪廓與飽和度控制，而不是單純套一層漫畫 Shader。

Production 影響

對 Stylized／Unity 團隊，可把它當成「先定視覺預算再做資產」的案例：先鎖定 palette，再檢查角色、特效與背景的辨識度，能提早發現過度依賴顏色數量才能成立的材質與 VFX。

導入測試與限制

這是單人 Game Jam 專案，能證明限制式美術方向可成立，但不代表已涵蓋大型關卡、多人協作、完整 UI 與多種光照條件；量產前仍要補測不同場景明暗下的可讀性。

#06 · environment-production

《Lioness》S3：Framestore 以全 3D 戰場支撐 180 鏡頭視差與尺度

Framestore 為《Lioness》第三季建立可與 138 英畝實景銜接的 CG 戰場；因 180 個鏡頭有大量攝影機運動，團隊採完整 3D 方案維持 parallax 與尺度，並製作壕溝、殘骸、無人機、爆炸及三個時段的環境變化。

場景製作 ★★★☆☆
完整分析

技術／流程變更

這類大型環境的關鍵不是單一 hero shot，而是同一戰場必須承受 180 個攝影機角度與三種時間條件；因此 CG、FX、DMP、Comp 必須共享尺度、地形與 lighting 基準，否則跨鏡頭很容易出現接縫。

Production 影響

對大型場景團隊，可借鏡其「先建立可跨鏡頭成立的 3D 基底，再讓 FX／DMP／Comp 延伸」的分工方式；尤其適合檢查地形、破壞物、煙火與遠景是否能在不同鏡頭共用，而非逐鏡頭重做。

導入測試與限制

這是影視 VFX 場景，資產密度與鏡頭需求不同於即時遊戲；若轉到 Unreal／Unity，仍需另做 LOD、streaming、碰撞與 runtime FX 預算評估，不能直接照搬離線渲染配置。

#08 · character-production

Modo 14.2：角色直接操控、USD 匯出與 Cryptomatte 工作流

Modo 14.2 加入 Rig Clay，可直接在角色表面拖曳 Command Region 觸發 Deformer，不必一直找控制器；同版也加入 USD Export、原生 Cryptomatte、mPath 暫停續算，以及 retopo viewport 與 UV real-world scale 改善。

角色製作 ★★★☆☆
完整分析

技術／流程變更

Rig Clay 的重點是把 pose 操作從控制器位置轉成角色表面語意區域，能降低複雜 Rig 的操作門檻；USD Export 與 Cryptomatte 則分別補強跨 DCC 資料交換與 compositing ID matte 流程。

Production 影響

若有舊 Modo pipeline，可用實際角色測 Rig Clay 的選取／姿勢效率，再用同一 asset 測 USD 到下游 DCC 的 mesh、instance、joint animation、camera 與 Principled material 保留程度。

導入測試與限制

USD 支援並非完整：Portal／Mesh light 不支援，角色 Rig 也可能需要重整才可在其他軟體正確工作；而且 14.2 已是舊版本，應把它視為歷史功能參考，而不是現行採購依據。
