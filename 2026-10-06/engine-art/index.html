HarmoFlow：支援 PBR／NPR 的 3D 貼圖繪製與 PSD 輸出

HarmoFlow 是 Windows 用的 3D 貼圖繪製工具，可在模型或 UV 上作畫，編輯材質，並輸出保留圖層的 PSD；目前提供試用版。

Shader ★★★★☆
完整分析

技術／流程變更

工具同時提供 3D 與 UV 繪製，並以 PBR／NPR 材質預覽檢查外觀；保留圖層的 PSD 輸出，讓貼圖能繼續交給影像編輯軟體修改。

Production 影響

對手繪與卡通角色貼圖，可測試直接在模型上畫分色、再回 PSD 整理圖層的方式，是否比現有工具更容易維持設定圖的用色與筆觸。

導入測試與限制

來源是工具介紹，尚無大型資產的測試結果。導入前應確認貼圖尺寸、透明通道、PSD 圖層與色彩空間，並比較工具預覽和遊戲引擎的結果。

#10 · unreal

UE Shader 免費教材：從材質節點、SDF 到 Substrate

Unreal Engine Shader Book 是可免費閱讀的日文教材，涵蓋材質基礎、Shader 數學、SDF 圖形與 Substrate；部分章節另提供 GitHub 範例工程。

Unreal ★★★☆☆
完整分析

技術／流程變更

教材以材質節點與數學操作逐步建立效果，包含用 SDF 畫圓、星形等圖案，也說明 Substrate 的材質分層與混合，可搭配範例工程理解節點關係。

Production 影響

適合已會做貼圖、想進一步控制材質效果的美術。可先選一個 SDF 或材質混合範例重做，再把參數整理成團隊能調整的材質介面。

導入測試與限制

教材主要以日文撰寫，範例也有版本與功能設定要求。跟做前應確認 UE 版本及 Substrate 設定，並檢查 Shader 指令與貼圖採樣成本，避免只照搬外觀。
