Animo V10：Maya 免費動畫工具集擴到 500+ 功能，加入影片 Reference 與 Arc Tracker

Animo V10/V10.5.4 為 Maya 動畫師整合 500 多項工具，新增 Tools Editor、影片 reference 匯入、camera-space Arc Tracker、Mirror Pose／Animation 等，商用與非商用皆免費。

動畫 ★★★★☆
完整分析

動畫工具整合

V10 把大量零散動畫操作集中到 Tools Editor，並加入影片 reference 直接使用、camera-space arc tracking、mirror pose／animation 等功能，方向不是自動生成動畫，而是降低手工 blocking、polish 的重複操作。

Production 價值

對 Maya 角色動畫團隊，reference、arc、mirror 與各種 timeline／curve 小工具如果能在同一套 UI 找到，能減少 script shelf 碎片化；免費商用也降低在團隊試導入時的授權門檻。

導入測試

先挑一個既有遊戲 attack 或 locomotion shot，比較純 Maya 與 Animo 在 pose mirror、arc 檢查、reference、curve polish 的操作時間；同時確認 Maya 版本、hotkey 衝突、scene callback 和團隊共用設定是否穩定。

KeyFlow：25+ Maya 動畫工具＋獨立 Shot Review，Reference 可直接送 Maya/Blender

Flying Wild Hog 動畫師 Sebastian Jaksan 公開 KeyFlow，包含 25+ Maya 日常動畫工具與獨立 KeyFlow Studio review app；支援 A/B、annotation、reference retime，並可把處理後 reference 送往 Maya 或 Blender。

動畫 ★★★★☆
完整分析

動畫生產力工具

KeyFlow Tools 聚焦 SelSet、Mirror、RelativeSpace、Playblast 等動畫師每天會反覆使用的操作，並提供 timeline dock、搜尋與 GIF tooltip；KeyFlow Studio 則把 reference 比較、註記與 review 從 DCC 中拆成輕量工具。

Production 影響

reference trim／retime 後可直接送 Maya 或 Blender，代表 animator、lead 和 review 的資料交換可以縮短；對需要大量 shot feedback 的團隊，A/B、annotation 與 live review 比單純增加一堆 Maya script 更有流程價值。

工具目前仍在積極開發，先以一個動畫小組試用 Mirror、RelativeSpace、Playblast 與 Studio review，檢查 Maya 2021–2026 相容、專案路徑、影片編碼與多人註記保存，再決定是否納入工作室標準工具包。

#09 · animation

Animo Sliders for Blender：把 Maya Animo 的 16 個動畫滑桿移植到 Blender 4.0–5.2

免費 Animo Sliders 把 Tween、Blend to Neighbors、Push/Pull、Time Offset、Smooth/Harsh、Simplify/Bake 等 16 個常用 animation slider 帶到 Blender，商用與非商用皆可使用。

動畫 ★★★★☆
完整分析

動畫工具流程

Animo Sliders 把 pose interpolation、neighbor blend、push/pull、time offset、noise、smooth／harsh 與 simplify／bake 集中成 Blender K 面板滑桿，技術上是把常見 Graph Editor 操作封裝成可重複動畫工具。

Production 價值

對從 Maya 轉 Blender 或需要快速 blocking／polish 的團隊，滑桿式操作可降低命令記憶與重複曲線編修成本，也讓一般 animator 更容易使用原本依賴 script 的微調功能。

導入測試

目前不是完整 Animo，支援範圍標示 Blender 4.0–5.2；應用 locomotion 與 attack 各一段實測 Tween、Time Offset、Simplify/Bake 是否保留 NLA／constraint 行為，並驗證 5.3 相容性。
