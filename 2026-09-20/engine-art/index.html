#03 · rendering

Unity Surface Cache GI：URP 動態 GI 可跟著幾何與燈光改變，近期回報也暴露多燈噪點限制

Unity 正在為 6.7 LTS 推進 Surface Cache GI，目標是在不預烘焙的情況下支援動態幾何與動態燈光的間接照明；9 月討論仍指出多燈 light sampling 尚未完善，ECS 支援預計進 6000.7.0b1。

渲染 ★★★★☆
完整分析

GI 能力

SCGI 的核心是讓 indirect diffuse 能隨場景幾何和燈光即時改變，包含程序城市、破壞物件、開關門、日夜循環等過去需要 bake 或 lighting scenario 才較容易處理的情境。

Production 影響

對 URP 場景，美術迭代可以先不用反覆烘焙就檢查 bounce light，特別適合動態場景與快速 lookdev；官方也明確表示最終效能若需要，仍可在 release 階段切回 baked lighting。

導入限制

目前仍是 preview，近期官方回覆指出 light sampling 對大量燈具仍是 work in progress，燈越多噪點可能越高；ECS 支援也還在後續 beta。導入前應用實際場景量測 VRAM、noise、動態物件與多燈穩定度。

#10 · shader

Unity 6.5 Shader Function Reflection：用 HLSL function 自動生成 Shader Graph Node

Unity 6.5 的 Shader Function Reflection API 讓技術美術在 HLSL function 前加 UNITY_EXPORT_REFLECTION 後，自動把 function signature 反射成 Shader Graph node，並以 XML hints 控制顯示名稱、分類與 port。

Shader ★★★☆☆
完整分析

Shader 工具流程

Reflection API 把 HLSL function 的輸入輸出直接映射成 Shader Graph node，支援 in／out／inout 與 void，並可用 hints 描述 provider key、display name、search category 與參數 UI，減少手動同步 Custom Function Node port。

Production 影響

對公司共用 shader library，技術美術可以維護一份 HLSL 實作，再讓 Graph 使用者以 node 方式調用，降低程式函式簽名改動後 Graph wrapper 忘記更新的風險；也比較適合 AI／LLM 先產 HLSL 再接圖形化流程。

導入限制

它只處理 function body 與 ports，不包含 SubShader／Pass 的 Stencil、Depth、Blend 等狀態；導入時應先挑 3–5 個公司常用 HLSL helper 測 namespace、precision、reference type 與版本控制，再決定是否取代既有 Custom Function Node。

#16 · rendering

Unity 6000.6：GraphicsStateCollection API 轉正並強化 Shader 資產連結

Unity 6000.6.0f1 將 GraphicsStateCollection 從 Experimental.Rendering 移到正式 Rendering namespace，並在 importer inspector 加入現有 Shader 資產連結能力，對 shader variant / graphics state 管理更接近 production API。

渲染 ★★★☆☆
完整分析

Graphics API 技術變更

Unity 6000.6 將 GraphicsStateCollection 從 Experimental.Rendering 移到正式 UnityEngine.Rendering namespace，Importer 也新增連結既有 Shader 資產能力，代表 graphics state 管理 API 正式化。

Production 影響

對 shader variant、warmup 與 graphics pipeline 工具，正式 namespace 可降低依賴 experimental API 的維護風險，Importer 連結 Shader 也讓 state collection 與資產管理更容易整合進 production tooling。

升版測試與相容性

既有工具若引用舊 namespace 必須先做 API migration，並重跑 shader variant collection、warmup、platform graphics validation、build stripping 與 runtime 相容測試，避免只修 compile error 卻漏掉行為差異。
