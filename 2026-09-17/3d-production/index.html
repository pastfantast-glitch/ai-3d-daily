#09 · character-production

ZBrush 風格化角色：Sculptris Pro 探形、Keep Groups 重拓樸與 Bend Curve 控角

Shane Olson 示範從動態拓樸 blockout 到 ZRemesher、custom brush 分件邊界、角的 Bend Curve 造型與換材質檢查表面噪點的完整雕刻決策。

角色製作 ★★★★☆
完整分析

角色雕刻流程

初期以 Sculptris Pro 不受既有拓樸限制地找大輪廓，mesh 拉伸後再 Mirror and Weld、Auto Groups，並以 ZRemesher 的 Keep Groups 與低 Smooth Groups 保住零件交界和銳利折面。

造型製作價值

作者先用 custom brush 在同一 mesh 上刻出清楚分件邊界，避免探索期過早增加 SubTools；大型角則先均化 topology 再用 Bend Curve 分段調方向、scale、twist，適合需要快速維持強輪廓的風格化角色。

實作限制

示範著重雕刻與 3D print 造型，並未涵蓋遊戲角色 retopo、UV、rig deformation。實作時應另外檢查 group 邊界的 subdivision、細節投射、列印分件公差，以及若要進即時引擎時的低模與表情變形需求。

#12 · production-workflow

HIVEalt 2026：Houdini 從 F1 賽道、CAD→UE 到 AI 輔助程序工具的實務合集

SideFX 集合建築、F1 數位孿生、重型 CAD 清理、Houdini MCP、增材製造與汽車氣動等流程，重點是以可重用程序系統處理頻繁設計變更。

製作流程 ★★★★☆
完整分析

程序技術流程

Q3D 以 Houdini 將數週 F1 賽道幾何縮成數日，Ocean Infinity 則把大型 SolidWorks assembly 經程序清理後送進 Unreal simulation；共同做法是把反覆版本變更轉為非破壞處理，而非每版重新人工整理。

跨領域價值

議程還涵蓋建築規則、鞋類 biomimetic、增材製造 lattice、汽車氣動資料與 Houdini MCP；AI 被用來建立或調整程序 setup，而核心幾何、模擬與美術控制仍保留在 Houdini node network 中。

採用判斷

活動頁提供流程摘要但完整錄影尚待發布，細部效能與工具維護成本仍未驗證。團隊應挑一個高頻改版資產測輸入標準化、cook time、manual override、HDA 版本、Unreal handoff 與錯誤恢復，再評估程序化投資是否真的縮短交付。

#13 · prop-production

風格化海盜寶箱：Blender 5.2 到 UE5.8 的 GLB／FBX、材質與互動 Blueprint 流程

3D Tudor 以 44 節課拆解 blockout、plank rhythm、modifier、UV、AO／cavity bake、引擎材質與開箱互動，強調遊戲距離下的輪廓與轉場可讀性。

物件製作 ★★★★☆
完整分析

道具製作流程

案例先鎖定大比例與木板節奏，再以 Solidify、Bevel、Mirror 和刻意 edge loop 建立可讀輪廓；完成 UV 與 AO／cavity bake 後，以 GLB／FBX 送往 UE5.8，建立可重用材質與開箱 Blueprint。

遊戲製作價值

金屬框被當成第二層 silhouette，開合動作以清楚 before／after 狀態和越界動勢遮住 mesh 切換；這顯示互動道具不一定需要大型動畫系統，先讓造型、材質分離與焦點在遊戲距離成立更關鍵。

實作限制

來源同時推廣付費課程，效能數據與 Blueprint 細節有限。採用時應獨立檢查 scale、pivot、碰撞、LOD／Nanite、材質 instance、GLB 與 FBX 差異、開合狀態同步及複雜光照中 emissive 焦點是否仍清楚。
