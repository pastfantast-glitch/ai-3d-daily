Agora Studio 的 UE5 即時動畫流程：平行製作、Subsequence 隔離與 Shot Sculpt

《A-COM》把預覽、動畫、燈光與剪輯集中在 UE5 Sequencer；複雜角色分到子序列後烘焙回主剪輯，並直接在引擎內做殘影與局部 Morph 修形。

動畫 ★★★★★
完整分析

即時動畫流程

Agora Studio 移除 DCC 與引擎間反覆 FBX 轉換，把動畫、燈光與合成由接力式改成可平行調整的 Sequencer 流程；動畫師工作前先有接近最終畫面的環境與燈光，因此構圖、節奏和演出回饋能在同一上下文中完成。

穩定與造型控制

多人且 constraint 複雜的鏡頭被拆成獨立 Subsequence，再以烘焙 clip 進入主剪輯，換版更快並降低主序列崩潰與 motion blur ghost；快速攻擊以額外手臂 mesh 製作 smear，肩部塌陷則用 UE 內 Morph Target 配合 Control Rig curve 做逐鏡頭修形。

導入測試

引擎內完成不代表所有控制器都適合即時計算。團隊應用一個多角色鏡頭比較 live rig 與 baked clip 的開檔、換版、渲染和崩潰率，驗證 constraint、曲線、motion blur、Morph 版本管理及回到 DCC 的可逆性，再決定哪些階段留 live、哪些階段固定烘焙。

KeyFlow：免費 Maya 動畫工具組串接 Blocking、Pose Library、Bake 與獨立 Shot Review

KeyFlow 提供 25 項以上 Maya 動畫效率工具；KeyFlow Studio 則支援 A/B、逐幀標註、區網／線上 review，以及把參考影片送往 Maya 或 Blender。

動畫 ★★★★☆
完整分析

動畫工作流

Maya 工具涵蓋 tween、跨角色／場景複製動畫、pose library、transform 與 bake，目標是從 blocking 到 polish 的日常小操作累積節省；作者表示可搭配一般標準 Maya rig。

審片製作價值

獨立 Studio app 可做 A/B、文字與畫筆標註、同步 feedback session，亦能剪裁或 retime 參考影片後送到 Maya／Blender；動畫製作與審片可由同一套免費工具串接，降低小團隊導入商業 review 系統的門檻。

相容性測試

目前僅支援 Windows 10+，KeyFlow 需 Maya 2021+，且跨複雜自訂 rig 的證據有限。導入前應測 namespace、referenced rig、多角色 copy、undo、bake curve、色彩管理、EXR sequence、網路 review 延遲與 Blender 匯出結果。

#10 · rigging

mGear 5.3：Maya 2027／Python 3.13、Blendshape Transfer 與 SDK Creator

mGear 5.3 新增八項工具並更新變形工作流；Blendshape Transfer 可重建 combo network、清理 zero-delta target，SDK Creator 能從時間軸 pose 建立可鏡像的 Set Driven Key。

綁定 ★★★★☆
完整分析

Rig 工具更新

5.3 將 solver 與 C++ acceleration modules 重新編譯至 Maya 2027／Python 3.13，並移除舊 Python 2／3 相容層；Blendshape Setup Transfer 可跨多來源 mesh 重建 combo network 並移除沒有變形的 target。

製作價值

SDK Creator 讓 rigger 在時間軸先擺 pose，再自動建立 Set Driven Key network，支援左右鏡像與 scripting API；對表情、corrective shape 與重複角色 build，可把容易遺漏的手工連線改成可重現步驟。

升版測試

團隊若仍在 Maya 2022–2026，需確認同一套 rig package 的版本矩陣。建議用含 combo blendshape、namespace、reference、custom solver 與 ueGear 匯出的代表角色測 rebuild、序列化、publish farm 與 Maya 2027 plugin 載入。
