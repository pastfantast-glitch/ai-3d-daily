Blender 5.2 LTS：Geometry Nodes Physics 已進入可做 Production Prototype 的階段

Blender 官方說明 5.2 LTS 的 Hair／Cloth dynamics 已由 Geometry Nodes 內建資產包裝 XPBD Solver，並支援 Collider、Custom Force 與 Custom Effector。它仍標示 Experimental，但已不是單純技術展示。

Procedural ★★★★★ 成熟度 Experimental 先測 Cloth / Hair
完整分析

問題／目標

把 cloth、hair dynamics 從黑盒 simulation 拉進可程序化、可組合的 Geometry Nodes workflow。

Production

高階資產包裝底層 XPBD；Collider 可直接用 modifier stack 幾何，Custom Force／Effector 可插入自訂行為。這讓 Technical Artist 能把 simulation 規則封裝成資產，而不是每個 shot 重建。

限制

官方仍標 Experimental，設計可能迭代；正式專案先做 prototype，不宜立刻替換成熟 cloth pipeline。

20 分鐘實測

BLENDER / RETOPO DISCOVERED · 06/25

RetopoFlow 4.1.9：Blender 5.2 相容，Retopo 工具已深度整合 Edit Mode

RetopoFlow 4 的核心變化是從舊版獨立模式改成 Edit Mode 內的工具；4.1.9 已加入 Blender 5.2 相容。對從 3ds Max／其他 DCC 轉 Blender 的角色美術，這是值得建立 muscle memory 的手動 Retopo 路線。

Character ★★★★★ Blender 5.2 支援 Workflow Edit Mode
完整分析

關鍵決策

RetopoFlow 4 把 Contours、PolyStrips、Strokes、PolyPen 等工作直接融入 Edit Mode，進入工具時自動處理 snapping、retopology overlay、auto merge、inactive geometry fade，退出後恢復原設定。

Production 收益

限制

第三方 Add-on 仍要做 Blender 版本鎖定與專案測試。

SOP

先用頭部／肩膀高模做 20 分鐘測試，檢查 Contours、PolyStrips、Relax、Mirror 與 Blender 原生 Edit 操作是否符合習慣。

NPR / UE5 DISCOVERED · 08/2026

Arknights: Endfield Rendering Recreation：UE5.8 與 Blender 共用同一 NPR 視覺目標

這個 2026/08 專案把同一角色分別在 UE5.8 與 Blender 建立 Hybrid NPR，目標是在 realtime／offline 間維持一致的 anime readability，同時保留部分 PBR 材質資訊。

NPR ★★★★★ UE5.8 Realtime 跨引擎 高參考值
完整分析

視覺問題

Realtime 中臉部陰影過重、衣服紋理容易被壓掉、anime readability 不足。

方法

UE5 端採 view-dependent NPR 思路，柔化 face／hair tonal steps，同時讓 body 保留 PBR detail，再統一 skylight、rim light 與 post process。價值在於不是追求完全 Unlit，而是分區決定 NPR 與 PBR 的職責。

限制

這是 solo recreation，不等同原遊戲官方 shader；應當作可驗證方法，而非逆向定論。

SOP

同角色固定相機，先建立 Face/Hair/Body 三區，再分別決定 tone step、PBR 保留量與 rim/post，最後用 UE／Blender A/B 比較。

效率 高 內建 Add-on 是 學習成本 低
完整分析

問題／目標

材質與 Geometry Nodes debug 時，快速查看任一節點輸出比反覆手動改線更重要。

Material Lighting Nodes：NPR Project 開始把自訂材質光照帶回 EEVEE

NPR ★★★★★ EEVEE 開發中 Production 先 Prototype

問題／目標
